# 모의문서 43건 — 영업비밀 등급분류 가이드 기반 (2026-09-29, 2차 수정)

출처: 사용자가 2026-09-29 카카오톡으로 전달한 등급분류 가이드북 사진 6장(부서별
정보유형->등급 매핑표)을 정답(true_grade)으로 사용. 본문은 사람이 직접 작성(LLM 미사용).
2차 수정은 "모의문서 생성·검증 절차" 안내문(사용자 제공)을 반영한 것 — 1차본에서
실제로 위반 2건(제품 코드명 PS-330이 특급기밀 100%·공개등급 0%에 쏠림, 관리수준을
"~외에는 공유하지 않는다"류 문장으로 직접 서술한 곳 4곳 중 3곳이 특급기밀에 쏠림)이
발견되어 고쳤고, ICD 메타데이터 필드·대조 문서 3건을 추가했다.

## 정답 라벨의 성격
`true_grade`는 **가이드가 정보유형에 직접 배정한 값**이지, 룰엔진·분류모델·사람
검수자가 판정한 값이 아니다. 특급기밀(TS) 3건은 가이드 카탈로그 표에 직접 예시가
없어(표는 1급비밀까지만 실려 있었다) 가이드 앞부분의 등급 정의를 적용해 만든
확장 예시다 — `internal_manifest.jsonl`의 `label_basis` 필드에 구분을 남겼다.
40~43번 3건은 기존 문서와 같은 부서·양식·소재의 **대조 문서**(등급만 다름) —
`contrast_of` 필드로 짝을 남겼다.

## 파일
- `reviewer_documents.jsonl` — 검수자에게 줄 파일. review_id + text(제목+본문)만.
- `internal_manifest.jsonl` — 내부 정답표. true_grade·department·info_type·doc_format·
  char_count·label_basis·contrast_of·**source_type·security_marking·access_scope**
  (ICD §3 형식, rule_engine.management_from_metadata·pipeline.metadata_floor가 실제로
  읽는 필드와 동일 — 본문에는 없고 메타데이터로만 존재). **검수자에게 배포하지 말 것**
  (mock1000과 동일 원칙 — doc.zip 배포 금지 사례 참고).
- `shortcut_audit_*.json` — 아래 통계적 지름길 검증 결과(있으면).

## 한계 (숨기지 않음)
- 문서는 사람(Claude)이 한 회사(가상의 "가온정밀(주)")를 배경으로 직접 작성한 것이라,
  같은 세션·같은 문체에서 나온 근접 중복 위험이 mock1000류(여러 출처 혼합)보다는
  클 수 있다 — 근접중복 코사인 유사도는 이 스크립트에서 측정하지 않았다.
- 등급 판정은 전문가 검수를 거치지 않았다(가이드 배정값 그대로). 실제 학습/검수
  투입 전 표본 검수를 권장한다.
- 정량 사실(금액·수치)은 내적 일관성만 맞췄고 실제 산업 통계와 대조하지 않았다.
- TS(특급기밀) 3건은 가이드 카탈로그에 직접 예시가 없어 확장 구성한 것이므로,
  나머지보다 라벨 근거가 한 단계 약하다 — 검수 시 우선 확인 권장.
- ICD 메타데이터는 등급에서 파생한 것이지 실제 KL 공급값이 아니다 — 실제 배치
  전 검증 신호로 쓰기에는 한계가 있고, metadata_floor 게이트 동작 확인용이다.
- 표본이 43건(등급당 9~17건)으로 작아 통계적 지름길 검증(4번 항목)의 검정력이
  낮다 — "유의하게 낮다"보다 "방향과 크기"로 읽을 것.
