구매요청서·발주서 작성 매뉴얼

문서번호: 구매-매뉴얼-2026-011
작성부서: 구매팀
작성일: 2026년 9월 25일
적용대상: 전자승인시스템을 사용하는 전 부서 담당자

1. 목적
이 매뉴얼은 전자승인시스템에서 구매요청서(PR)와 발주서(PO)를 작성하는 절차와 항목별 작성 기준을 안내하기 위해 작성하였다. 지난달 시스템 전환 이후 작성 항목을 헷갈려 반려되는 사례가 반복되어, 구매팀이 각 부서 문의를 모아 정리하였다.

2. 작성 절차 개요
가. 요청 부서가 전자승인시스템에서 구매요청서를 작성한다.
나. 부서장 승인 후 구매팀이 내용을 검토한다.
다. 구매팀 검토가 끝나면 발주서를 작성해 거래처에 전달한다.
라. 물품 입고 후 검수를 완료하면 건이 종료된다.

3. 구매요청서 작성 항목

| 항목       | 작성 기준                               |
|------------|------------------------------------------|
| 품목명     | 규격·모델명까지 구체적으로 기재          |
| 수량       | 단위를 함께 표기(개, box, set 등)        |
| 희망 입고일| 영업일 기준으로 여유 있게 설정            |
| 용도       | 사용 목적을 한 줄로 간단히 기재           |
| 예산 항목  | 해당 부서 예산 코드 선택                  |

4. 승인단계별 처리기한

| 단계          | 처리기한       | 담당           |
|---------------|----------------|----------------|
| 부서장 승인   | 접수 후 1영업일| 요청 부서장    |
| 구매팀 검토   | 승인 후 2영업일| 구매팀 담당자  |
| 발주서 발행   | 검토 후 1영업일| 구매팀 담당자  |
| 입고 검수     | 입고일 당일    | 자재관리팀     |

처리기한은 통상적인 품목 기준이며, 수입 품목이나 특수 사양 품목은 거래처 사정에 따라 기한이 늘어날 수 있다.

5. 발주서(PO) 작성 시 유의사항
구매요청서 검토가 끝나면 구매팀이 발주서를 작성해 거래처에 전달한다. 발주서에는 품목·수량·단가·납기와 함께 거래처 담당자 정보를 함께 기재하며, 작성 전 최근 거래 이력을 참고해 이전과 다른 조건이 있는지 확인한다. 금액이 큰 발주 건은 팀장 전결 범위를 넘는지 먼저 확인하고, 범위를 넘으면 상위 결재선을 추가로 지정한다. 발주서 발행 후에는 거래처에 유선이나 문서로 접수 여부를 다시 확인하는 것을 권장한다.

6. 변경 및 취소 처리
가. 입고 전 품목·수량 변경: 요청 부서가 변경 사유를 적어 구매팀에 다시 요청하면, 구매팀이 거래처와 협의해 발주서를 정정한다.
나. 발주 취소: 거래처에 이미 전달된 건은 취소 가능 여부를 거래처와 먼저 확인한 뒤 처리하며, 이미 생산이나 입고 준비가 진행된 경우 취소가 어려울 수 있다.
다. 반품·교환: 검수 단계에서 불량이 확인되면 자재관리팀이 사진과 함께 사유를 기록해 구매팀에 전달하고, 구매팀이 거래처와 반품·교환 절차를 진행한다.

7. 자주 반려되는 사례
가. 품목명에 규격을 적지 않아 거래처가 다른 사양으로 견적을 제시한 경우
나. 예산 항목을 잘못 선택해 결재 단계에서 되돌아오는 경우
다. 희망 입고일을 지나치게 짧게 잡아 거래처 납기와 맞지 않는 경우
라. 수량 단위를 적지 않아 개수인지 묶음인지 혼동되는 경우
마. 용도란을 비워 두어 검토 단계에서 추가 설명을 다시 요청받는 경우

8. 문의처
작성 중 오류가 발생하면 구매팀 담당자에게 문의하고, 시스템 자체 오류는 전산지원팀에 별도로 접수한다. 긴급한 발주 건은 구매팀 담당자에게 사전에 알려 처리 순서를 조정할 수 있다.

9. 기타 안내
이번 매뉴얼 배포와 함께 다음 주 화요일 오전에는 각 부서 담당자를 대상으로 한 사용법 설명 시간을 짧게 운영할 예정이며, 참석이 어려운 경우 이 매뉴얼로 대체 숙지하면 된다. 아울러 매뉴얼은 분기마다 현황에 맞게 다시 점검해 갱신할 계획이며, 개정 시에는 변경 이력을 첫 페이지에 함께 표기한다. 참고로 이번 주 금요일부터는 본관 2층 회의실 일부가 공사로 사용이 제한되니, 설명 시간 장소는 3층 교육실로 변경되었음을 함께 안내한다.
