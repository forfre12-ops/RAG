회의실예약-출입카드 연동 테스트 결과 메모

9/17 메모

- 지난주부터 진행한 회의실예약시스템과 출입카드 연동 테스트 결과 정리.
- 목적: 회의실 예약 시간에 맞춰 외부 방문객 출입카드가 자동으로 활성화/비활성화되도록 하는 기능 테스트.
- 테스트는 본관 3층 회의실 2곳 대상으로 진행. 총 24건 중 21건은 정상 작동, 3건은 활성화 시점이 예약 시간보다 10분 이상 늦게 반영됨. 늦어진 3건 모두 연속 예약(앞 회의 바로 이어서) 상황이었음.
- 원인 확인 중인데, 정보시스템팀은 서버 간 동기화 주기(현재 15분)가 너무 길어서 그런 것 같다고 추정. 총무팀은 주기를 줄이면 해결될 것 같다는 의견이지만, 정보시스템팀은 주기를 줄이면 서버 부담이 커질 수 있어 신중해야 한다는 입장. 아직 조율 안 됨.

- 당장은 수동으로 활성화 시간을 5분 앞당겨 운영하는 임시 방편으로 가기로 합의.
- 다음 테스트는 10월 1일 예정, 범위를 신관까지 넓혀서 진행. 신관은 회의실이 4곳이라 테스트 건수도 더 늘어날 것으로 예상.

- (별건) 이번 주 금요일 전체 회의실 정기 청소 예정, 사용 예약 있는 팀은 미리 확인 요망.
- (별건) 다음 달 비품 주문 마감일이 하루 앞당겨진다고 공지함.

- 추가로, 활성화 지연이 있었던 3건 모두 외부 방문객이 포함된 회의였는데, 다행히 지연 시간이 10분 수준이라 실제 업무에 큰 지장은 없었다는 담당 부서 피드백을 받음.
- 다음 테스트에서는 연속 예약 상황을 일부러 더 늘려서 재현성을 다시 확인해볼 계획.
- (추가) 정보시스템팀은 동기화 주기 조정 대신, 연속 예약 건에 한해 별도 로직을 적용하는 방식도 검토해보겠다고 함. 다음 테스트 전까지 가능 여부를 확인할 예정.
- (추가) 신관 테스트 결과가 나오면 전체 적용 시점도 함께 논의할 예정.
- (추가) 테스트 결과는 다음 주 월요일 정보시스템팀과 공유 회의에서 다시 정리할 계획.
