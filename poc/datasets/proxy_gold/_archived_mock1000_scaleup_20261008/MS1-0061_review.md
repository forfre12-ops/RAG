고정자산 처분 내역 자료 요청

수신: 총무팀
발신: 경영감사팀
요청일: 2026.10.04

1. 요청 내용
올해 1월부터 9월까지 처분(폐기·매각)된 고정자산 목록과 각 건의 사전 승인 일자, 실제 처분 일자를 비교할 수 있는 자료를 10월 14일까지 보내주시기 바랍니다. 가능하면 처분 사유 구분(노후·고장·단종 등)도 같이 표시해 주세요.

2. 배경
표본으로 뽑아본 처분 건 중 사전 승인 일자가 실제 처분 일자보다 늦게 찍힌 경우가 3건 있었습니다. 총무팀 쪽 설명으로는 노후 설비 폐기가 안전 문제로 급하게 처리되는 경우 사후에 서류를 정리하는 경우가 있다고 하는데, 경영감사팀 입장에서는 순서가 바뀌면 절차상 문제로 볼 여지가 있어 전체 건수를 다시 확인해보려고 합니다. 올해 처분 건 전체는 대략 60건 정도로 파악하고 있습니다.

3. 추가 확인
해당 3건의 처분 사유서와 당시 담당자 의견도 같이 받을 수 있을지 부탁드립니다.

4. 기타
다음 달 진행 예정인 비품 정리 행사 관련해서는 이번 건과 무관하게 총무팀에서 별도로 안내해주시면 됩니다. 회신은 자료가 정리되는 대로 순차적으로 주셔도 괜찮습니다. 사전 승인과 실제 처분 사이 간격이 평균 며칠 정도인지도 전체 건수 기준으로 같이 집계해 주시면 참고가 될 것 같습니다. 자료 형식은 기존에 쓰시던 엑셀 양식 그대로 보내주시면 되고, 별도 가공은 필요 없습니다. 혹시 처분 대상 중 아직 매각 절차가 끝나지 않은 건이 있다면 별도로 표시해 주세요. 참고로 고정자산 처분 승인 절차는 금액 구간별로 승인 단계가 다르게 설계되어 있어, 이번 조사에서는 구간별로 나누어 패턴을 다시 볼 예정입니다. 총무팀 담당자는 안전 관련 긴급 처분 건에 한해서는 사후 승인 절차를 별도로 명문화하는 방안도 검토해보자는 의견을 주셨습니다. 자료 취합이 끝나는 대로 결과는 간단히 정리해서 다시 공유드리겠습니다.
