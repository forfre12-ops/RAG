근태관리시스템 전환 관련 주간 메모

10/5 월. 근태시스템 전환(기존 사내 서버형 → 클라우드형) 진행 상황 정리.

- 데이터 이관 테스트 2차 완료. 1차에서 걸렸던 반차 시간 단위 계산 오류는 해결됨. 근데 야간 근무자 교대 기록 쪽에서 또 다른 오류 발견 — 자정 넘는 근무가 다음날로 두 번 잡히는 현상. 전산팀은 이번 주 내 패치 예정이라고 함.
- 생산팀장은 전환 일정을 11월로 미루자는 입장. 교대 근무 특성상 바쁜 시기에 시스템이 바뀌면 혼란이 크다고 함. 반면 인사운영팀장은 연말 연차 정산 전에 끝내야 한다고 보고 있어서 서로 입장이 다름. 다음 주 임원 보고 전에 한 번 더 조율 필요.
- 참고로 금요일에 노조 쪽에서 근태 관련 질의가 하나 들어왔는데 수당 계산 방식 관련 건이라 재무팀과 같이 답변 준비 중.
- 다음 주 화요일 전산팀과 데이터 이관 3차 테스트 일정 조율 중. 이번엔 생산팀 입회하에 진행하기로 함.
- 참고로 이번 주 금요일 본관 주차장 일부 구역이 소방 점검으로 통제된다고 함.
- 참고로 이번 전환 작업 중 테스트 계정 2개가 잘못 생성돼 있던 것도 발견, 바로 삭제 처리함.
- 다음 주 수요일 오후에는 전산팀, 재무팀, 인사운영팀 삼자 미팅 예정. 수당 정산 건 포함해서 같이 정리할 계획.
- 참고로 전환 작업 중 생산팀에서 요청한 교대조별 집계 화면 개선 건도 같이 반영 중. 완료되면 별도 안내 예정.
- 다음 주 초 인사운영팀 내부적으로 전환 체크리스트 재점검 예정.
- 그 외: 사내 동아리 지원 신청 마감 다음 주로 연장됨. 구내식당 메뉴 설문 결과는 다음 회의 때 공유 예정.
- 참고로 전환 이후 데이터 백업 주기도 기존 주 1회에서 일 1회로 늘리기로 함. 저장 용량 문제는 전산팀에서 별도 확인 중.
- 다음 주 월요일까지 전환 리스크 목록 다시 정리해서 공유 드릴 예정.
