계약서 번역 오류 발견 및 처리

10/6, 오후 메모

지난주 해외 거래처(델타머터리얼즈)랑 맺은 기술 사용 계약서 번역본 다시 보다가 조항 하나 번역이 좀 이상한 거 발견함. 원문은 갱신 통보 기한이 계약 종료 90일 전인데 번역본엔 60일 전으로 되어있었음. 큰일은 아니지만 혼동될 수 있어서 바로 번역 업체에 확인 요청함. 처음 발견한 건 우연히 다른 조항 찾다가였음.

번역 업체는 자기들 오류 맞다고 인정하면서 수정본 보내주겠다고 함. 근데 법무팀 쪽에서는 이미 거래처한테 전달된 버전이라 그냥 정정 공문으로 처리하자는 의견이고, 저는 번역본을 통째로 다시 보내는 게 깔끔하다고 생각해서 방식은 아직 안 맞춰짐. 혹시 다른 조항에도 비슷한 오류가 있을까 싶어서 처음부터 한 번 더 대조해볼 생각. 전체 스무 개 조항 중 절반 정도는 오늘 중으로 끝낼 수 있을 듯.

내일 법무팀이랑 다시 얘기해보기로 함.

+ 참고로 오늘 오전에 신규 입사자 책상 배치 다시 함. 자리 배치표 수정해서 공유드림. 그리고 다음 주 금요일 부서 전체 회의 시간이 오전에서 오후로 바뀌었다고 전달받음, 다들 참고. 회의실도 3층으로 바뀐다고 함.

+ 번역 건은 수정본 받으면 원본 계약서 파일과 같이 묶어서 다시 정리해둘 예정. 비슷한 실수가 반복 안 되게 다음 번역 맡길 때는 중요 조항은 따로 한 번 더 확인 요청하기로 함. 번역 업체 쪽에도 이번 건 피드백은 공식적으로 전달하기로 함.

+ 그리고 오후에 거래처(가온리테일) 쪽에서 전화로 다른 계약서 사본 요청도 들어와서 그건 내일 처리하기로 함. 급한 건 아니라고 해서 이번 주 안으로만 처리하면 될 듯.

+ 참고로 이번 번역 오류 건은 금액이나 기한에 영향을 주는 수준은 아니었던 걸로 결론 남. 그래도 혹시 몰라서 과거에 같은 업체가 번역한 다른 계약서도 한두 건 더 확인해볼 생각. 시간 날 때 하나씩 천천히 보려고 함.
