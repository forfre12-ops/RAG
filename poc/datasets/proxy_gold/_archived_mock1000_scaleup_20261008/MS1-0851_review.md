월간 검수 현황 메모

10/6(화) 메모 — 9월 검수 현황 정리

9월 전체 입고 검수 건수는 작년 같은 달보다 조금 늘어난 수준. 불량으로 분류돼 반송되거나 재검수로 넘어간 비율은 전체의 2.4% 선으로, 8월(2.1%)보다 소폭 올라감. 품목별로 보면 소형가전 부품 쪽 불량 비율이 특히 눈에 띄게 올라서 따로 봐야 할 것 같음.

품질관리팀 담당자는 이 추세가 이어지면 해당 품목 협력업체 쪽에 공식적으로 개선 요청을 보내야 한다는 쪽. 구매팀 대리는 아직 두 달치 추세라 속단하기는 이르다며 10월까지 한 달 더 지켜보자는 입장. 의견이 갈려서 일단 10월 말에 다시 판단하기로 함.

참고로 소형가전 부품 쪽 9월 불량률은 3.6%로 8월 2.2%보다 꽤 올라간 수치. 다른 품목군은 큰 변화 없음. 주방가전은 오히려 8월보다 소폭 낮아진 1.1%를 기록함.

+ 출고 전 검품 쪽은 특이사항 없었음. 다만 추석 연휴 전 물량이 몰리면서 검수 인력이 며칠 바빴다고 함. 연휴 직전 하루는 평소보다 두 시간 가까이 늦게 퇴근했다고.

+ 별건 — 다음 주 검수 장비 캘리브레이션 일정 다시 확인 필요. 그리고 신규 입사자 검수 교육은 이번 주 안으로 마무리 예정. 교육 끝나면 바로 현장 투입 가능할 듯.

+ 월말 보고 때 소형가전 불량률 추세 그래프로 따로 정리해서 올릴 예정. 품질관리팀 쪽에서 원인 분석 결과도 같이 받아서 붙이기로 함.

+ 참고 — 작년 9월 같은 품목 불량률은 2.0% 정도였는데 올해가 그보다 꽤 높은 편. 작년에는 특별한 원인 없이 10월 들어 자연스럽게 떨어졌던 적이 있어서, 올해도 비슷하게 흘러갈지 좀 더 지켜봐야 할 듯.

+ 메모 — 구매팀 쪽에 해당 협력업체 최근 생산 공정 변경 여부도 물어봐달라고 요청해둠. 답 오면 불량률 추세랑 같이 엮어서 봐야 할 듯. 혹시 공정 변경이 원인으로 확인되면 다음 달 재계약 검토 자료에도 같이 반영해야 할 것 같음.
