## 승인 범위

본 메모는 변경 조건을 양산에 적용하는 승인이 아니다. VP-2026-017에서 확인된 하한 미만 결과와 장비 점검 이력 누락을 해소하기 위한 재검증에만 적용한다. 재검증 대상은 CR-2026-017에 적힌 지정 로트로 한정하며, 조건표의 수정·복사·외부 제공은 별도 승인 없이는 허용하지 않는다.

## 승인 조건

- 실패 구간의 장비 점검 이력을 조건표와 같은 로트 식별자로 연결할 것
- 재검증 결과가 정상 관리범위 안에 있는지 품질보증이 확인할 것
- 원시 측정값, 작업 로그, 회의 결정사항을 검토 묶음으로 보관할 것
- 추가 열람 또는 반출 요청은 공정개발 파트장과 보안운영 책임자의 공동 확인을 받을 것

## 승인 보류 사유

현재 결과는 조건 조합의 효과와 장비 상태의 영향을 분리하지 못했다. 이 상태에서 양산 라인에 적용하면 재작업 범위와 원인 분석 비용이 커질 수 있다. 또한 조건 조합과 적용 순서는 내부 검증을 통해 축적된 결합정보이므로, 검증 목적과 무관한 공유는 허용하지 않는다.

## 이행 확인과 변경 통제

공정개발은 재검증을 시작하기 전에 조건표의 개정 번호와 적용 대상을 다시 확인한다. 제조기술은 장비 점검 이력이 비어 있는 로트를 재검증 대상에서 제외하거나, 점검표가 보완된 뒤에만 포함한다. 품질보증은 결과 보고서에 정상 범위 판정만 적지 않고, 원시 측정값과 로트 식별자가 실제로 연결되는지 확인한다.

재검증 과정에서 조건표를 수정해야 할 경우에는 수정 사유, 수정자, 영향 로트를 기록하고 CR-2026-017에 연결한다. 기존 조건표를 덮어쓰거나 구두 지시로 바꾸는 행위는 허용하지 않는다. 보안운영은 조건표 발췌본의 배포 이력과 외부 반출 요청 여부를 승인 종료 전 다시 점검한다.

## 승인 종료 후 기록

재검증이 끝나면 공정개발은 적용·미적용 로트 목록, 품질보증은 결과 판정 근거, 제조기술은 작업 표준 영향 검토서를 각각 제출한다. 세 자료가 같은 변경 요청 번호를 참조해야 하며, 누락 또는 상충이 있으면 양산 승인 안건을 상정하지 않는다. 검토 묶음은 승인 종료 뒤에도 지정 보관 위치에 남겨 후속 원인 분석과 감사 확인에 사용한다.

## 종료 기준

품질보증 책임자가 재검증 결과와 로그 완결성을 확인하고, 제조기술이 작업 표준 변경 범위를 검토한 뒤 별도 양산 승인 안건을 제출한다. 위 조건이 충족되지 않으면 본 조건부 승인은 자동으로 종료되며, 변경안은 현행 절차로 되돌린다.
