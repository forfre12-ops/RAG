# 검증 결과 보고서

| 항목 | 내용 |
| --- | --- |
| 문서번호 | VP-2026-017 |
| 대상 | CR-2026-017 HBM-E 적층 전 세정 순서 변경안 |
| 검증 기간 | 2026-07-18 ~ 2026-07-24 |
| 작성부서 | 품질보증팀 |
| 검토 상태 | 재검증 필요 |

## 1. 검증 개요

지정 로트에 변경 조건을 적용한 뒤, 접촉저항 산포와 작업 로그의 대응 관계를 확인했다. 검증은 조건표에 등록된 순서로만 진행했으며, 조건표 사본은 검증 책임자와 공정개발 지정 인원의 보안 작업공간에 보관했다.

## 2. 결과 요약

검증 완료율은 변경 전 73%에서 변경 후 59%로 감소했다. 절대 차이는 14%p, 감소율은 19.2%다. 정상 관리범위는 63~83%이며 현재 값은 하한 미만이다. 착수 5주차에 기준값을 확인했고, 6주차에 변경 조건을 적용했으며, 7주차에 재검증을 수행했다.

| 확인 항목 | 결과 | 판단 |
| --- | --- | --- |
| 조건표와 장비 로그 대응 | 일부 로트에서 대기 순서 기록 누락 | 보완 필요 |
| 접촉저항 산포 | 특정 구간에서 확대 | 재검증 필요 |
| 원시 측정값 보관 | 지정 작업공간에서 확인 | 유지 |
| 외부 공유 이력 | 확인되지 않음 | 유지 |

## 3. 발견 사항

실패 로트는 세정액 농도보다 분사 순서와 건조 대기 조건이 함께 바뀐 구간에서 집중됐다. 그러나 해당 구간의 작업 로그에는 노즐 점검 시점이 빠져 있어, 조건 조합 자체의 영향과 장비 상태 영향을 분리할 수 없다. 현 시점에서 변경안의 효과 또는 실패 원인을 단정하는 것은 부적절하다.

재검토 과정에서는 측정값 자체보다 기록의 연결 상태가 더 큰 문제로 확인됐다. 일부 로트는 조건표의 개정 시각과 장비 로그의 작업 시작 시각이 일치했으나, 실패 로트는 점검 직후 적용 여부가 로그에 남지 않았다. 검증 담당은 누락된 기록을 사후 추정으로 채우지 않고, 당시 생성된 장비 점검표와 작업자 확인 기록을 찾아 연결해야 한다.

## 5. 예외 처리 기준

재검증 중 정상 관리범위를 벗어난 값이 다시 나오면 해당 로트는 즉시 다음 공정으로 넘기지 않는다. 검증 책임자는 원시값의 측정 조건, 장비 점검 상태, 작업자 변경 여부를 먼저 확인하고, 원인을 분리할 수 없으면 변경안 전체를 보류 안건으로 올린다. 예외 처리의 판단 근거는 회의록과 승인 메모에 같은 식별자로 남긴다.

## 6. 후속 조치

공정개발은 누락된 장비 점검 이력을 보완하고, 실패 구간을 별도 로트로 다시 검증한다. 품질보증은 재검증 시 조건표·장비 로그·측정값이 같은 로트 식별자로 연결되는지 확인한다. 변경안은 후속조치 완료 전까지 양산 라인에 적용하지 않는다.
