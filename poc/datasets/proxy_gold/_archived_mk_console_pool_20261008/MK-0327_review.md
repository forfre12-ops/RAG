업무일지 - 6월 3주차

작성자: 선임연구원(센서알고리즘팀) / 기간: 2026년 6월 15일~19일

월요일
- 오전: 정기 주간회의 참석, 2분기 목표 재확인
- 오후: 노이즈 필터링 알고리즘 파라미터 튜닝. 임계값을 0.15에서 0.22로 조정 테스트

화요일
- 거리 추정 모델 재학습 진행. 학습 데이터 3,200건 기준, 평균 오차가 기존 모델 대비 12.4cm에서 7.8cm로 줄어듦. 특히 근거리(1m 이내) 구간에서 오차 개선폭이 커서(기존 9.1cm→4.2cm) 근거리 인식 정확도가 크게 좋아진 것으로 보임
- 오후: 장비팀과 테스트베드 일정 조율 통화

수요일
- 오전: 치과 반차
- 오후: 원거리(5m 이상) 구간 오차는 아직 15cm 내외로 개선 여지 있음. 센서 퓨전 가중치 조정 필요성 논의

목요일
- 신규 테스트 차량에 알고리즘 탑재, 실외 주행 테스트 2회 진행
- 우천 시 인식률이 맑은 날 대비 약 6%p 낮게 나와 후속 보완 필요 메모

금요일
- 주간 결과 정리 및 팀장 보고
- 다음 주 테스트 계획: 야간 조건 추가, 가중치 재조정 버전 적용 예정
- 팀 회식 관련 메뉴 투표 진행함(삼겹살 다수)

비고: 금요일 오후 사내 전산 점검으로 서버 접속 1시간가량 불가 예정이라 작업 백업 미리 해둠. 다음 주 월요일 오전에는 분기 안전교육이 전 팀 공통으로 잡혀 있어 참석 필요.

추가 메모: 목요일 실외 주행 테스트 중 특정 구간(지하주차장 입구)에서 인식 지연이 반복 관찰됨. 로그 확인 결과 조도 변화 구간에서 센서 보정 시간이 평소보다 200ms가량 더 걸리는 것으로 추정됨. 다음 주 테스트 시 해당 구간 데이터를 별도로 수집해 원인을 좁혀볼 계획. 팀장님께는 금요일 보고 때 구두로 먼저 공유하고 다음 주 화요일 정식 보고서로 정리 예정.
