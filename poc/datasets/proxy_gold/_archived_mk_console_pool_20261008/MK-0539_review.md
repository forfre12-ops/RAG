8월 급여 지급 이후 오류 점검 메모

8월 급여 지급 이후 확인된 사항을 정리함.

1. 확인 경위
8월 급여 지급일 다음 날, 생산2팀 소속 직원 급여가 평소보다 과다 지급되었다는 문의가 접수됨. 확인 결과 7월 중 적용된 교대수당 산정 기준 변경분이 급여 시스템에 이중으로 반영된 것으로 파악됨. 최초 문의는 본인이 급여명세서를 확인하는 과정에서 발견한 것으로, 이상하게 생각해 인사팀에 직접 연락을 준 것이 계기가 되었음.

2. 확인 내용
해당 직원을 포함해 같은 기간 동일 조건이었던 인원을 확인한 결과 총 5명에게서 유사한 이중 반영이 발견됨. 1인당 과다 지급액은 적게는 3만원에서 많게는 11만원까지 차이가 있었으며, 합산하면 약 34만원 수준으로 확인됨. 큰 금액은 아니나 반복 발생 가능성이 있어 원인 파악이 필요하다고 판단함. 확인 과정에서 7월, 8월 두 달치 급여 데이터를 전수로 다시 대조하는 작업을 거침.

3. 원인
급여 시스템 담당자 확인 결과, 7월 초 수당 기준표를 갱신하는 과정에서 기존 값을 삭제하지 않고 새 값만 추가로 입력한 것이 원인으로 확인됨. 입력 화면상으로는 구분이 어려웠던 것으로 보임. 비슷한 입력 방식의 다른 수당 항목들도 추가로 확인했으나 다행히 다른 이상은 발견되지 않음.

4. 조치
가. 해당 5명에 대해서는 9월 급여에서 과다 지급분을 차감 정산하기로 함. 사전에 개별 안내는 완료함
나. 기준표 입력 화면에 중복 입력 방지 로직 추가를 시스템 담당 부서에 요청함. 적용 시점은 다음 달 중순 예상
다. 유사 사례 재발 방지를 위해 매월 급여 지급 다음 날 표본 점검을 추가하기로 함, 우선 생산직 전체 인원의 10% 수준을 무작위로 확인하는 방식으로 시작

5. 비고
이번 건은 금액 자체는 크지 않았으나 시스템 입력 절차상 허점이 확인된 사례로, 다음 분기 내부 점검 시 중점 항목으로 포함하기로 함. 담당자 간 인수인계 시 기준표 변경 이력도 함께 공유하도록 절차를 보완하기로 함.
