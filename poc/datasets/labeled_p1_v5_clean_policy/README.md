## 근거
공개 판결문은 비공지성 실패라 내용의 민감도와 무관하게 S3 다(프로젝트 정책). v5_clean 은 옛 검출기가 놓친 판결문 62건 중 52건을 높은 등급으로 갖고 있었다
(9/5 메모리 "62건을 놓쳤다"와 같은 구멍).

## ⚠ 한계
- 정정 주체는 사람이 아니라 검출기·규칙이다(사람 서명 아님). 검출기가 놓친 판결문이 더 있을 수 있다.
- **대가가 있다**: 교차검증에서 S2 재현율 95→92%, 등급명 낱말이 없는 문서의 S1 68→56%·S2 79→65%. 모델이 애매한 문서를 S3 쪽으로 더 기운다.
- 옛 v6 판례 교정(미탐 16→83, "개정" 지름길)과 같은 종류의 정정이라 독립 셋에서 고등급 미탐이 늘지 않는지 계속 봐야 한다 — 이번 측정에서는 늘지 않았다(holdout109 2→2, golden100 72→43).
- 나머지 label_source(synthetic_llm 등)에 같은 종류의 오류가 더 있는지는 확인하지 않았다.
