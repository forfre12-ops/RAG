IT-2025-1603 / 전사 IT기획팀, 운영지원부, 인사관리팀 / IT기획팀 김지영 / 2025-02-24  

1. 검토 배경  
- 현업 부서에서 제안한 시스템 개편 요구사항 중 일부가 기존 범위를 초과함에 따라 재정의 필요함  
- 특히 생산관리팀과 영업지원팀에서 각각의 업무 흐름 개선이 시급하다고 판단됨  
- 기존 예정된 일정은 3월 중순 완료 예정이지만, 요구사항 조정으로 인해 지연 가능성 발생함  

2. 검토 내용  
- IT기획팀은 2월 18일부터 2월 23일까지 각 부서 담당자들과 협의를 진행함  
- 생산관리팀은 기존 시스템에서 실시간 재고 이관 기능 부족으로 인해 오류 발생함  
- 영업지원팀은 고객 주문 내역 처리 속도가 느려지고 있어, 주간 보고서 생성에 지연 발생함  
- 이에 따라 기존 범위에 추가로 △실시간 재고 연동 기능 △자동 주문 내역 정리 프로세스 △고객별 주문 분석 대시보드 포함 필요함  

3. 주요 결과  
- 개편 범위는 다음과 같이 확장됨:  
  | 구분 | 현행 | 조정안 |  
  |------|------|--------|  
  | 재고 연동 | 일일 갱신 | 실시간 연동 |  
  | 주문 처리 | 수동 처리 | 자동 처리(3초 이내) |  
  | 보고서 생성 | 주간 1회 수동 생성 | 주간 3회 자동 생성 |  
- 단계별 일정은 아래와 같이 재조정됨:  
  - 1단계 (3월 1일~3월 15일): 요구사항 정리 및 설계 완료됨  
  - 2단계 (3월 16일~4월 5일): 개발 및 테스트 완료됨  
  - 3단계 (4월 6일~4월 15일): 사전 운영 및 교육 실시됨  
  - 4단계 (4월 16일): 정식 운영 시작됨  

4. 문제점  
- 일부 기능에 대한 사용자 인터페이스 개선 필요함이 확인됨  
- 영업지원팀은 새로운 보고서 형식에 익숙하지 않아 교육 시간 추가 필요함  

5. 검토 의견  
- 개선된 시스템은 생산관리팀의 오류율 감소와 영업지원팀의 업무 효율성 향상에 긍정적 영향을 줌  
- 기존 일정보다 최소 10일 지연될 수 있으나, 품질 저하 없이 안정적인 전환 가능함  

6. 향후 조치  
- IT기획팀은 3월 초까지 최종 설계안을 공유하고, 관련 부서 담당자들 대상으로 설명 회의 실시함  
- 운영지원부는 시스템 전환 전 테스트 환경에서의 검증 완료함  
- 인사관리팀은 교육 일정을 조율하여, 모든 부서 담당자가 원활한 전환 가능하도록 지원함
