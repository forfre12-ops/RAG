회계-2025-3826 / 회계팀장, 재무팀장, 감사·내부통제팀 / 회계팀, 김지영 / 2025-05-20  

1. 검토 배경  
- 제품원가 산출을 위한 원가분석 자료가 정상적으로 완료되지 않음  
- 2025년 1분기 기준 품목별 단가현황과 부품단가표의 일관성 부족으로 인해 재정 집행에 차질 발생함  
- 원가 산출 시점이 지연되면서 3월 말 기준으로 최종 마진율 산출이 보류됨  
- 업무 협조 부서에서 제출한 거래단가표의 일부 항목에서 가격 조정이 필요함이 확인됨  
- 부품별 거래단가표에서 모듈 부품(제품 X)의 경우 공급사 변경 이후 단가 조정이 미흡하게 반영됨. 기존 공급사 기준 단가는 1,200원으로, 변경 후 공급사 기준은 1,350원으로 12.5% 상승함. 이로 인해 원가 증가에 따른 마진율 저하 우려 발생함.  
- 현재까지 산출된 마진율은 실제 판매 실적과 일치하지 않으며, 이는 단가 조정 미흡으로 인한 오산출 가능성 있음.  
- 회계팀은 원가분석 시 기존 공급사 단가를 기준으로 산출했으나, 재무팀은 변경 후 단가를 반영함. 이로 인해 품목별 차이 발생.  

2. 검토 내용  
- 재무팀은 원가분석에서 직접 원가를 산출하는 방식으로 진행함  
- 회계팀은 부품별 거래단가표를 기반으로 한 정산 기준을 적용함  
- 각 품목별로 판매단가와의 차이를 확인하는 과정에서 불일치 발생함  
- 감사·내부통제팀은 원가 집계 시 사용된 데이터의 신뢰성에 대해 검토 필요함을 제안함  
- 감사·내부통제팀은 공급사 변경 시점이 2025년 3월 15일로 명확히 기재되어 있으나, 이에 따른 단가 반영 기한이 불분명함. 이로 인해 산출 시점 차이 발생 가능함.  
- 회계팀은 4월부터 변경된 공급사 단가를 반영하지 않아 오산출 발생 가능성 있음.  
- 재무팀은 실제 판매 실적 기반으로 산출해야 하나, 현재까지는 예비 산출만 수행됨.  

3. 주요 결과  
- 3월 기준 품목 A의 경우 판매단가 12,800원, 원가 11,500원으로 마진율 10.1% 산출됨  
- 품목 B는 판매단가 18,400원, 원가 17,200원으로 마진율 6.5%로 집계됨  
- 품목 C는 판매단가 9,600원, 원고 9,900원으로 마진율 -3.1%로 손실 발생함  
- 부품단가표에 따르면 모듈 부품(제품 X)의 경우 공급사 변경 후 단가 조정 필요함  
- 품목 C는 모듈 부품(제품 X)을 사용하며, 이 부품의 공급사 변경 후 단가는 1,350원으로 증가함. 이로 인해 원가 증가는 물론, 실제 판매량 대비 비용 증가율이 높아짐.  
- 실제 판매 실적 기준으로 재산출 시 마진율은 -4.8%로 하락할 전망임.  

4. 문제점  
- 회계팀은 공급사 변경 전 단가를 기준으로 산출한 반면, 재무팀은 변경 후 단가를 반영함  
- 감사·내부통제팀은 데이터의 일관성을 위해 기존 공급사 단가와 조정된 단가를 비교해야 한다고 판단함  
- 업무 협조 부서는 원인을 설명하지 않은 채 단가 조정만 요청함  
- 공급사 변경 이후 단가는 정산 주기와 맞춰야 하나, 현재까지는 정기적 정산 주기와 연계되지 않음.  
- 감사·내부통제팀은 데이터 일관성 검토를 위해 각 부서의 자료를 별도로 보관하고 있으나, 이를 통합 관리할 시스템 미비함.  

5. 검토 의견  
- 회계팀은 원가분석 시 사용된 공급사 정보의 정확성을 재확인 필요함  
- 재무팀은 마진율 계산 시 실제 판매 실적 기반으로 산출해야 함  
- 감사·내부통제팀은 공급사 변경 이후의 단가 조정 기간을 명확히 해야 함  
- 회계팀은 각 품목별로 사용된 공급사 정보를 별도로 명시해야 함. 예: 품목 A는 3월까지는 A사 사용 → 4월부터 B사로 전환됨.  
- 재무팀은 실제 판매량 및 실제 납품일자 기반으로 원가 산출 필요하며, 이를 위해 생산실적 데이터와 연동 필요함.
