생산-2025-0361 / 생산관리팀장, 생산기술팀장, 품질보증팀장 / 생산관리팀 김지영 / 2025-11-03  

1. 현상  
- 10월 중순부터 제품 A의 생산량이 일주일 기준 12,500개에서 11,300개로 감소함.  
- 이 기간 동안 제품 검사 결과, 품질 기준에 미달된 불량률이 4.8%로 전월 대비 1.2%p 상승함.  
- 생산기술팀은 생산 라인의 기계적 오차가 발생했으나, 이를 조기에 인지하지 못함.  
- 검사 부서는 제품검사 기준서의 일부 항목이 개정된 이후에도 기존 기준으로 검사를 진행함.  

2. 원인 분석  
- 생산기술팀은 10월 15일에 라인의 자동 조정 장치에서 오차 발생을 확인했으나, 보고 체계 미흡으로 인해 지연됨.  
- 품질보증팀은 10월 18일에 제품검사 기준서 개정 안내를 수신했으나, 담당자가 업무 중복으로 인해 확인 미흡함.  
- 이로 인해 10월 20일부터 25일까지는 불량률이 지속적으로 증가하며 고객 불만 발생함.  
- 추가적으로 불량 유형 중 '표면 흠집'과 '치수 오차'가 주요 원인으로 확인됨.  

3. 개선 대책  
- 생산기술팀은 모든 라인에 실시간 모니터링 시스템을 도입하고, 오차 발생 시 즉시 알림이 가도록 설정함.  
- 품질보증팀은 검사 기준서 변경 시 각 담당자에게 이메일과 함께 알림을 병행하여 확인 완료를 유도함.  
- 불량개선 회의록에 따르면, 각 부서장이 직접 회의에 참석하고, 개선안을 실행하는 방식으로 전환함.  
- 별도로 불량률이 높은 제품에 대해서는 주간 단위로 자체 점검을 실시하도록 지침을 마련함.  

4. 실행 결과  
- 11월 1주차부터는 생산량이 12,800개로 회복되었으며, 불량률은 3.1%로 감소함.  
- 검사 부서는 개정된 기준서를 활용한 검사가 정상적으로 수행됨을 확인함.  
- 생산기술팀은 최근 한 주간 라인 오류 알림을 모두 처리하였으며, 오류 발생률이 전주 대비 73% 감소함.  

5. 표준화 방안  
| 구분 | 현행 | 조정안 |  
|------|------|--------|  
| 검사 주기 | 월 1회 | 주간 점검 + 월별 종합 검사 |  
| 불량 보고 체계 | 이메일 보고 | 시스템 통합 알림 및 담당자 직접 확인 처리 |  
| 기준서 변경 안내 | 메일 전달 | 메일 + 사내 메신저 알림 + 담당자 확인 필드 포함 |  

- 모든 부서에서 공유되는 내부 포털에 개선된 절차를 정리하여 게시하고, 훈련도 실시함.  
- 앞으로는 분기마다 각 부서장이 직접 검토하는 '품질 운영 점검 회의'를 정례화하여 운영 예정임.  

본 보고서는 생산실적 개선과 품질 안정화를 위해 진행된 조치의 결과를 종합한 것으로, 이후에도 지속적인 모니터링과 개선 노력이 필요함.
