총무-2025-3972 / 총무팀 / 경영지원부서 / 총무팀 김현우 / 2025-11-20

1. 분석 목적  
- 최근 보안 시스템의 개선 요구가 지속적으로 발생함에 따라 기존 시스템의 취약점과 개선 필요성을 파악하고자 함  
- 내부 보안 사고 예방을 위한 시스템 기반 개선 방향 설정 필요함  

2. 분석 방법  
- 보안 시스템 운영 기록(2024년 1월 ~ 2025년 10월)을 기반으로 접근 기록, 인증 실패 이력, 시스템 다운 타임 분석 실시  
- 외부 감사 업체와 협업하여 실시간 모니터링 도구 및 인증 방식 검토 수행  
- 보안 취약점 점검 도구를 활용한 자동 검사 및 위험도 평가 수행  

3. 분석 결과  
- 전체 접근 기록 중 14.7%가 비정상적인 시간대(새벽 03:00~05:00)에 발생함  
- 인증 실패 이력 중 68%는 비밀번호 재시도 5회 초과로, 이 중 43%는 브라우저 별로 다름  
- 시스템 다운 타임은 총 3회 발생했으며, 이 중 2회는 전기 공급 불안정으로 인한 것으로 확인됨  
- 최근 6개월 동안의 감사 결과, 두 가지 보안 정책 미적용 사례 적발됨  

| 구분 | 현행 | 조정안 |  
|------|------|--------|  
| 인증 방식 | 단일 비밀번호 | 다단계 인증 도입 예정 |  
| 접근 제한 시간 | 24시간 | 근무시간(오전 9시~오후 6시)으로 제한 예정 |  
| 감시 주기 | 실시간 아님 | 실시간 모니터링 도입 예정 |  

4. 해석  
- 기존 보안 시스템은 사용자 편의를 우선시한 설계로, 취약점이 노출된 환경이 존재함  
- 특히 비정상적인 접근 시간에 대한 제한이 없었으며, 이로 인해 내부 정보 유출 리스크 발생 가능성 있음  
- 다단계 인증 미적용으로 인해 타인의 계정 정보를 활용한 위장 접근 가능성 존재함  

5. 활용 방안  
- 내부 보안 정책 개정을 위한 안내문 작성 및 교육 일정 확보 예정  
- 다단계 인증 시스템 도입을 위한 예산 승인 요청서 제출 예정  
- 감시 시스템을 통한 실시간 모니터링 체계 확립 및 주간 리포트 작성 예정
