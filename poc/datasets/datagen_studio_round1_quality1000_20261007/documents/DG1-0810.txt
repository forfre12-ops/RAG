총무-2025-1104 / 총무팀, 경영지원팀 / 총무팀 / 2025-08-11

1. 검토 배경  
- 총무팀은 최근 보안 시스템 업데이트에 따라 기존 인증서 기반 접근 제어 체계가 취약해질 수 있다는 점을 확인함.  
- 이에 따라 경영지원 담당자 A는 내부 시스템 접근 로그 분석을 통해 비정상적인 접속 시도가 3월부터 지속적으로 발생하고 있음을 확인함.  
- 동시에 업무 협조 부서인 기술지원팀은 보안 인프라의 버전 차이로 인해 일부 시스템에서 인증 오류가 반복 발생함을 보고함.  

2. 검토 내용  
- 총무팀은 보안 시스템 정보 중 3개의 주요 구성 요소를 점검함: 인증서 만료 일자, 접근 제어 목록, 로그 저장 기간.  
- 경영지원 담당자 A는 지난 6개월 동안의 접근 로그 중 7건의 비정상적인 IP 주소 기록을 분석함.  
- 기술지원팀은 보안 시스템의 버전이 2.1.3으로, 최신 안정성 패치가 적용되지 않은 상태임을 확인함.  

3. 주요 결과  
- 총무팀은 인증서 중 2개가 2025년 8월 말 만료 예정임을 확인함.  
- 경영지원 담당자 A는 비정상 접속이 대부분 외부 IP에서 발생했으며, 이 중 3건은 중국 지역에서 발생한 것으로 파악됨.  
- 기술지원팀은 현재 사용 중인 보안 소프트웨어가 최신 업데이트를 지원하지 않아 취약점이 존재함을 확인함.  

4. 문제점  
- 보안 시스템 정보 간 불일치로 인해 접근 제어 정책이 제대로 적용되지 않음.  
- 관리자 권한이 있는 사용자들이 별도의 승인 없이 보안 설정 변경 가능하여 위험함.  
- 로그 저장 기간이 최소 90일로 설정되어 있으나, 실제는 60일까지만 유지됨.  

5. 검토 의견  
- 현재 보안 시스템 정보 간 일관성 부족으로 인해 내부 정보 유출 가능성이 높음.  
- 별도의 관리 체계 없이 각 부서에서 개별적으로 정보를 관리하고 있어 통합 관리가 불가능함.  
- 업데이트 미완료로 인한 취약점에 대한 조치가 시급하며, 이를 위한 보완 절차 필요함.  

6. 향후 조치  
- 모든 보안 시스템 정보에 대해 중앙에서 일괄 관리할 수 있는 시스템 도입 예정임.  
- 다음 주 월요일까지 인증서 갱신 작업 완료하고, 만료일 기준 60일 전부터 자동 알림 설정함.  
- 기술지원팀은 내부 보안 업데이트 작업을 오는 8월 18일까지 완료하고, 이후 정기 점검 실시 예정임.
