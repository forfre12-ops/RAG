총무-2025-0919 / 총무팀장 / 경영지원부, 기술지원팀 / 2025-03-18  

1. 인수인계 개요  
- 총무팀 김지영 대리가 2025년 3월 31일자로 퇴사함에 따라 보안시스템 정보 관리 업무를 신규 담당자인 박민수 과장에게 인수인계함  
- 기존 보안 시스템은 3개의 주요 서버와 2개의 감시 센서를 기반으로 운영되며, 접근 권한은 총 17명의 승인된 직원에게만 부여됨  
- 보안 시스템 운영 기간 동안 발생한 주요 이슈는 총 4건이며, 이 중 3건은 내부 시스템 오류로 인한 것으로 확인됨  

2. 담당 업무  
- 보안 시스템의 사용자 권한 설정 및 변경 기록 관리함  
- 주간 보안 감시 로그 분석 및 이상 징후 탐지 후 조치 내역 보고함  
- 외부 감사 대응을 위한 보안 시스템 구성도 및 접근 로그 파일 제출 준비함  

3. 진행 중 사안  
- 2025년 3월 말까지 진행된 보안 시스템 업데이트 작업에서, 서버 A의 인증 프로토콜이 비활성화됨에 따라 보안 취약점이 발견됨  
- 해당 문제는 즉각적으로 기술지원팀과 협력하여 보완 조치를 완료하였으나, 향후 리스크 대비를 위해 정기적인 점검 주기가 필요함  
- 현재 보안 감시 시스템의 알림 전송 방식이 이메일 중심으로 구성되어 있어, 모바일 알림으로의 전환 필요성이 제기됨  

4. 유의사항  
- 보안 시스템 정보는 내부 업무용으로만 사용되며, 외부 노출 금지됨  
- 신규 담당자는 기존 정보를 확인한 후, 업무 시작 전에 반드시 경영지원부와의 검토 회의를 실시함  
- 기존 담당자는 인수인계 완료 후 7일간 상담 지원 가능하며, 이후에는 업무 관련 문의에 대해 직접 응답 불가함  

5. 관련 자료  
| 구분 | 현행 | 조정안 |  
|------|------|--------|  
| 접근 권한 수 | 17명 | 15명(보안 강화를 위해 2명 감축) |  
| 모니터링 주기 | 주간 | 월간 → 주간으로 전환 예정 |  
| 알림 수단 | 이메일 | 이메일 + 모바일 앱 알림 병행 예정 |  

보안 시스템 운영에 있어 신뢰성과 안정성을 확보하기 위해, 인수인계 이후에도 지속적인 점검과 개선 작업이 필요함. 특히 최근 발생한 인증 프로토콜 문제와 같은 취약점은 정기적인 검토 없이 반복될 수 있으므로, 다음 달부터는 분기별로 외부 전문가 자문을 받아보완 계획을 수립함.  
업무 인수인계 이후에도 기존 업무에 대한 연락처는 경영지원부에 공유되며, 신규 담당자는 이를 참고하여 업무 수행함.
