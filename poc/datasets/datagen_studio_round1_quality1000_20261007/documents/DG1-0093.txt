1. 현상  
- 2025년 4월 중순부터 고객센터로 접수된 '배송 지연' 문의가 급증함  
- 이 중 78%가 대량 주문 시스템을 이용한 거래처 고객으로, 대부분 4월 14일 이후에 집중 발생함  
- 특히 4월 17일~19일 기간 동안 하루 평균 32건의 문의 발생으로 기존 대비 3.5배 증가함  

2. 원인 분석  
- 배송 시스템 내 재고 부족 알림 로직이 지연되면서 실제 재고 소진 후에도 주문 처리가 완료됨  
- 주문 시스템은 재고 확인 후 주문 완료를 처리하지만, 물류 시스템과의 연동 지연으로 인해 배송 일정이 제대로 반영되지 않음  
- 이로 인해 고객은 주문 완료 후에도 배송 예정일이 지나도 상품 수령 불가 상태 발생함  
- 내부 테스트 결과, 재고 부족 시 알림이 지연되는 문제는 3월 말부터 존재했으나, 감시되지 않음  

3. 개선 대책  
- 배송 지연 알림을 실시간으로 전달하기 위해 물류 시스템과의 연동 주기를 초당 1회로 조정함  
- 주문 완료 직후 재고 소진 여부를 자동으로 확인하는 검증 로직을 추가하여 배송 불가 안내 자동 발송 필요함  
- 고객에게는 '재고 소진'으로 인한 배송 지연 사유를 사전 안내하고, 보상 정책을 적용할 예정임  

4. 실행 결과  
- 개선 조치 이후 5월 1일부터는 동일한 유형의 문의가 발생하지 않음  
- 기존에 발생하던 배송 지연 문의는 85% 감소했으며, 이는 시스템 개선 효과로 판단됨  
- 향후에는 실시간 재고 확인을 위한 모니터링 도구를 도입하여 지속적 관리 예정임  

5. 표준화 방안  
| 항목 | 현행 | 조정안 |  
|------|------|--------|  
| 재고 확인 주기 | 5분 간격 | 실시간(초당 1회) |  
| 배송 지연 알림 시점 | 주문 완료 후 | 재고 소진 확인 후 즉시 |  
| 고객 안내 메시지 | 일반 안내 포함 | 구체적 사유 포함 및 보상 안내 포함 |  

- 이번 사례를 기반으로 고객센터 상담 가이드라인을 개정하여, 동일한 유형의 문의에 대해 보다 빠르게 응답 가능하도록 함  
- 품질관리팀은 월 1회 이상 데이터 기반 모니터링을 실시하여 조기 탐지 체계 강화 필요함
