품질-2025-1411 / 품질관리팀장, 생산기술팀장, 영업2팀장 / 품질관리팀 / 김민수 / 2025-09-02  

1. 현상  
- 2025년 8월 중순 기준으로 로트 번호 25-08-101에서만 부식이 발생한 제품이 전체 출하 품목 중 약 3.7%에 해당하는 1,243개가 적발됨  
- 이 중 68%는 외관상 녹이 슬었으며, 내부 검사 시 금속성 분리가 확인됨  
- 영업팀에 따르면 A거래처에서 불량 제품에 대한 반품 요청이 접수되었으며, 품질관리팀은 즉시 조치를 시행함  

2. 원인 분석  
- 생산기술팀은 해당 로트의 도금 공정에서 전기분해 용액 온도가 설계 기준보다 3도 높았으며, 이로 인해 도금층이 미세하게 흐려졌음을 확인함  
- 자재 담당자에 따르면 해당 로트의 아연 합금 원재료 공급사에서 최근 변경된 첨가제가 포함된 것으로 확인됨  
- 품질관리팀은 도금 후 세척 공정에서 물세척 시간이 설계 대비 15초 단축된 상태였으며, 이로 인해 잔여 화학물질이 도금층에 남아 있음  
- 별도로 진행된 실험에서는 기존 공정 대비 온도와 세척 시간을 조정한 경우 부식 발생률이 97% 감소함  

3. 개선 대책  
- 도금 공정 시 온도를 45도에서 42도로 조정하고, 세척 시간을 최소 30초 이상으로 확보함  
- 아연 합금 원재료에 대해 공급사와의 협의를 통해 첨가제 성분을 검증하고, 변경된 사양에 대해 재인증 절차를 시행함  
- 품질검사 기준을 강화하여 도금 후 검사 시 '세척 후 잔류 물질 검출 여부' 항목을 필수 항목으로 추가함  
- 생산기술팀은 다음 로트부터는 실시간 모니터링 시스템을 운영하여 공정 파라미터를 자동 기록함  

4. 실행 결과 및 조치 일정  
- 2025년 9월 1일부터 시행된 개선 조치 이후 로트 25-08-103에서의 불량률은 약 0.3%로 감소함  
- 추가적으로 현재까지 총 3개의 로트에서 재검사를 실시했으며, 이 중에서 불량 발생 없음 확인됨  
- 품질관리팀은 다음 달 5일까지 모든 로트에 대한 검증 결과를 정리하여 관련 부서에 전달 예정임  

5. 표준화 방안  
| 구분 | 현행 | 조정안 |  
|------|------|--------|  
| 도금 온도 | 45도 | 42도 |  
| 세척 시간 | 15초 | 최소 30초 이상 |  
| 검사 항목 | 도금 두께만 측정 | 잔류 화학물질 검출 포함 |  

- 모든 공정은 현재 수정된 운영 지침서에 따라 시행되며, 내년 상반기까지는 해당 지침서를 기반으로 교육 프로그램을 운영할 예정임  
- 생산기술팀과 품질관리팀은 월 1회 합동 점검을 통해 지속적인 개선 여부를 검토함
