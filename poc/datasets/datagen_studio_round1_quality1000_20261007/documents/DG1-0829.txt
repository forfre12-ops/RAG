이사회 정보 관리 관련 협의 회의 / 2025년 9월 22일 오전 10시 / 회의실 B / 총무팀장, 경영지원부서장, 업무협조팀장, 감사·내부통제팀장 / 총무팀 김민수  

- 이사회 회의록 보관 및 관리 방안에 대해 논의함.  
- 이사회 회의록은 현재 총무팀이 전담하여 보관하고 있으나, 일부 부서에서는 접근 제한이 필요하다고 판단함.  
- 감사·내부통제팀은 이사회 자료에 대한 접근을 엄격히 통제해야 한다고 지적함.  
- 경영지원부서는 회의록이 필요 시 신속히 제공될 수 있도록 유연한 접근 체계를 마련해야 한다고 주장함.  
- 업무협조팀은 이사회 자료가 포함된 문서가 내부 업무와 연계되어 있어야 한다며, 일부 정보는 공유가 불가피하다고 판단함.  

- 총무팀은 현재까지 이사회 회의록을 엄격한 기준으로 관리해 왔으나, 이를 기반으로 한 정보 공유가 원활하지 않음.  
- 감사·내부통제팀은 이사회 자료의 무단 공유가 발생할 경우 분쟁으로 이어질 수 있다고 판단하여, 접근 권한을 최소한으로 제한해야 한다고 주장함.  
- 경영지원부서는 업무 효율성을 위해 정기적인 회의록 갱신이 필요하다고 지적하며, 일부는 실시간 공유가 가능해야 한다고 주장함.  
- 업무협조팀은 이사회 자료와 관련된 업무 처리 시 빠른 결정이 필요하므로, 특정 기간 동안은 제한적 공유를 허용해야 한다고 제안함.  

- 각 부서별 입장 정리  
  - 총무팀: 보안 강화를 위해 접근 제한 필요, 현재 보관 체계 유지 필요  
  - 감사·내부통제팀: 정보 유출 리스크로 인해 최소한의 접근 권한 부여 필요  
  - 경영지원부서: 업무 효율성과 관련해 실시간 정보 제공 필요, 공유 확대 필요  
  - 업무협조팀: 업무 연계를 위해 제한적 공유 허용 필요, 단기적 접근 허용 고려  

- 현재까지 합의된 결정사항 없음. 각 부서 간 입장 차이가 심하여 추가 논의 필요함.  
- 이사회 회의록에 대한 접근 권한 부여 방안에 대해 추가 검토 기간을 두기로 함.  
- 각 부서장과 협의하여 구체적인 접근 기준을 마련하고, 다음 주 월요일까지 안건을 제출하기로 함.  

- 이후 조치 및 기한 명시  
  - 총무팀: 감사·내부통제팀과 협의하여 보안 기준 재정비 및 문서 목록 정리 완료 예정 (2025년 10월 3일)  
  - 경영지원부서: 업무 효율성과 관련된 정보 공유 방안 마련 (2025년 10월 1일)  
  - 업무협조팀: 관련 업무 처리 시 필요한 정보 범위 파악 및 제안서 작성 (2025년 10월 2일)  
  - 감사·내부통제팀: 리스크 평가 기준 마련 및 제출 예정 (2025년 10월 3일)  

- 모든 부서는 다음 주 화요일 오후 2시에 다시 회의를 개최하며, 각 부서에서 제출한 안건을 기반으로 최종 방안 도출 예정.  
- 이후 조치는 각 부서장 승인 후 총무팀에서 통합하여 시행 예정.  

- 총무팀은 현재 보관하고 있는 이사회 회의록 중 최근 3년치(2023~2025년)에 해당하는 회의록 약 47건을 대상으로 접근 권한 분류 검토를 실시함. 이 중 감사·내부통제팀은 무단 공유 가능성이 있는 데이터를 포함해도 무단으로 접근할 수 없도록 하되, 경영지원부서와 업무협조팀은 해당 문서 중 정기보고서 및 결산안과 관련된 부분에 대해서만 접근 허용 예정임.  
- 감사·내부통제팀은 최근 1년간 내부 감사 시스템에서 발생한 정보 유출 사례(총 3건) 중 이사회 관련 문서가 포함된 사례가 있어, 이에 따라 접근 제한이 필수적이라고 판단함. 해당 사례는 비밀 유지 계약 위반이었으며, 금번 조치에서 이를 반영하기로 함.  
- 경영지원부서는 이사회 자료와 연계된 업무 처리 시 평균적으로 회의록 요청 후 평균 3.7시간 소요됨을 확인했으며, 이를 개선하기 위해 실시간 공유 시스템 도입을 검토 중임. 다만, 민감도 높은 내용은 암호화된 포털에서만 제공하기로 함.  
- 업무협조팀은 이사회 자료와 연계된 업무 중 상황별로 가장 빠른 결정이 필요한 경우(예: 분기 리뷰 진행 시점)에 한해 단기적 접근 허용을 제안하며, 해당 기간은 평균 72시간으로 제한 예정임. 이는 실제 업무 처리 속도 개선에 기여할 것으로 판단됨.  

- 이후 조치 및 기한 명시  
  - 총무팀: 감사·내부통제팀과 협의하여 보안 기준 재정비 및 문서 목록 정리 완료 예정 (2025년 10월 3일)  
    → 배경: 최근 발생한 정보 유출 사례를 반영해 보안 강화 필요 지적됨.  
    → 판단 근거: 감사·내부통제팀 산하 리스크 평가 결과, 무단 접근 가능성이 확인됨.  
    → 예상 영향: 정보 유출로 인해 법적 책임 발생 가능성 존재 → 보안 강화 필수.  
    → 담당 부서 입장: 보안 우선 원칙 유지하되, 업무 효율성 저해 없도록 조정 필요.  

  - 경영지원부서: 업무 효율성과 관련된 정보 공유 방안 마련 (2025년 10월 1일)  
    → 배경: 최근 요청 건당 평균 소요 시간이 과도하게 길어짐 (3.7시간).  
    → 판단 근거: 요청 건수 대비 처리 지연 건수 증가 (지난 분기 대비 +18%).  
    → 예상 영향: 업무 지연 → 전체 프로세스 지연 가능성 있음.  
    → 담당 부서 입장: 실시간 공유 체계 도입으로 처리 속도 개선 예상됨.  

  - 업무협조팀: 관련 업무 처리 시 필요한 정보 범위 파악 및 제안서 작성 (2025년 10월 2일)  
    → 배경: 이사회 자료와 연계된 주요 업무 중 빠른 결정이 필요한 경우 발생함.  
    → 판단 근거: 최근 분기 리뷰 시점에서 평균적으로 결정 지연 시간이 약 48시간 발생함.  
    → 예상 영향: 지연 시 전체 프로세스 마감 지연 가능성 있음.  
    → 담당 부서 입장: 단기적 접근 허용을 통해 빠른 의사결정 가능하도록 조치 필요함.  

  - 감사·내부통제팀: 리스크 평가 기준 마련 및 제출 예정 (2025년 10월 3일)  
    → 배경: 최근 내부 감사 결과에서 이사회 관련 정보 유출 사례 발생함.  
    → 판단 근거: 지난해 전체 감사에서 약 6%가 이사회 관련 데이터 노출로 인해 리스크 판정됨.  
    → 예상 영향: 무단 공유 발생 시 법적 책임 발생 가능성 있음.  
    → 담당 부서 입장: 최소 권한 부여 원칙 고수하며 리스크 최소화 방향 추진 필요함.

- 모든 부서는 다음 주 화요일 오후 2시에 다시 회의를 개최하며, 각 부서에서 제출한 안건을 기반으로 최종 방안 도출 예정.  
- 이후 조치는 각 부서장 승인 후 총무팀에서 통합하여 시행 예정.
