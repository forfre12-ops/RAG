IT-2025-3278 / 모든 부서 / IT기획팀, 운영지원팀, 영업기획팀 / IT기획팀 김지영 / 2025-01-28

1. 보고 개요  
- 차기 시스템 개편 업무에 대한 현업 요구사항이 추가됨에 따라 기존 범위를 재조정함  
- 주요 요구사항은 영업 담당자 15명의 일일 업무 기록 자동화 및 리포트 생성 시간 단축임  

2. 진행 현황  
- 기존 계획된 범위는 고객 정보 관리, 주문 처리 자동화, 보고서 생성 시스템 포함됨  
- 현업 요청에 따라 업무 흐름 기반 자동 기록 시스템 도입 필요함 (예: 영업 방문 후 30초 내 자동 기록)  
- 테스트 환경에서의 검증 결과, 현재 평균 12분 소요되던 보고서 생성 시간이 4분으로 단축됨  

3. 특이사항  
- 업무 자동화 범위 확장으로 인해 시스템 연동 부담 증가 필요함 (예: CRM 시스템과의 실시간 연계)  
- 기존 시스템과의 호환성 문제로 인해 개발 일정 조정 필요함  
- 아래 표와 같이 범위 조정이 완료됨  

| 구분 | 현행 | 조정안 |  
|------|------|--------|  
| 자동 기록 포함 항목 | 주문 정보, 날짜 | 영업 방문 일정, 고객 응답 내용 포함 |  
| 리포트 생성 빈도 | 주간 | 근무일 기준 당일 자동 생성 예정 |  
| 연계 시스템 | CRM만 연동 | CRM + 전자결재 + 이메일 알림까지 확장 예정 |  

4. 조치 계획  
- 개편 범위 확장에 따라 개발 팀과 협의하여 3월 15일까지 상세 설계 완료함  
- 현업 부서 대표 3명과 함께 3월 10일 회의 실시하여 사용자 테스트 환경 검증 예정  
- 필요 자원은 서버 확장 2단계, 보안 인증서 재발급 1회, 사용자 교육용 매뉴얼 5종 제작 완료함  
- 예상 효과로는 영업 업무 효율성 35% 향상 및 리포트 작성 시간 감소 70% 예상됨
