영업-2025-3007 / 영업본부 전체 / 영업기획팀, 마케팅팀 / 2025-10-27  

1. 검토 대상  
- 홍보자료, 기업소개 자료, 제품소개 자료를 포함한 전체 홍보 콘텐츠의 포괄적 검토 필요함  
- 2025년 4분기 홍보 캠페인에 활용될 콘텐츠로, 전사적으로 사용 가능한 공식 자료임이 확인됨  

2. 주요 조항 검토  
- 홍보자료에는 기존 고객사례 13건이 포함되나, 이 중 3건은 개인정보가 포함되어 있어 수정 필요함  
- 제품소개 자료의 사양 정보는 현재 버전에서 3개 항목이 미확인 상태이며, 기술 지원팀과의 협의 필요함  
- 기업소개 자료에는 2023년 기준 실적 데이터가 포함되어 있으나, 2024년 기준으로 갱신된 내용이 없어 업데이트 예정임  

3. 위험 요소  
- 고객사례 중 일부는 공개된 후기와 동일한 내용으로, 동의 없이 사용된 것으로 확인됨  
- 제품소개 자료의 시각화된 그래프는 원천 정보가 명시되지 않아 신뢰성 저하 가능성 있음  
- 홍보자료의 배포 시스템은 현재 내부 서버에만 저장되어 있어, 외부 공유 시 접근 제한 불가능함  

4. 수정 제안  
- 고객사례 3건은 실제 이름 대신 ‘고객 A’, ‘고객 B’ 등으로 가명 처리하고, 동의서 별도로 보관함  
- 제품소개 자료에 대해는 기술지원팀과 협의하여 미확인 사양 항목을 ‘확인 중’으로 표기하고, 11월 10일까지 보완 예정임  
- 기업소개 자료는 2024년 실적을 반영하여 갱신하고, 원천 정보를 링크 형식으로 추가함  
- 홍보자료 배포 시스템은 클라우드 기반으로 전환하여 전사적 접근 가능하게 함  

5. 결론  
- 홍보자료는 수정 후 11월 5일까지 완성하여 영업팀 전체에 배포 예정임  
- 모든 자료는 외부 공유 시에도 문제없도록 내부 검토 절차를 강화하고, 마케팅팀 주관으로 정기 검토 실시함
