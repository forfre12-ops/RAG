1. 조사 개요  
- 최근 영업팀에서 판매고객 관리 업무를 수행하면서 발생한 거래처 정보의 중복 및 누락 문제로 인해 정기 보고서 작성에 차질이 발생함  
- 기존 거래처 목록 기준으로 산출된 판매 실적 집계가 실제 납품처와 일치하지 않아 재조정 필요함  
- 영업기획팀은 이를 개선하기 위해 지난 3개월 간의 거래 내역과 고객 데이터 명부를 기반으로 조사를 실시함  
- 배경: 영업 담당자가 수기로 입력한 정보가 중복되어 등록되며, 특히 대량의 거래처를 보유한 팀에서 발생함. 현재까지 확인된 중복 거래처 17개는 평균 1.5배 이상의 과중한 데이터로 이어짐. 판단 근거로는 영업기획팀이 분석한 내역에 따르면, 중복 등록된 거래처 중 12개는 같은 주소와 대표자 정보를 공유함. 예상 영향: 중복된 정보는 실적 집계 오류로 이어져 분기별 성과 평가에 부정적인 영향을 미침. 담당 부서는 영업팀이 직접 검증한 데이터 기준으로 처리해야 함.

2. 조사 방법  
- 영업팀에서 제공한 고객 명단과 거래처 연락처를 기반으로 고객데이터 명부를 정리함  
- 납품처 정보와 판매금액을 연계하여 실제 납품이 이루어진 거래처에 대한 기록을 추적함  
- 감사부서의 요청으로 내부통제 절차 검토를 위해 영업기획팀이 보유한 데이터와 운영지원팀의 관리 시스템을 비교 검증함  
- 배경: 영업 담당자가 고객 정보를 입력할 때 동일한 회사명을 다른 형태로 입력하는 사례가 빈번함 (예: 주식회사 vs 주식회사). 구체적인 수치로는 17개의 중복 등록 중 6개는 회사명 차이만 존재하며, 실제 동일한 납품처임이 확인됨. 판단 근거: 동일한 사업자등록번호나 주소 기준으로 정렬 시 중복 여부 확인 가능. 예상 영향: 중복된 데이터는 정산 업무에서 오류 유발 및 세금 신고 오류로 이어질 수 있음. 담당 부서는 영업기획팀이 정기적으로 정제 작업 수행 필요.

3. 조사 결과  
- 전체 거래처 124개 중 17개에 대해 중복 등록 및 오류 수정 필요함 (예: A거래처는 두 번 등록되어 있으나 실제는 동일한 납품처)  
- 영업팀은 지난 분기 기준으로 89개의 고객에 대해 실적을 기록했으나, 실제로 납품이 완료된 거래처는 76개로 확인됨  
- 경쟁사 대비 가격 경쟁력 약화로 인해 일부 고객이 다른 공급사로 전환된 사례 발견됨  
- 주요 거래처 중 3곳은 연락처 정보가 정확하지 않아 최근 6개월 내 회신 없음  
- 배경: 최근 분기 기준으로 경쟁사 A사는 평균 12% 할인을 제공하며, 우리사의 경우 최대 5% 할인만 적용 가능. 구체적인 수치로는 지난 분기 경쟁사 대비 우리사 판매 금액 감소율이 18%로 나타남. 판단 근거: 경쟁사 가격 조사를 통해 산출된 결과이며, 이는 실제 납품 건수 감소와 직결됨. 예상 영향: 지속적인 가격 경쟁력 약화 시 고객 이탈 확률 증가 예상됨. 담당 부서는 영업팀이 가격 조정 전략 수립 필요.

4. 시사점  
- 영업기획팀은 영업 담당자들이 직접 고객 데이터를 입력하되, 최소한의 검증 절차를 통한 데이터 관리 필요함  
- 운영지원팀은 현재 시스템 상에서 중복된 고객 코드가 발생하지 않도록 정책 개선 필요함  
- 감사부서는 정기적인 데이터 정합성 검토를 위해 분기별로 별도의 점검 예정  
- 배경: 영업 담당자들이 입력하는 정보에 대한 검증 절차가 미흡하여 오류 발생 가능성 높음. 구체적인 수치로는 지난 분기 기준으로 입력 오류가 23건 발생했으며, 이중 65%가 중복 등록 또는 잘못된 연락처 포함됨. 판단 근거: 감사부서가 수행한 내부 검토 결과, 검증 절차 미수행 시 오류 발생률이 약 3배 증가함. 예상 영향: 잘못된 데이터는 후속 업무 처리 지연 및 계약 불이행으로 이어질 수 있음. 담당 부서는 운영지원팀이 시스템 개선과 함께 검증 프로세스 도입 필요.

5. 부서별 의견 및 근거  
1) 영업팀  
- '영업 담당자가 직접 고객 정보를 입력하는 것이 가장 신속하고 정확하다고 판단함'  
- '지난 분기부터 일부 고객에 대해는 납품 완료 후 즉시 보고하도록 지시했으나, 일부는 미보고 상태임'  
- 배경: 영업 담당자가 직접 업무 처리 시 빠른 반응 가능하나, 업무 부담 증가로 인해 일부 무시되는 경우 존재. 구체적인 수치로는 지난 분기 보고 미완료 건수가 총 14건으로, 이중 60%는 납품 완료 후 보고 누락됨. 판단 근거: 보고 지연 시 실적 집계에 차질 발생 가능. 예상 영향: 보고 누락은 전체 실적 집계 오류 유발 가능. 담당 부서는 영업기획팀이 보고 마감일 설정 필요.

2) 영업기획팀  
- '현재 시스템은 중복 등록을 막지 못하며, 정기적인 정리가 필요함'  
- '중복된 데이터는 실적 집계 오류로 이어지므로, 월말마다 데이터 정리 작업 필요함'  
- 배경: 현재 시스템은 자동 중복 체크 기능 없음. 지난 분기 기준으로 월간 평균 4건의 중복 등록 발생함. 판단 근거: 중복된 데이터는 정산 업무에서 오류 유발 가능하며, 감사 시에도 문제가 될 수 있음. 예상 영향: 지속적인 오류 발생 시 내부통제 약화 요인으로 간주됨. 담당 부서는 운영지원팀과 협력하여 자동 체크 도입 필요.

3) 운영지원팀  
- '고객 코드를 자동 생성하는 방식으로 변경하면 중복 방지 가능할 것임'  
- '현재는 수동 입력만 가능하나, 시스템 개선이 필요함'  
- 배경: 현재 고객 코드 생성은 직원 수동 입력 방식으로 인해 오류 발생 빈도 높음. 구체적인 수치로는 지난 분기 기준 자동 생성 없이 인위적으로 코드 생성 시 오류율이 약 8% 발생함. 판단 근거: 자동 생성 시스템 도입 시 오류율 약 0.5% 하락 예상됨. 예상 영향: 자동 생성 시스템 도입으로 인해 전체 데이터 품질 향상 기대됨. 담당 부서는 감사부서와 협력하여 안정성 검증 필요.

4) 감사부서  
- '내부통제 절차상 정기적인 검증이 이뤄져야 하며, 오류 발생 시 책임 소재 파악이 어려움'  
- '영업 담당자 개인의 업무 기준보다는 공통 기준 마련 필요함'  
- 배경: 최근 분기 기준으로 검증 미실시로 인해 문제 발생 가능성 높음. 구체적인 수치로는 지난 분기 내부검토에서 발견된 오류 건수 총 9건 발생함. 판단 근거: 공통 기준 없이는 책임 소재 불명확할 수 있음. 예상 영향: 책임 소재 불명확은 조직 문화 저하 유도 가능. 담당 부서는 영업기획팀과 협력하여 공통 가이드라인 마련 필요.
