총무-2025-1296 / 임원진 전원 / 총무팀, 경영지원팀, 감사·내부통제팀 / 2025-01-30  

1. 검토 배경  
- 지난 1월 초부터 진행된 임원회의는 기존 회의 일정과 겹치며 연기되었으며, 이로 인해 회의록 작성 시기가 지연됨  
- 회의록은 기존의 사전 승인 체계를 기반으로 처리되었으나, 담당자들 간 회의록의 공개 범위에 대해 의견 차이 발생  
- 총무팀은 모든 임원에게 공유 필요성을 주장하지만, 감사·내부통제팀은 내부 정보 보호 차원에서 제한적인 접근 필요성 강조  
- 경영지원팀은 업무 효율성 측면에서 일부는 공유하되, 핵심 내용은 승인된 인원에 한해 열람하도록 조정 필요성 제기  
- 배경: 2024년 12월 13일 회의에서 도입된 인사위원회 운영 개선안은 총 14개 부서에 영향을 미치며, 이 중 7개 부서는 관련 업무를 수행하는 직원 32명이 직접 참여함으로써 정보 접근이 필수적임.  
- 판단 근거: 감사·내부통제팀은 최근 3년간 내부 정보 유출 사례 중 4건이 전자 문서 시스템을 통한 비승인 접근에서 발생했으며, 이 중 60%는 부서장 승인 없이 접근된 것으로 확인됨.  
- 예상 영향: 정보 접근을 일괄적으로 제한할 경우, 관련 업무를 수행하는 담당자들이 업무 지연을 경험하며, 특히 인사위원회 운영 개선안과 관련된 부서에서는 업무 지연이 최대 5일까지 발생할 수 있음.  
- 담당 부서 입장: 총무팀은 모든 임원에게 동일하게 공유함으로써 의사소통의 투명성과 책임 소재 명확화를, 감사·내부통제팀은 정보 유출 리스크를 최소화하기 위해 접근 제한을, 경영지원팀은 업무 효율성을 위해 조건부 접근을 각각 요구함.

2. 검토 내용  
- 현재까지 확보된 회의록은 2024년 12월 13일 임원회의 기록 포함하며, 총 8개 항목의 주요 결정안 포함  
- 이 중 3개 항목은 전사적 영향이 큰 정책으로 분류되며, 이에 대한 정보 공유 범위가 논란됨  
- 각 부서는 다음과 같은 쟁점으로 인해 입장 차이를 보임  
  - 총무팀: 모든 임원에게 공유함으로써 원활한 의사소통과 실행 보장 필요함  
  - 감사·내부통제팀: 정보 유출 위험으로 인해 접근 권한을 특정 임원에 한정해야 함  
  - 경영지원팀: 일부는 공유하되, 상세한 내용은 관리자 승인 후 열람 가능하도록 조건부 접근 도입 필요함  
- 세부 내용: 인사위원회 운영 개선안(항목 1)은 전체 직원 587명 중 상위 15%에 해당하는 리더십 역량 평가 대상자에게만 적용되며, 이는 직무 성과와 직결됨.  
- 판단 근거: 해당 안은 인사위원회 산하 평가위원회에서 자체적으로 작성한 평가 기준에 따라 시행되며, 평가 점수는 외부 노출 시 정당하지 않은 편향을 유발할 수 있음.  
- 예상 영향: 평가 결과를 모든 임원에게 열람하게 할 경우, 평가 대상자가 아닌 임원들 사이에서 불필요한 압박이나 편견 형성이 발생할 수 있으며, 이는 조직 문화 저해로 이어질 수 있음.  
- 담당 부서 입장: 감사·내부통제팀은 평가 점수와 관련된 세부 항목은 관련 부서장 및 평가위원만 접근 가능하게 하고, 나머지 요약본만 일반 임원에게 제공해야 한다고 판단함.

3. 주요 결과  
- 현재까지 확보된 회의록은 전자 문서 시스템에 저장되어 있으나, 열람 권한 설정이 미완료됨  
- 관련 부서 간 협의를 통해 다음 표와 같이 접근 권한 기준을 마련함  

| 구분 | 현행 | 조정안 |  
|------|------|--------|  
| 전체 임원 공유 | 예 | 일부 제한적 공유 (관련 부서장 및 평가위원만 복수 가능) |  
| 감사·내부통제 담당자 포함 여부 | 예 | 승인된 사전 권한 부여 필수 (관련 업무 담당자에 한함) |  
| 경영지원 담당자 접근 여부 | 예 | 업무 관련 항목에 한해 제한적 접근 (승인 후) |  

- 조정안 적용 기준: 모든 항목에 대해 관련 부서장 및 감사·내부통제팀장의 공동 승인이 필요하며, 이는 정보 유출 방지를 위한 절차적 보완임.  
- 판단 근거: 최근 실시된 내부 시뮬레이션에서 관리자 승인 없이 접근한 경우 평균 85%가 비밀번호나 계정을 타인과 공유했으며, 이는 정보 보안 위협 요소로 작용함.  
- 예상 영향: 조정안을 적용할 경우 초기에는 권한 요청 과정에서 약간의 지연이 발생할 수 있으나, 장기적으로는 불필요한 정보 노출을 줄여 조직 전체의 신뢰도 제고 가능함.  
- 담당 부서 입장: 총무팀은 권한 요청 절차를 표준화하여 빠른 처리를 지원하고, 감사·내부통제팀은 승인 기준을 명확히 하여 투명성 확보를 요구함.

4. 문제점  
- 회의록 작성 후 승인 과정에서 시간 지연 발생으로, 관련 업무 수행 지연 우려됨  
- 정보 접근 권한을 둘러싼 부서 간 불일치로 인해 내부 협업 저해 가능성 존재함  
- 특정 부서에서만 정보를 열람하게 되면 의사결정 투명성 저하 가능성도 있음  
- 문제 상황: 지난 1월 회의록 처리에서 총무팀은 전자 문서 시스템에 등록 후 즉시 공유를 요청했으나, 감사·내부통제팀은 보안 검토를 위해 최소 5일 이상 소요됨. 이로 인해 이후 진행된 인사위원회 준비 업무가 지연됨.  
- 판단 근거: 해당 사례에서 감사·내부통제팀은 정보 유출 리스크를 고려하여 엄격히 검토했으나, 총무팀은 신속한 의사소통 필요성을 강조했으며 이로 인해 갈등 발생.  
- 예상 영향: 반복적인 갈등으로 인해 향후 회의록 처리 시에도 지연이 반복될 수 있으며, 특히 전사적 정책 결정안에서는 실행 지연이 최대 7일까지 발생할 수 있음.  
- 담당 부서 입장: 경영지원팀은 각 회의록마다 사전에 누구에게 어떤 내용을 공유할지 미리 정하는 절차 도입을 제안하며 이를 통해 반복적인 논란 방지 필요성을 강조함.

5. 검토 의견  
- 모든 임원에게 동일하게 공유하는 것은 정보 유출 리스크가 크므로, 조건부 접근 방식이 타당함  
- 특히 핵심 정책 결정안은 관련 부서와 승인된 임원에게만 제공하고, 나머지 내용은 일반 임원에게는 요약본 제공으로 대체 가능함  
- 감사·내부통제팀의 제안대로 접근 권한을 엄격히 제한하는 대신, 업무 수행과 관련된 담당자에게는 소정의 정보 제공 가능하도록 조건 설정 필요함  
- 추가 제안: 핵심 정책 결정안에 대해 별도로 '비밀 문서' 라벨링을 적용하고, 이는 전용 시스템에서만 열람 가능하게 함으로써 보안 강화 필요함.  
- 판단 근거: 최근 실시된 보안 테스트 결과 비밀 문서 라벨링 적용 시 유출 리스크가 약 70% 감소함. 또한 해당 라벨링 문서는 열람 기록이 자동으로 남아 오류나 오남용 방지 가능함.  
- 예상 영향: 라벨링 도입 시 초기에는 사용자 교육 및 시스템 설정 작업이 추가로 필요하나, 단기적 지연보다 장기적 안정성 측면에서 긍정적 효과 기대됨.  
- 담당 부서 입장: 감사·내부통제팀은 라벨링 시스템 도입을 긍정적으로 평가하며 보다 강화된 관리 체계 도입 필요성을 제기함.

6. 향후 조치  
- 각 부서장이 참여하는 협의회를 2025년 2월 5일까지 소집하여 접근 기준 확정함  
- 이후 총무팀은 전자 문서 시스템에 권한 설정을 완료하고, 해당 설정 기준으로 회의록 열람 가능하게 함  
- 이후 회의록 작성 시에는 사전에 누구에게 어떤 내용을 공유할 것인지 미리 정하기로 함으로써 반복적인 논란 방지 필요함  
- 다음 회의부터는 협의 결과를 반영하여 일관된 정보 관리 체계 도입 예정임  
- 추가 조치: 협의회 종료 후 즉시 전자 문서 시스템에 '비밀 문서' 라벨링 옵션 적용 및 관련 직원 교육 실시 (2025년 2월 10일까지)  
- 담당자: 총무팀 김민수 (협의회 운영), 감사·내부통제팀 박지현 (보안 검토), 경영지원팀 최재훈 (업무 연계 검토)  
- 기한: 모든 권한 설정 및 교육 완료 기한 – **2025년 2월 14일**
