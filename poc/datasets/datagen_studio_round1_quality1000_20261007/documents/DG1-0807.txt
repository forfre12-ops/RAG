총무-2025-0709 / 총무팀 / 경영지원부서 / 총무팀 김지영 / 2025-10-14

1. 추진 배경  
- 최근 보존 활동을 위한 유형자산 관리 체계가 미흡함으로써, 보호구역 정보의 누락 및 오류가 반복됨  
- 기존 시스템은 보호구역 정보를 별도로 관리하지 않아, 법적 기준 준수와 관련된 리스크 발생 가능성 있음  

2. 추진 목적  
- 보호구역 정보를 포함한 유형자산에 대한 정기적 검토와 관리 체계를 마련함으로써, 내부 시스템의 신뢰성 제고  
- 유형자산의 정기적 점검 및 업데이트를 통해 장기적인 관리 기반 마련 필요함  

3. 추진 내용  
- 유형자산 등록 시 보호구역 정보 필드를 별도로 추가함으로써, 등록 시 자동으로 입력되도록 설정함  
- 총무팀에서만 접근 가능한 보안 시스템을 운영하며, 승인된 담당자에게만 정보 제공  
- 기존 데이터 기반으로 2025년 10월 말까지 보호구역 정보 보완 작업 완료 예정  

4. 일정  
- 2025년 10월 15일: 시스템 개선 계획 승인 완료됨  
- 2025년 10월 20일: 데이터 정제 작업 시작됨  
- 2025년 10월 31일: 보호구역 정보 반영 완료됨  
- 2025년 11월 1일: 정기 점검 실시 예정  

5. 예상 효과  
- 보호구역 정보 누락으로 인한 오류 발생률이 약 75% 감소할 것으로 예상됨  
- 법적 문제 발생 가능성이 있는 자산에 대한 조기 탐지 가능해짐  

6. 리스크  
- 데이터 입력 부족으로 인한 보완 작업 지연 가능성 있음  
- 시스템 연동 오류 발생 시, 업데이트 실패 가능성 있음
