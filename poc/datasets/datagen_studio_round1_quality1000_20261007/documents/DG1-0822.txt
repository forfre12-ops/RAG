총무-2025-2864 / 총무팀, 경영지원부 / 총무팀장, 김지영 / 2025-04-22

1. 검토 배경  
- 최근 보안 침해 사고 발생 가능성을 고려하여 보안 시스템 정보의 정기적 점검 필요함  
- 기존 보안 시스템의 접근 권한 관리 체계가 미흡하여 내부 정보 유출 위험 발생함  

2. 검토 내용  
- 보안 시스템의 주요 구성 요소인 인증서, 접근 제어 목록, 로그 기록 시스템을 대상으로 현황 파악함  
- 총 7개 부서에서 13개의 보안 설정 항목이 확인되었으며, 이 중 4개는 만료 기한이 지난 상태로 확인됨  
- 보안 정책에 따라 정기적인 갱신이 필요하지만, 현재는 담당자 미지정으로 인해 갱신이 지연됨  

3. 주요 결과  
- 인증서 갱신 기한이 지난 항목 중 2개는 이미 만료되어 시스템 접속에 실패함  
- 접근 제어 목록에서 권한이 부여된 사용자 중 3명은 퇴사 완료 상태이나, 여전히 접근 권한 유지됨  
- 로그 기록 보관 기간이 규정된 90일보다 짧아진 60일로 설정되어 있어 감사 시 비효율적임  

4. 문제점  
- 보안 시스템 관리 책임자 지정 미흡으로 인해 점검 주기가 불규칙함  
- 업데이트 예정일이 명시되지 않아 담당자 혼란 발생함  
- 관리자 권한을 가진 직원의 이직 후에도 권한 회수 미완료로 인한 내부 위험 존재함  

5. 검토 의견  
- 보안 시스템 관리 책임자를 각 부서별로 지정하고, 분기별 점검을 시행할 것임  
- 인증서 갱신은 최소 30일 전에 완료되도록 조치 예정이며, 만료 직전 알림 시스템 도입 필요함  
- 접근 제어 목록은 월 1회 정기적으로 검토하여 퇴사자 권한 자동 회수 방식으로 전환할 것임  

6. 향후 조치  
- 보안 시스템 관리 매뉴얼을 개정하여 모든 절차를 문서화하고, 관련 부서에 안내 예정임  
- 2025년 5월 말까지 전체 보안 설정에 대한 재점검 실시 및 결과 공유 예정임
