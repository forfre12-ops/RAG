안녕하십니까, IT운영팀장 박민수입니다.  

이번 주 초부터 진행되고 있는 핵심 시스템 개편 작업과 관련하여, 이행 중 발생할 수 있는 장애 상황에 대비한 안정적인 롤백 절차의 필요성이 제기되고 있습니다. 현재까지 각 팀에서 검토한 내용을 종합하여 보다 신뢰할 수 있는 시스템 전환 체계를 마련하고자 하오니, 아래와 같이 관련 부서 담당자 분들께 확인 요청을 드립니다.

가온산업의 주요 고객 정보 처리 시스템은 기존 3-tier 아키텍처에서 클라우드 기반의 마이크로서비스 기반 구조로 전환 중이며, 이에 따라 데이터베이스 연결 방식과 API 연동 흐름이 변경되었습니다. 특히, 고객 계정 정보를 담당하는 ‘사용자관리 서비스’는 기존 서버에서 독립적으로 운영되며, 인증 처리는 JWT 기반으로 재구성되었습니다. 이에 따라 기존의 세션 기반 로그인 처리는 완전히 제거되었으며, 이로 인해 애플리케이션 간 인증 흐름의 일관성이 유지될 수 있도록 연동 범위를 재설계하였습니다.

IT개발팀에서는 현재 개별 서비스 간 통신을 위한 REST API 기반의 연동 흐름을 100% 검증하였으며, 특히 고객 정보 조회 시 사용되는 ‘사용자기본정보API’는 3월 20일부터 가용성 테스트를 완료하였습니다. 다만, 이 연동이 완료된 이후에도 별도의 오류 발생 시점에 대비하여 로그 분석 및 모니터링이 가능한 지점이 부족하지 않은지 확인이 필요합니다. 이를 위해 IT운영팀에서는 실시간 모니터링 도구를 활용하여 5초 단위로 상태 점검을 수행하고 있으며, 오류 발생 시 자동으로 알림을 보내는 구조로 운영하고 있습니다.

또한 정보보안팀에서는 암호화된 데이터베이스 접근을 위한 키 관리 방식을 새롭게 도입하였으며, 이는 기존의 고정 키 방식에서 벗어나 동적 키 기반으로 전환되었습니다. 이로 인해 복구 시점에 원활한 데이터 복원이 가능하도록 하기 위해 백업 파일마다 암호화 키 버전을 명시하고 있으며, 현재는 각 백업 파일에 대해 2개 이상의 복원 가능성을 보유하고 있습니다. 다만, 실제 롤백 시점에서 암호화된 데이터를 올바르게 복구할 수 있는지에 대한 검증은 아직 완료되지 않았으며, 이에 대해 검토 부탁드립니다.

업무협조팀에서는 고객 문의 처리 흐름과 연계된 내부 프로세스가 변경됨에 따라, 고객 문의가 발생했을 때 해당 문의가 올바르게 처리되는지 확인하는 작업을 수행하고 있습니다. 현재까지 총 7건의 예외 상황을 가상으로 설정하여 테스트한 결과, 2건은 시스템 전환 후에도 원활히 처리되나, 나머지 5건은 일시적인 오류가 발생할 가능성이 확인되었습니다. 특히 회원 탈퇴 요청 처리 시 데이터 삭제가 지연되는 문제가 발견되어, 이에 대한 보완 조치가 필요합니다.
