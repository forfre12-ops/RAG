총무-2025-1252 / 모든 부서 / 총무팀, 업무협조 담당자 전체 / 2025-03-17  

1. 검토 배경  
- 총무팀은 지난 2월 말 기준으로 각 부서에서 사용한 사무용 소모품의 집계를 완료함  
- 업무 협조 부서인 기획실과 영업실은 각각 복사지, 펜, 메모지 등에 대해 사용 내역을 제출함  
- 3월 중순 기준으로 예상되는 추가 발주량을 산출하기 위해 각 부서의 요청 사항을 정리함  

2. 검토 내용  
- 복사지(흰색 A4)는 기획실이 345권, 영업실이 198권을 사용함으로 총 543권 소요됨  
- 펜(검정, 중성)은 영업실이 146본, 기획실이 78본을 사용함으로 총 224본 소요됨  
- 메모지(작은 크기)는 영업실에서 36개, 기획실에서 18개를 사용함으로 총 54개 소요됨  
- 현재 재고는 복사지 176권, 펜 89본, 메모지 43개로 잔여 수량 확인됨  

3. 주요 결과  
- 복사지의 경우 사용량 대비 잔여 수량이 낮아 추가 발주 필요함  
- 펜과 메모지는 사용량 대비 여유가 있으나, 영업실의 경우 다음 달 예상 사용량이 증가할 것으로 판단됨  
- 기획실은 기존 발주량 대비 약 10% 감소 예상, 영업실은 약 25% 증가 예상됨  

4. 문제점  
- 영업실의 경우 복사지 사용량이 전월 대비 약 40% 증가했으나, 이에 대한 사전 예측 없이 발주 진행됨  
- 복사지의 경우 납품 주기가 길어 다음 달 중순까지 재고 소진 가능 여부 확인 필요함  
- 메모지 제품군은 현재 공급사 변경 작업 중으로 공급 지연 가능성 있음  

5. 검토 의견  
- 복사지에 대해서는 현재 재고 대비 추가로 최소 300권 발주 필요함  
- 펜과 메모지는 영업실 요청량을 반영해 각각 추가로 100본, 50개 발주 결정함  
- 공급사 변경으로 인한 지연 가능성에 대비해 복사지는 조기 발주로 납기 보장 필요함  

6. 향후 조치  
- 복사지 발주는 3월 20일까지 납품 업체에 주문 완료함  
- 펜과 메모지는 영업실 요청량 반영하여 3월 19일까지 발주 진행됨  
- 다음 달부터는 월초 기준으로 사전 예측량을 기반으로 자동 발주 시스템 도입 예정임
