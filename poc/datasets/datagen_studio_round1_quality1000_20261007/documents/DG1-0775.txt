1. 추진 배경  
- 최근 내부 보안 테스트 도중 인증 처리 과정에서 악성 코드 삽입이 가능한 취약점이 발견됨  
- 이 취약점은 사용자 인증 토큰을 재사용할 수 있도록 하는 구조로, 타사 시스템과 연동 시 위험도가 높음  
- 현재 운영 중인 고객 관리 시스템의 85%가 해당 구조를 사용하고 있어 영향 범위가 크며, 서비스 중단 없이 조치할 수 있는 방안이 필요함  

2. 추진 목적  
- 취약점에 대한 보완 조치를 빠르고 안정적으로 수행하여 서비스 장애 및 데이터 유출 사고를 예방함  
- 사용자 인증 흐름의 무결성을 확보하고, 보안 인증 기준을 업데이트함  
- 기존 시스템에 영향을 주지 않으면서도 완전한 보안 패치를 적용함  

3. 추진 내용  
- 취약 구간: 사용자 세션 토큰의 유효 기간이 지나도 재사용 가능한 구조로, 타임스탬프 검증 미흡으로 인해 위험 발생함  
- 영향 범위: 고객 관리 시스템(버전 3.4.1), 모바일 앱 인증 서비스, API 엔드포인트 3개 모두 해당됨  
- 조치 방안: 토큰 유효 기간을 15분으로 단축하고, 재사용 방지를 위한 고유한 랜덤 값 추가 적용
