품질-2025-0400 / 품질관리팀, 제조팀 / 품질관리팀 / 김민수 / 2025-09-23  

1. 배경  
- 최근 분기 품질 활동에서 발생한 불량률 개선 여부를 종합적으로 검토함  
- 제조팀 내 일부 공정에서 검사 기준이 미흡하게 적용되어 재작성 필요 발생함  

2. 목표  
- 분기별 품질 활동을 기반으로 한 표준 작업 절차 정착 완료함  
- 향후 분기부터는 모든 공정에서 동일한 기준으로 검사 수행 필요함  

3. 세부 계획  
- 모든 공정에 대한 검사 기준서를 재정비하고, 각 팀장 승인 완료함  
- 검사 항목별로 점검 기준을 명확히 하고, 오류 발생 시 보고 체계 강화함  
- 제조팀 내 3개 부서에서 시행한 시범 운영 결과, 불량률 18% 감소 확인됨  

4. 일정  
- 9월 25일까지 검사 기준서 최종 승인 완료됨  
- 10월 1일부터는 전체 공정에서 표준 작업 절차 적용 예정임  
- 10월 15일까지는 시행 착오 보고서 작성 및 개선안 도입 예정임  

5. 필요 자원  
- 품질관리팀 산하 표준업무팀에서 담당자 2명 배치됨  
- 제조팀 각 부서별로 검사 담당자 1명씩 지정하여 교육 실시함  

| 구분 | 현행 | 조정안 |  
|------|------|--------|  
| 검사 빈도 | 주 1회 | 주 2회로 확대 |  
| 불량 기록 방식 | 구술 보고 | 전산 시스템 입력 필수 |  
| 검사 결과 통보 | 직접 전달 | 이메일로 자동 전송 |  

6. 지표 변화  
- 분기 말 기준 불량률이 전 분기 대비 18% 감소함  
- 고객 불만 건수는 전 분기 대비 3건 감소하여 안정적 추세 유지됨  

7. 다음 분기 계획  
- 표준 작업 정착 후 모니터링 주기를 주 1회에서 월 1회로 전환함  
- 분기 말에 품질 성과를 평가하여 개선 필요 시 보완 조치 예정임  

8. 참고 사항  
- 현재까지의 시행 결과, 검사 부족으로 인한 재작성 건수는 9건 감소함  
- 다음 분기에는 품질 관리 시스템의 자동화 도입을 고려 중임
