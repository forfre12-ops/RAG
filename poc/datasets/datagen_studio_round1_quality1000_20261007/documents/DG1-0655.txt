영업소개자료 갱신 협의 회의 / 2025-06-16 / 회의실 304 / 영업기획팀 김지영, 마케팅팀 박상훈, 영업지원팀 정민재 / 김지영  

- 영업기획팀은 고객사 대응을 위한 소개 자료의 내용을 현행화하기로 함  
- 기존 자료에는 제품의 기능 중심 설명만 포함되어 있어, 고객 맞춤형 설명이 부족하다는 지적이 있었음  
- 마케팅팀은 공개 가능한 사양을 기준으로 제품 개요를 재구성하기로 함  
- 기술 사양 중에는 최신 버전의 전력 소비량과 내구성 검증 결과를 포함하기로 함  
- 고객 문의 시 사용할 창구를 영업지원팀이 담당하며, 이메일과 전화번호를 공개하기로 함  
- 소개 자료는 7월 초까지 수정본을 제출하고, 외부 배포 전 사전 승인 절차를 거치기로 함  
- 영업기획팀은 고객사별 맞춤형 버전도 별도로 제작하여 제공할 예정임  

- 영업기획팀은 소개 자료 개선안을 2025-06-23(월)까지 완성하기로 함  
- 마케팅팀은 사양 정보 검증 및 이미지 보완 작업을 2025-06-20(금)까지 완료하기로 함  
- 영업지원팀은 문의 창구 안내 문구를 2025-06-18(수)까지 최종 검토하여 공유하기로 함
