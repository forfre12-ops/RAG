영업-2025-2090 / 영업팀, 영업기획팀, 데이터관리팀 / 영업기획팀 / 2025-08-14

1. 분석 목적  
- 영업팀에서 관리하고 있는 판매고객 데이터의 정확성과 포괄성을 검증하고, 최근 실적 하락 원인을 파악하기 위해 거래처별 판매 현황을 종합적으로 분석함  
- 고객 명단과 납품처 정보의 중복 여부 및 연락처 미동기화 문제를 확인하여, 향후 영업 활동의 신뢰도를 높이기 위한 기초 자료 마련함  

2. 분석 방법  
- 영업기획팀이 보유한 고객데이터 명부(2025년 7월 기준)와 영업팀의 거래처 목록을 기반으로 중복 체크 수행  
- 고객명, 주소, 대표 연락처, 납품처 정보를 기준으로 일치 여부를 검증하고, 데이터 미등록 또는 오기된 경우는 별도로 정리함  
- 데이터 정합성 검사를 위해 업무 협조 부서인 데이터관리팀이 제공한 정제된 고객 정보 기준으로 비교 검증 진행  

3. 분석 결과  
- 총 187개의 거래처 중 14개에 대해 중복 등록된 고객이 확인됨 (예: A거래처, B거래처 등)  
- 13개의 고객에 대해는 주소 정보가 변경되었으나, 영업팀에서 이를 반영하지 않아 납품 오류 발생함  
- 영업 담당자 A 과장은 6개의 고객 연락처를 갱신하지 않아 실제 납품 시 전화 연결 불가 발생함  
- 거래처별 판매 금액 집계 결과, 상위 3개 거래처만 전체 매출의 67%를 차지하며, 나머지 184개는 33%에 불과함  

4. 해석  
- 영업 담당자들의 경우 거래처 관리 시 일상적인 업데이트가 이루어지지 않아 데이터 신뢰성이 저하됨  
- 특히 중소 규모 거래처들에 대한 세부 정보 관리가 미흡하여, 향후 계약 갱신 시 불이행 사례 발생 가능성 있음  
- 대량의 중복 데이터로 인해 고객 분류 및 타겟팅에 어려움이 있으며, 이는 영업 전략 수립에도 부정적 영향을 줌  

5. 활용 방안  
- 영업기획팀에서 각 영업 담당자별로 데이터 정리 작업을 완료할 수 있도록 8월 말까지 보고서 제출 예정  
- 데이터관리팀과 협력하여 정기적인 주간 데이터 정합성 점검 시스템 도입 (주간 1회 자동 체크)  
- 내년 상반기부터는 거래처별로 월별 실적 기준으로 포트폴리오 분류 및 리워드 지급 방식 도입 예정

영업팀은 현재 진행 중인 거래처 리뷰 회의에서 제시된 개선안을 반영하여 다음 주부터 자체 점검을 실시함  
영업기획팀은 각 담당자의 작업 내역을 확인하고, 누락된 정보는 반드시 보완하도록 안내함  
데이터관리팀은 추후 시스템 개선 시 자동 동기화 기능 추가를 검토 중이며, 이는 내년 상반기 중 적용 예정임
