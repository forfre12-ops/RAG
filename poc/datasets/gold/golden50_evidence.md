# 골든셋 50건 — 판단근거 대장

각 문서가 **정본 가이드 B안(등급 = 비공지성 S × 경제유용성 V × 비밀관리성 M)** 의
어떤 기준·문구로 해당 등급에 매핑됐는지 추적. (S/V/M ∈ {0,1,2}, 곱=등급)

- 곱 매핑: 8→특급 / 4→1급 / 1·2→2급 / 0→3급공개
