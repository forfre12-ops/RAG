# 골든셋 50건 파일럿 — 발견사항·결정 (2026-06)

본셋 1,000건 구축 전, 50건 파일럿으로 품질·근거·데이터정합을 검증한 결과.

## 1. 골든셋 자력 구축 — 본문 품질 ✅
- 회사 내부형 문서(반도체·금융·M&A·바이오·국방 등) × 4등급 × 13건 = 52건 생성(`golden50.jsonl`).
- 본문은 구체 수치·구조·민감도 신호 + `[가상X]` 익명화 → **고객 납득 가능 수준**.
- 실제 형식(DOCX/PDF) 변환·재추출 검증 완료(`scripts/format_export.py`). HWP는 별도 트랙(한글 COM/HWPX/발주처 샘플).

## 2. 판단근거 대장 — "객관성"의 조건 (③④)
- 초안 대장(`golden50_evidence.md`)은 **수식 비정합 18/52**(예 `0→S1`, `4→TS`) — 룰의 신규도메인 미탐 + FNR-safe 보정 + 키워드 오매치 탓.
- **교훈: 자동라벨만으로는 객관 대장 불가.** S×V×M이 등급을 실제 재구성하고 근거가 그 등급을 정당화해야 함.
- 정합 재구성판(`golden50_evidence_v2.md`): LLM의 S/V/M 수치 포착 → **곱↔등급 52/52(100%) 정합**.
  - 자동확정후보 **17건**(룰=LLM=목표 일치) / 전문가 검수필요 **35건**(불일치) → 검수 물량의 현실 추정치.

## 3. 학습데이터 법률코퍼스 오염 — 중대 발견 + ablation
- 기존 학습셋 5,911건 중 **56%(3,320건)가 법률 판례·심결**, 그중 **2,210건이 비밀등급(TS 536/S1 699/S2 975)으로 오라벨**.
  - 공개 법원문서를 "기밀"로 학습 → 도메인 불일치 + 라벨 오류.
- **ablation(법률 제외 재학습, `labeled_clean_nolegal`)**:

  | 평가셋 | 법률포함(기존) | **법률제외** |
  |---|---|---|
  | 정제 test split(비즈니스) | 78% | **93%** |
  | 홀드아웃 금융보고서(49) | 67% | **73%** |
  | 홀드아웃 비즈니스만(판례 제외, 90건) | ~67% | **78%** |
  | 홀드아웃 판례(19) | 낮음 | 0%(미학습) |
  | 고등급 FNR(test) | 21% | **8%** |

- **결정**: 영구삭제가 아니라 **영업비밀 학습셋에서 법률코퍼스 제외**(원본 아카이브) + **홀드아웃에서도 판례 제거**(공개 법원문서는 영업비밀 분류 대상 아님).
  - 근거: 비즈니스 문서 정확도 67→78%↑, test split 93%, FNR 21→8%.

## 본셋(1,000) 반영 사항
1. 법률코퍼스 제외 + 판례 홀드아웃 제거(데이터 정합).
2. 근거대장은 정합 재구성판 방식(LLM S/V/M + 검수상태) 적용.
3. 검수필요 비율(파일럿 35/52≈67%) → 전문가 검수 공수 산정 + 발주처 검수 참여 제안.
4. S1↔S2 경계·금융/판례 도메인 표본 집중 보강(특성화 결과 기반).
