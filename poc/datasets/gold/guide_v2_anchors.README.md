# guide_v2_anchors.jsonl — 정본 가이드 기반 골든셋 시드 (B안 S×V×M)

출처: 발주처 **영업비밀 등급분류 가이드**(특허청·한국지식재산보호원) p11·p12 + p6~9 예시표.
용도: ① S/V/M 스코어러 calibration 앵커, ② 합성(M1) 등급·토픽 시드, ③ 룰 라벨러 등급 회귀 정답.
관련: [doc/22 v2 §3·§4](../../../doc/22_영업비밀_등급분류_기준_적용서_v2_정본가이드기반.md) · [grade_from_svm](../../src/lloydk/modules/m3_labeling/rule_engine.py)

## 레코드 종류 (`kind`)

| kind | 출처 | 권위 | 내용 |
|---|---|---|---|
| `factor_level_example` | 가이드 p11 | 높음 | 각 요건(S/V/M)의 0·1·2 수준이 "어떤 문서인지" 예시 — **S/V/M 스코어러 calibration의 1차 기준** |
| `svm_anchor` | 가이드 p12 워크드 예시 | **권위(authoritative)** | S·V·M 명시 + 곱(svm) + 등급. `grade_from_svm` 회귀 정답 |
| `grade_example` | 가이드 p6~9 예시표 | 검수필요(needs_review) | 직무별 문서유형→등급. **OCR 추출 + 가이드 내부 변이** 존재 → 사람 검수 전 잠정 |

## ⚠ 가이드 내부 변이 (발주처 협의 항목)

가이드의 **예시표(p6~9)** 와 **S×V×M 워크드 예시(p12)** 가 일부 불일치한다 — 가이드 p2가 *"각 기업 현실에 맞도록 수정하여 활용"* 이라 명시한 가이드라인 특성.

| 문서 | p6~9 예시표 | p12 S×V×M | 비고 |
|---|---|---|---|
| 중장기 경영계획 | **1급(S1)** | S=V=M=2 → 8 → **특급(TS)** | 산정법(예시표 vs S×V×M) 중 무엇을 정본으로 볼지 발주처 확정 필요 |

→ 본 시스템은 **S×V×M(p12·p11) 방식을 정본으로 채택**(doc/22 v2 §3.3). 따라서 `svm_anchor`가 권위, `grade_example`은 보조·검수 대상. 화요일 기술협의에서 발주처 승인 후 `grade_example`을 S/V/M로 정규화하여 골든셋 본셋(PMR-002 1,000건)으로 확장한다.

## 다음 단계
1. 발주처 산정법·특급 처리 확정(화요일).
2. `factor_level_example`로 S/V/M 스코어러 calibration(전환 ③).
3. `svm_anchor`/`grade_example` 토픽으로 M1 합성 → 등급별 문서 생성 → 사람 검수 → **블라인드 골든셋 1,000건**.
