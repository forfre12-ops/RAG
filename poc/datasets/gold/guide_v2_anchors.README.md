## ⚠ 가이드 내부 변이 (발주처 협의 항목)

가이드의 **예시표(p6~9)** 와 **S×V×M 워크드 예시(p12)** 가 일부 불일치한다 — 가이드 p2가 *"각 기업 현실에 맞도록 수정하여 활용"* 이라 명시한 가이드라인 특성.

| 문서 | p6~9 예시표 | p12 S×V×M | 비고 |
|---|---|---|---|
| 중장기 경영계획 | **1급(S1)** | S=V=M=2 → 8 → **특급(TS)** | 산정법(예시표 vs S×V×M) 중 무엇을 정본으로 볼지 발주처 확정 필요 |

→ 본 시스템은 **S×V×M(p12·p11) 방식을 정본으로 채택**(doc/22 v2 §3.3). 따라서 `svm_anchor`가 권위, `grade_example`은 보조·검수 대상. 화요일 기술협의에서 발주처 승인 후 `grade_example`을 S/V/M로 정규화하여 골든셋 본셋(PMR-002 1,000건)으로 확장한다.

## 재검증 이력 (2026-06-18, 가이드 고해상도 재판독)

p5·6·7·8·9·11·12를 3.0x로 재렌더링해 한 글자씩 대조. **권위(svm_anchor·factor_level)는 전부 정확** 확인. 오류는 `grade_example`(p6~9 색상표, OCR 취약 tier)에 한정 — 아래 정정:

| 항목 | 정정 전 | 정정 후(가이드 실제) |
|---|---|---|
| 이사회 명단 | S3 | **S2** (2급 대외비) |
| 산업재산권 관리정보(특허·실용신안·디자인) | S3 | **S2** (2급 대외비) |
| 생산기술(도면·제조방법) | (S2로 묶임) | **S1** (1급 비밀, 별도 추가) |
| 비밀관리성 lv0 예시 | "신고 자료" | "신고의무 정보" |

⚠ **검토 항목(발주처)**: 가이드는 산업재산권 관리정보(특허·실용신안·디자인)를 **2급 대외비**로 분류하나, *등록·공개된* 특허는 비공지성상 **3급 공개**가 타당할 수 있음 — 출처 게이트(공개특허→S3)와 충돌. 화요일 협의 시 "등록/공개 IP의 등급" 확인 필요.

## 다음 단계
1. 발주처 산정법·특급 처리 확정(화요일).
2. `factor_level_example`로 S/V/M 스코어러 calibration(전환 ③).
3. `svm_anchor`/`grade_example` 토픽으로 M1 합성 → 등급별 문서 생성 → 사람 검수 → **블라인드 골든셋 1,000건**.
