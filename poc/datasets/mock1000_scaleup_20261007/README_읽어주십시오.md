# 규칙준수 + DataGen식 실감 — 1,001건 전량 (2026-10-07~08)

## 배경

128건 파일럿([[mock_pilot_rulegen_20261007]])에서 "DataGen Studio가 잘하는 것(구체적 상황
설정)은 가져오고, 우리 규칙 위반은 없앤다"는 방식을 검증했다. 사용자가 KL 김창훈 부장의
"KL(DataGen Studio) 문서가 더 품질 좋다"는 평가에 대응해, 같은 방식을 **mock1000과 동일한
부서 비중(1,001건)**으로 전량 확장할 것을 지시했다.

## 방법

- **구성**: guide40 카탈로그의 (부서,등급,정보유형) 전체 64칸을 mock1000과 동일한 부서
  비중(경영141·구매47·생산제조204·연구개발156·인사156·총무93·판매110·회계94)에 맞춰
  칸당 약 15~16회 반복 배분(최대나머지법). `poc/scripts`에 두지 않은 임시 계획 스크립트로
  41개 작업 단위(배치)로 쪼갰다(배치당 평균 24건).
- **작성자**: Claude 서브에이전트 41명(배치당 1명, 전부 foreground 병렬 3개 Wave로 투입).
  각자 지시 파일(스크래치패드)을 직접 Read로 읽어 수행 — 규칙 본문을 매번 손으로 붙여넣지
  않고 공유 지시 파일을 참조하는 방식으로 오케스트레이션 메시지 크기를 줄였다.
- **규칙**: 128건 파일럿과 동일 — `generation_playbook.py` 6규칙 + 반복금지어 30개 + 등급명
  비공개(민감도 설명만 제공, TS/S1/S2/S3 각 3버전 순환) + 형식 9종(이메일·회의록·메신저·
  품의서·업무요청서·점검기록·인수인계서·내부공지·비정형메모) 직접 배정 + DataGen에서 가져온
  "구체적 날짜·수치·담당자 간 미해결 의견차" 지침.
- **중단 처리**: 작업 중 도구 호출이 5차례 사용자 요청으로 중단됐다(batch13 1차, batch24·27·
  28·31). 중단된 배치는 전부 처음부터 다시 작성했다(미완성분 재사용 금지) — batch13의 1차
  중단분은 글자수 448~809자로 기준 미달인 상태로 파일이 남아 있었던 것을 확인해 폐기하고
  재작성했다.

수치·갈등)가 들어갔다. 미달 114건 중 65건이 "수치가 너무 적음", 49건이 "문단 수가 적음" —
짧은 형식(이메일·메신저)에 몰린 문서들이라 mock1000(91.7%)보다는 여전히 조금 낮다.

## ⚠ 전수 검증 중 발견한 결함 — 보고하고 수정함

**카탈로그 자체에 등급이 겹치는 정보유형 3개가 있었다**: "생산계획 정보"·"제품 생산실적
정보"(생산제조)·"인력채용 정보"(인사)가 guide40 원본에서부터 **같은 이름으로 S2·S3 두
등급에 모두 쓰이고 있다**(구분 꼬리표 없음 — 예: "공정 진척 정보" vs "공정 진척
정보(작업일보)"처럼 다른 정보유형은 괄호로 구분해 뒀는데 이 셋은 안 돼 있다).
```
생산계획 정보        생산제조/S2(MG-0034) · 생산제조/S3(MG-0046)
제품 생산실적 정보    생산제조/S2(MG-0012) · 생산제조/S3(MG-0021)
인력채용 정보        인사/S2(MG-0051) · 인사/S3(MG-0042)
```
이번 배치 계획은 (등급,정보유형) 조합을 각각의 칸으로 다뤄서 47건이 정확한 의도대로
작성됐지만(각 문서의 `grade` 필드 = 그 문서를 지시할 때 지정한 등급), **정보유형 이름만
보고 등급을 되찾으려 하면 틀린다** — 최종 manifest의 `true_grade`는 문서 생성 시 실제
지시한 등급(에이전트가 적어 넣은 값)을 그대로 썼다. mock1000 쪽에도 같은 카탈로그
모호성이 있을 수 있어 별도 확인이 필요하다(이번 작업 범위 밖).

## 파일

- `raw/batch##_<부서>.json` — 41개 작업 단위 원본(참고용, 최종본 아님).
- `scaleup_manifest.jsonl` — 1,001행. doc_id(MS1-0001~1001)·department·true_grade·info_type·
  doc_format·char_count.
- `documents/MS1-####.txt` — 제목+본문.

## 하지 않은 것 (한계, 파일럿과 동일)

- 통계적 지름길 검사(가족단위+라벨섞기) 안 함 — 1,001건 규모라 이번엔 가능한 조건이나
  아직 안 돌렸다.
- 사람 검수 없음(라벨은 지시한 등급 그대로, 전문가 확정 아님).
- 본문의 20~30% 무관내용·핵심사실 분산은 자동검증 불가, 41개 서브에이전트 각자의 자체
  점검(스크립트+육안)에 의존.
