# 전문가 검수용 모의문서 1,000건 안내

이 폴더는 전문가가 모의문서를 읽고 문서 등급을 판정하는 검수 패키지입니다.
각 문서에는 `MR-0001`부터 `MR-1000`까지의 검수번호가 부여되어 있습니다.

문서 선별 단계에서는 문서형태, 본문 안의 등급 단서, 동일 본문 중복을 확인했습니다.
전문가 검수 결과는 이후 학습 데이터, 개발 평가 데이터, 최종 골든셋 구성의 기준 정보로 활용됩니다.

## 파일별 용도

### 1. `reviewer_documents.jsonl` — 전문가 검수 화면용

전문가 검수 화면에 올리는 파일입니다.

각 행에는 아래 두 정보가 있습니다.

| 항목 | 설명 |
|---|---|
| `review_id` | 검수 문서번호. 예: `MR-0001` |
| `text` | 전문가가 읽고 판정할 문서 본문 |

검수 화면에서는 문서번호와 본문을 기준으로 특급, 1급, 2급, 3급, 보류, 제외 등의 결과를 기록합니다.
문서별 기존 잠정 등급, 원천 문서 ID, S/V/M 값, 자동 판정 근거는 검수 화면의 표시 정보에서 제외합니다.

### 2. `internal_manifest.jsonl` — 관리자 운영·결과 병합용

관리자가 보관하는 대응표입니다. 전문가 검수 결과의 `review_id`를 기준으로 원천 문서와 연결할 때 사용합니다.

| 정보 | 설명 |
|---|---|
| `review_id` | 전문가 검수 화면의 문서번호 |
| `source_name` | 문서가 선별된 데이터셋 이름 |
| `source_path` | 원천 데이터 파일 위치 |
| `source_doc_id` | 원천 데이터 내부 문서 식별자 |
| `source_label` | 전문가 검수 이전의 잠정 등급 |
| `source_sha256` | 본문 동일성 확인용 해시값 |
| `quality_metrics` | 문단 수, 본문 길이, 구체 정보 수 등 1차 품질 측정값 |

이 파일을 이용하면 검수 완료 문서의 원천 추적, 검수 결과 병합, 중복 확인, 후속 데이터셋 분류가 가능합니다.

### 3. `summary.json` — 전체 현황 확인용

검수 시작 전 전체 구성을 빠르게 확인하는 집계 파일입니다.

| 항목 | 설명 |
|---|---|
| `selected_total` | 전문가 검수 대상 전체 건수 |
| `selected_by_source` | 데이터셋별 선별 건수 |
| `selected_by_provisional_label` | 잠정 등급별 건수 |
| `outcomes_by_source` | 문서형태 통과·보류·보강 대상·제외 현황 |
| `rule` | 문서 선별 기준 |

## 전문가 검수 진행 흐름

1. 관리자가 `reviewer_documents.jsonl`의 문서를 검수자별로 배정합니다.
2. 검수자는 본인에게 배정된 문서의 본문을 읽고 등급과 사유를 기록합니다.
3. 관리자는 검수 결과와 `internal_manifest.jsonl`을 `review_id` 기준으로 연결합니다.
4. 전문가 확정 문서는 학습셋, 개발 평가셋, 최종 골든셋 중 하나의 용도로 분류합니다.

## 검수 결과의 데이터셋 분류

| 분류 | 의미 | 활용 시점 |
|---|---|---|
| 학습셋 | 모델이 학습하는 전문가 확정 문서 | 다음 모델 재학습 |
| 개발 평가셋 | 모델·규칙·프롬프트 개선 과정의 성능 확인 문서 | 개발 및 튜닝 |
| 최종 골든셋 | 최종 성능 측정 기준 문서 | 최종 블라인드 테스트 |

동일 문서는 위 세 분류 중 하나의 역할로 관리합니다.
