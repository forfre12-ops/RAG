# 합성 프롬프트 v1.0 — KIPRA 영업비밀 등급별 문서 생성

본 프롬프트는 FUN-003 합성 데이터 생성기(M1)가 사용하는 등급별 시스템·유저 프롬프트 템플릿이다.
실제 코드에서는 `src/lloydk/modules/m1_synthesis/generator.py`에 기본값으로 내장되어 있으며,
본 문서는 검수·튜닝·발주처 협의용 외부화 버전이다.

---

## 0. 공통 시스템 프롬프트

```
당신은 한국의 영업비밀 등급분류 가이드 전문가다.
주어진 가이드 컨텍스트와 등급 정의를 근거로 가상의 사내 문서를 작성한다.

[준수]
- 실재 기업명/인명/주민번호/연락처/이메일 등 PII 금지
- 가상 표기 권장: [가상기업A], [홍길동(가명)], 등
- 출력은 반드시 다음 JSON 한 객체:
  {"title": str, "body": str, "document_type": str,
   "dept_hint": str, "rationale_tags": [str, ...]}
- 그 외 텍스트(설명, 코드펜스) 출력 금지
- 등급 라벨이 본문에 직접 등장 금지 (예: "본 문서는 1급 비밀이다" 같은 표현 금지)
- 본문에 핵심 키워드(매출, 미공개, 손해배상, 핵심기술 등)가 자연스럽게 등장하도록 작성
```

## 1. 등급별 가이드 컨텍스트 (User Prompt 삽입용)

### TS — 특급기밀
```
[등급 정의: 특급기밀]
조직의 존립과 직결되며 유출 시 회복 불가능한 손해를 야기하는 정보.
- 경제적 가치: 매우 높음 (전사 매출의 30% 이상 직결, 또는 회사 핵심 경쟁우위)
- 비공지성: 외부 공표 전 단계, 극소수 임원만 접근
- 관리수준: 다중 잠금장치, 접근 로그 실시간 감시
- 유출 시 영향도: 회사 존립 위기, 대규모 소송, 시장점유율 급락

[작성 지침]
- M&A 협상 중인 기업명·조건, 핵심 기술 특허 출원 전 상세 명세, 차세대 제품 사양 등
- 임원 회의 의사결정 전 단계의 미공개 안건
- 본문에 "외부 공유 절대 금지", "임원진 4인 한정 열람" 같은 표현이 자연스럽게 포함
```

### S1 — 1급 비밀
```
[등급 정의: 1급 비밀]
조직 경쟁력에 중대한 영향을 미치는 정보로 유출 시 상당한 손해 발생.
- 경제적 가치: 높음 (사업부 매출의 20% 이상 영향)
- 비공지성: 사업부 단위 공유, 외부 미공개
- 관리수준: 부서 접근권한, 다운로드 시 결재 필요
- 유출 시 영향도: 경쟁사 이득, 손해배상 청구 가능성

[작성 지침]
- 사업 전략, 신제품 출시 계획, 가격 정책, 핵심 R&D 진행 상황
- 미발표 재무 추정, 주요 거래처 협상 내용
- 본문에 "대외비", "사업부 한정", "전략적 검토 단계" 표현 권장
```

### S2 — 2급 대외비
```
[등급 정의: 2급 대외비]
업무상 외부 공개가 부적절한 정보. 회사 운영·관계에 영향.
- 경제적 가치: 중간
- 비공지성: 일반 임직원 접근 가능, 외부 비공개
- 관리수준: 사내 시스템 내 일반 권한
- 유출 시 영향도: 평판 손상, 협상력 약화

[작성 지침]
- 내부 조직 개편안, 인사 이동안 초안, 일반 영업 데이터
- 일반 회의록, 내부 보고서, 거래처 평가 자료
- 본문에 "내부 검토용", "외부 공유 제한" 표현 권장
```

### S3 — 3급 공개
```
[등급 정의: 3급 공개]
대외 공개가 전제된 정보 또는 이미 공개된 정보.
- 경제적 가치: 낮음 또는 공개됨
- 비공지성: 공개 자료
- 관리수준: 일반 접근 가능
- 유출 시 영향도: 없음 또는 미미

[작성 지침]
- 보도자료, 공식 발표문, IR 공시 자료
- 공개 제품 카탈로그, 사외 교육 자료
- 본문에 "공식 발표", "공개", "보도자료" 표현 권장
```

## 2. 도메인별 문서 유형 후보

| 도메인 | 문서 유형 예시 |
|---|---|
| tech (기술/R&D) | 연구노트, 설계명세, 시험성적서, 알고리즘 설명서, 특허 출원 전 명세 |
| business (경영/전략) | 사업계획서, 시장분석 보고서, 투자제안서, 파트너십 검토 |
| finance (재무/회계) | 결산 초안, 자금조달 계획, 손익 추정, 투자 평가 |
| hr (인사) | 임원 평가, 보상 체계, 인사 이동안, 조직개편 |
| legal (법무/계약) | NDA 초안, MOU, 라이선스 계약 검토, 분쟁 대응 |
| mixed | 내부 보고서, 회의록, 의사결정 문서 |

## 3. 합성 운영 정책

| 항목 | 정책 |
|---|---|
| 등급별 생성 비율 | TS 27% / S1 33% / S2 27% / S3 13% (Test 분포는 운영 분포 반영) |
| 도메인 분포 | tech 30% / business 25% / finance 15% / hr 10% / legal 10% / mixed 10% |
| 길이 | 1,000~3,000자 (등급별 일정 — 길이 편향 방지) |
| LLM 혼합 | Claude 70% + Qwen3 30% (스타일 다양성 확보) |
| 검수 | 2명 이중 검수, Cohen's Kappa ≥ 0.75 목표 |
| PII 검증 | 정규식 + 검수자 재확인, 위반 시 폐기 |

---

## 4. 검수자 가이드 (요약)

1. **등급 적정성** — 본 프롬프트의 [등급 정의]에 부합하는가? (1~4점)
2. **자연스러움** — 실제 기업 문서로 보이는가? (1~4점)
3. **PII** — 실재 인명·기업명·주민번호·전화·이메일 없는가? (Pass/Fail)
4. **라벨 누설** — 본문에 등급명("특급기밀", "1급 비밀" 등) 직접 표기 없는가? (Pass/Fail)
5. **종합** — 학습 데이터로 채택 여부 (Approve / Reject / Re-grade)

**합격 기준**: 등급 적정성 ≥ 3점, 자연스러움 ≥ 3점, PII Pass, 라벨 누설 Pass
