## 사람 검수에 쓸 때

1. 검수자에게는 세트 폴더의 **`본문/`(0001.txt …, 번호는 섞인 순서)만** 줍니다. `정답표.csv`·`문서.jsonl` 은 정답이 들어 있어 주지 않습니다.
2. 본문 안에 등급 표기가 적힌 문서는 `정답표.csv` 의 `본문에_등급표기=1` 로 표시돼 있습니다. 학습셋 A 는 절반이 그렇습니다 — 검수가 아니라 확인이 됩니다.
3. 기존 엑셀 검수 도구(`scripts/export_golden_review_xlsx.py --gold <세트>/문서.jsonl`)에 이 폴더의 `문서.jsonl` 을 넣어 시험했습니다(20건, 결과는 리포 밖):
   평가셋 A → 워크북 생성(P1 18·P3 2) · 골든셋 B → 생성 · 학습셋 A → 생성(전건 P5=학습셋 포함, 평가 정답으로는 못 씀) ·
   **골든셋 A → 생성되나 `label` 키가 없어(`target`) 기계등급 `?`·우선순위 P4 로 나옵니다 — 키 이름을 맞추는 변환이 필요합니다.**
4. 워크북의 `기계등급(참고)` 열은 검수자에게 보입니다(시험 결과 첫 행 값 있음). 앵커링을 피하려면 열을 숨기는 결정이 필요합니다.
5. 회수는 `scripts/import_golden_review_xlsx.py` → `golden_signoff.promote_to_locked`(서명 승격)로 갑니다. 검수자별 배정 기능은 없습니다.
6. 학습셋 문서를 검수하면 라벨이 고쳐질 뿐 평가 정답이 되지는 않습니다. 골든셋·평가셋 문서를 검수한 뒤에는 그 문서를 학습에 넣지 않아야 블라인드가 유지됩니다.
