# 공정 변경 검토·승인 기록

| 항목 | 내용 |
| --- | --- |
| 문서번호 | MFG-CHG-2026-017 |
| 대상 공정 | HBM-E 적층 전 세정 단계 |
| 문서 상태 | 재검증 조건부 승인 / 양산 적용 보류 |
| 작성 부서 | 소자공정기술팀 |

| 개정 이력 | Rev.0 — 검증 결과 반영본 |

## 1. 변경 안건과 검토 범위

본 문서는 HBM-E 적층 전 세정 단계의 조건 순서를 변경하기 위한 검토와 승인 조건을 기록한다. 검토 대상은 세정액 농도, 분사 순서, 건조 대기 순서가 결합된 작업 조건이다. 개별 조건을 독립적으로 바꾸는 안이 아니라 세 조건의 조합과 적용 순서를 함께 조정하는 안이므로, 현행 작업 표준을 즉시 변경하지 않고 지정 로트에서만 검증했다.

변경 요청의 목적은 접촉저항 산포가 커지는 구간을 줄이고 재작업 및 원인 분석 시간을 낮추는 데 있다. 다만 이 문서에 포함된 조건 조합, 실패 구간, 적용 순서는 공정개발 과정에서 축적된 검증 결과와 결합돼 있다. 검증 목적과 무관한 복사·전달·외부 제공은 허용하지 않는다.

## 2. 적용 및 검증 결과

검증은 지정 로트에 한정해 진행했다. 착수 5주차에 기준 상태를 확인했고, 6주차에 변경 조건을 적용했으며, 7주차에 재검증을 수행했다. 검증 완료율은 변경 전 73%에서 변경 후 59%로 감소했다. 절대 차이는 14%p, 감소율은 19.2%다. 현재 관리 범위는 63~83%이며 변경 후 값은 하한 미만이다.

| 확인 항목 | 관찰 결과 | 검토 판단 |
| --- | --- | --- |
| 조건표와 장비 로그 | 일부 로트의 건조 대기 순서 기록이 누락됨 | 기록 보완 필요 |
| 접촉저항 산포 | 특정 조건 조합에서 확대됨 | 재검증 필요 |
| 원시 측정값 | 지정 작업공간에서 로트별 보관 확인 | 유지 |
| 장비 점검 이력 | 실패 로트 일부에서 점검 시점 미연결 | 원인 분리 불가 |
| 외부 공유 이력 | 확인되지 않음 | 현 통제 유지 |

실패 로트는 분사 순서와 건조 대기 조건이 함께 바뀐 구간에서 집중됐다. 그러나 같은 구간의 장비 점검 시점이 로그에 남지 않아, 조건 조합의 영향과 장비 상태의 영향을 분리할 수 없었다. 일부 로트의 표면 상태가 안정적으로 관찰됐더라도 이를 변경안의 효과로 확정하지 않는다.

## 3. 자료 관리와 접근 통제

조건표 원본, 원시 측정값, 장비 운전 로그는 서로 다른 저장 위치에 보관하되 동일한 변경 요청 번호와 로트 식별자로 연결한다. 조건표 발췌본에는 문서번호와 배포 대상을 표시하고, 원본의 수정 이력은 삭제하지 않는다. 구두로 전달된 조건 변경이나 사후 추정으로 보완한 기록은 검증 근거로 사용하지 않는다.

열람 권한은 공정개발·품질보증의 지정 인원과 검토에 참여한 제조기술 담당자에게만 부여한다. 추가 열람, 출력, 외부 반출 요청은 목적·수신자·제공 범위를 기록한 뒤 공정개발 파트장과 보안운영 책임자의 공동 확인을 받아야 한다. 검토 종료 뒤에는 업무상 필요가 끝난 계정의 권한을 회수한다.

## 4. 검토 의견 및 결정

품질보증팀은 관리 하한 미만 결과와 점검 이력 누락이 해소되기 전에는 양산 적용을 승인할 수 없다고 판단했다. 제조기술팀은 재검증 중 현행 작업 표준과 변경안이 현장에 혼재되지 않도록 별도 작업 지시를 사용하기로 했다. 보안운영팀은 검증 자료가 기존 권한 체계 안에서 관리되고 있으며, 회의 자료와 조건표가 외부 메일 또는 협력사 포털로 전달되지 않았음을 확인했다.

결정은 재검증 범위에 한한 조건부 승인이다. 이 결정은 양산 적용 승인이나 조건표의 일반 배포 승인이 아니다. 재검증 결과가 정상 관리 범위에 들어오더라도 원시 측정값·장비 로그·점검 이력이 같은 로트 식별자로 연결되지 않으면 다음 승인 안건으로 올리지 않는다.

## 5. 후속 조치와 종료 기준

| 조치 | 담당 | 완료 확인 기준 |
| --- | --- | --- |
| 장비 점검 이력 보완 | 제조기술팀 | 실패 로트별 점검 시점과 작업 로그 연결 |
| 재검증 계획 갱신 | 공정개발팀 | 비교 조건, 적용 로트, 개정 번호 명시 |
| 결과 및 원시값 대조 | 품질보증팀 | 관리 범위 판정과 로트 식별자 확인 |
| 권한·반출 이력 확인 | 보안운영팀 | 추가 열람 및 외부 제공 이력 검토 |

재검증 종료 후 공정개발팀은 적용·미적용 로트 목록을, 품질보증팀은 결과 판정 근거를, 제조기술팀은 작업 표준 영향 검토서를 제출한다. 세 자료가 같은 문서번호를 참조하고 상충이 없을 때에만 별도 양산 승인 안건을 제출할 수 있다. 위 조건이 충족되지 않으면 이번 조건부 승인은 종료되고 변경안은 현행 절차로 되돌린다.
