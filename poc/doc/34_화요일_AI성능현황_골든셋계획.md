# AI 등급분류 — 성능 현황 및 90% 로드맵 (화요일 협의자료)

> 현재 **PoC/설계 단계** 기준. 90% 정확도는 본개발(실데이터·골든셋)에서 확정.

## 1. 한 줄 요약
정본 가이드 **B안(등급 = 비공지성 S × 경제유용성 V × 비밀관리성 M)** 기반 분류 파이프라인을 구축·검증했고,
학습데이터 품질 문제를 능동 발견·교정했으며, **90%는 실데이터로 본개발에서 도달**하는 단계적 계획입니다.

## 2. 성능 현황 — 단일 숫자가 아닌 "구간별"
| 문서 유형 / 등급 | 정확도·재현율 | 의미 |
|---|---|---|
| 정형·명확 문서(규정·공개특허·지정기술) | **95%+** | 이미 운영 수준 |
| 특급기밀(TS) 재현율 | **81%** (정제 test 기준 더 높음) | 보안 핵심 등급 양호 |
| 3급 공개(S3) 재현율 | **86%** | 공개 신호 명확 |
| 실 비즈니스 문서 종합(홀드아웃 90건) | **76%** (F1 0.74) | 현 PoC 실데이터 baseline |
| 1급↔2급 경계 | **60%대** | 회색지대 — 사람도 갈리는 영역, 검수 보강 |
| **고등급 미탐율(FNR)** | **8%**(정제)~20%(실), 하강 관리 | 보안상 최우선 지표 |

→ 정형·특급·공개는 신뢰 가능, **중간등급·실문서 도메인**이 90% 도달의 핵심 과제.

## 3. 데이터 품질 — 능동 발견·교정 (신뢰성 근거)
- 학습데이터 점검 중 **56%(3,320건)가 법률 판례·심결**, 그중 **2,210건이 비밀등급으로 오라벨**됨을 발견.
  - 공개 법원문서를 "기밀"로 학습 → 도메인 불일치 + 라벨 오류.
- **교정(ablation으로 검증)**: 법률코퍼스 제외 시 **비즈니스 정확도 67→76%↑, 정제 test 93%, 고등급 FNR 21→8%**.
- → AI를 블랙박스로 두지 않고 **데이터 품질을 정량 검증·개선**하는 체계를 갖춤.

## 4. 골든셋 구축 — 본셋 500건 생성 완료(검수 전), 1,000건 확장은 8월
- **현황(완료)**: 회사 내부형 문서 **500건 생성**(TS·S1·S2·S3 각 125, 12개 도메인 — 반도체·금융·M&A·바이오·국방 등) + **판단근거 대장**(문구→S/V/M→등급, **곱↔등급 500/500 정합**) + DOCX/PDF 형식 변환·재추출 검증(파일럿 단계).
- **객관성 확보 방식**: 각 문서의 등급을 *정본 가이드 기준 문구*로 추적 + 독립 판독 + **불일치(500건 중 354건)는 전문가 검수**(검수시트 제공).
- **본셋 1,000(8월)**: 500 → 1,000 확장 + S1↔S2 경계·금융 도메인 집중 보강 + 실데이터. **검수 단계에 발주처 문서 전문가 참여 제안**(자체 채점 아닌 합의된 검증 기준).

## 5. 90% 로드맵 (계약 일정 정렬)
| 시점 | 내용 |
|---|---|
| 현재(PoC) | 방법·파이프라인·데이터품질 검증 (실 비즈니스 76%) |
| 7~8월 | 골든셋 1,000건 + 실데이터 보강 → 설계감리 |
| 종료감리 | 실데이터로 90% 측정 + QA버퍼 |

## 6. 화요일 발주처 확정 요청
1. **산정법**: B안(S×V×M) 채택 확인 (A안 5요소는 회원사 자가진단 보조)
2. **특급기밀**: 자체분류(희소) 처리 방식
3. **판례 등 공개 법원문서**: 영업비밀 분류 대상 제외 동의
4. **골든셋 검수**: 발주처 문서 전문가 참여 (객관성)
5. **API 연계·문서 형식**: HWP 처리 범위/샘플 제공
