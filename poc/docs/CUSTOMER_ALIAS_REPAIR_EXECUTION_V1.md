## 교정 규칙

변환기는 등급·정답을 입력으로 받지 않는다. 이미 발견한 TS 전용 비정책 별칭 표식이 교정 대상이다.
전체 64개에서 단일 영문 대상 별칭을 조사하고, 단위·약어·서로 비교하는 별개의 대상은 구별한다.
문서 안의 단일 대상 후보에 한하여 별칭 문자를 제거하는 진단뷰를 만들고 기존 한국어 명사·조사를 자연스럽게 유지한다.
새로운 ‘대상/해당/첫째’ 등 반복 접두어를 넣어 대체 등급 단서를 만들지 않는다.

모든 변경에는 부모 ID/본문 지문·원문 위치·before/after·이유를 기록한다.
다중 대상의 구별을 합치거나, 확인하지 않은 약어/단위/숫자를 삭제하지 않는다. 모호하면 실패/보류한다.
변경 구간 밖 바이트, 제목, 숫자열, 부정·조건 표현, 관리/공개/투입 맥락, 정책, 참조 등급, 배제 이유는 보존한다.
변경된 근거 문구는 새 본문 위치에 다시 결합하되 ‘수정했으니 의미가 완전히 같다’고 자동 인증하지 않는다.

변경본만 새 문서 ID/입력 지문을 얻는다. 동일한 원문/사례/표현 계열은 유지한다.
미변경 부모는 기존 ID/입력/정답을 그대로 사용한다. 부모-자식 이력은 별도 파일로 둔다.
진단에 사용하는 뷰는 기존196+변환패널64=260개다. 원본과 변환본 파일 수를 합쳐 신규 문서 수로 세지 않는다.
원본이 여전히 정본이다. 아래 독립 검토로 변환뷰의 답안 채택과 원문 대체는 금지한다.

### 동결 전 독립 검토에 따른 범위 정정

B가 전체 수정 대상 본문을 읽어, 단일 별칭이라도 삭제하면 적용 대상 식별을 잃을 수 있음을 지적했다.
특히 ‘이번 결과는 기질 배치 M에 한정’에서 M을 지우면 제한 대상이 덜 명확해진다.
분말·분할·구역에서도 특정 대상 관찰이 일반 명사에 관한 규칙처럼 읽힐 위험이 있다.
이는 숫자·정책·맥락 불변 검산만으로 해결되지 않는다.
따라서 이번 변환은 **제한적인 별칭 제거 진단**으로만 실행하며 안전한 원고 교정 성공으로 발표하지 않는다.
`target_binding_not_certified=true`, `adoption_allowed=false`, `authoritative_parent_replaced=false`를 유지한다.
진단 점수를 보고 같은 판본을 다시 고치지 않는다. 대상 정체성을 보존하는 별도 설계와 검산이 후속 과제다.

## 진단 사전 조건

교정 소스와 팩을 고정한 뒤 실제 문자 진단을 실행한다. 결과 점수에 맞춰 같은 판본을 반복 수정하지 않는다.
교정 전에 정한 같은 260개 부모·236그룹·5seed×5fold를 모든 비교에 사용한다.
TF-IDF는 각 학습 fold 안에서만 적합하며 원문/교정본 부모가 fold를 넘지 않는다.

본문 전용과 본문+맥락 각각에서 다음 네 칸을 구분한다.

| 학습 입력 | held-out 원문 | held-out 교정뷰 |
| --- | --- | --- |
| 원문 | 기준 관측 | 입력 표식 교정의 민감도 |
| 교정뷰 | 교정 학습이 원문에 미친 영향 | 교정 학습+교정 입력 |

샘플 수·참조 답·그룹·분할·학습 설정은 같고 텍스트의 승인된 별칭 교정만 다르다.
64부모×5seed 전체와 실제 변경 부모×5seed를 각각 보고한다. 반복 관측을 독립 문서 수로 부르지 않는다.
미변경 패널과 기존196도 대조군으로 구분한다. 학습 입력을 바꾼 경우 미변경 문서 예측까지 바뀔 수 있다.
예측 변경, 참조 일치의 증가/감소, 등급별 혼동을 모두 남긴다. 낮은 점수만으로 원고 품질 합격을 판정하지 않는다.
이 진단기는 고객 모델이 아니며 본문만으로 식별 불가능한 조건부 등급의 실제 정확도를 증명하지 않는다.

## 노출과 품질 상태

기존 노출 원장 260행을 수정/삭제하지 않고 실제 변경본만 새 지문으로 append한다.
원장 이벤트 수와 활성 문서 수를 분리한다. 의미 연결은 교정 ID로 대응시켜 보존하고 전수 평가 제외를 검증한다.
모든 활성 260개는 여전히 개발에 노출됐으므로 최종 미노출 200개에 배정하지 않는다.
원장 pin 누락/오류, 부모 누락, 같은 ID의 다른 본문, 자식 ID 재사용, 관계 손실은 실패 처리한다.

한 종류의 별칭 표식이 사라졌다는 사실과 전체 작성 편향 해결은 다른 결론이다.
이 실행에서 확인할 수 있는 상태는 ‘진단뷰에서 알려진 표식 제거’와 ‘확인한 불변조건 통과’다.
기존 전체 작성 품질 보류·미승인 사용 플래그를 자동으로 해제하지 않는다.
광범위한 형식·어휘·주제 편향, 비산술 문서, 장문, 사실 추출, 별도 시험팩 채택, 800/200 시험은 별도 남은 일이다.
