# S·V·M 제거 비교 실측 — 2026-09-14

## 결론

현재 코드와 로컬 기준 모델 `classifier_p1_v5_clean/v-fe4b386b`로 5개 평가셋
601행(공백 정규화 본문 기준 559개)을 비교했다.

- **S·V·M 숫자 산정과 숫자 요소 전달을 제외해도 최종 등급·점수·검수 상태 변경은 0건이었다.**
- 제거만으로 라벨 일치도가 좋아지지도 않았다. 이번 범위에서는 숫자 단계의 분류 기여를 관측하지 못했다.
- 규칙 불일치 검수까지 끄면 등급은 그대로인 채 일부 오답도 검수에서 빠졌다.
- 모델 직접 분류는 일부 평가셋에서 기존 라벨 일치도가 낮아졌다. 규칙 보정 전체 제거와 S·V·M 숫자 제거는 다르다.
- **독립적인 실제 S/V/M 정보를 학습·입력한 모델의 효용을 시험한 것은 아니다.**
  기존 모델의 학습 라벨에 S/V/M 기반 판단이 반영되어 있을 가능성까지 제거한 실험도 아니다.

운영 활성 모델은 조회하지 않았다. 이 결과는 현재 체크아웃 코드와 지정한 로컬 체크포인트의
진단 결과이며, 고객사 정확도·운영 배포 승인·모든 문서에서의 동등성을 증명하지 않는다.
