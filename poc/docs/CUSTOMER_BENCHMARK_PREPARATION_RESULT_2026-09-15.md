# 고객사800/200 시험 준비 — 첫 집필·분할·채점 도구 결과

2026-09-15. 사용자가 우리가 합성 문서를 제작하고 고객사가800건을 학습한 뒤200건을 평가한다고 설명한 후 '진행해'를 요청했다.

## 결론과 현재 수량

**제작을 시작했고, 준비 도구와 별도 집필 초안12건을 만들었다. 1,000건 제작이나 골든셋200건 확정은 완료하지 않았다.**
채점 정책은 원 가이드 기반/내부 내용보호/고객 별도 기준 중 선택을 질문한 상태이며 아직 응답을 받지 않았다.
그 사이에 공통 제작·중복·분할·입력 분리·채점 계약을 구현했다. 기준 차이를 임의로 승인하지 않았다.

| 항목 | 현재 |
|---|---:|
| 제작 목표 | 학습800 + 평가200 |
| 새 집필 초안 | 12 |
| 본문에 연결한 주장 근거 | 24 |
| 의미 검산을 통과한 신규 등급 정답 | 0 |
| 학습 채택 / 평가 채택 | 0 / 0 |
| 실제 모델 학습·분류 평가 | 미실행 |

사용자가 평가400건 증량을 확정하지 않았으므로800/200을 유지했다.
전체 목표의 등급 구성은 TS/S1/S2/S3 각각 학습200/평가50이다. 실제 제작 원고를 검산해 채택해야 이 수량에 반영한다.

## 이번에 작성한 문서

한 가지 카드의 숫자만 바꾸는 생성기를 돌리지 않고, 서로 다른 업무 상황12개를 별도로 집필했다.
문서 길이는 제목 포함370~416자다. 아직 장문·표·첨부·복잡한 문서군을 충분히 포함한 자료가 아니다.

| 영역 | 원고 |
|---|---|
| 제품개발 | 분류 이송대 속도 보정안 / 받침 프레임 시제품 조립 기록 |
| 연구시험 | 광량별 감지 지연 측정표 / 포장 완충재 복원 시험 순서 |
| 제조품질 | 수성 표시액 배합 시험 기록 / 검사 지그 위치 차이 조사 |
| 구매계약 | 운반 상자 견적 비교 메모 / 입고 시간대와 확인 순서 안내 |
| 영업사업 | 유지보수 갱신 제안 계산 / 시연용 보관함 사용 문답 |
| 인사운영 | 교육장 설치와 복구 담당표 / 장비 인수 확인 양식 |

원문 TXT는 [제작 팩](../reports/CUSTOMER_BENCHMARK_20260915/preparation_v1/README.md)의 `documents/`에 있다.
출처는 합성이며 실제 고객 문서·비밀·인증정보를 사용하지 않았다. 맥락의 공개/관리/사업영향 등은 unknown으로 남겼다.
근거24곳은 인용과 문자 위치/해시를 검사한 것이다. 주장 전체의 의미나 현실 진위·등급을 인증한 것은 아니다.
정책 결정 뒤 필요한 가상 조건을 명시하고, 본문 사실 검산과 등급 기준을 연결해야 한다.

답안은 한 정책 ID/버전/해시에 속해야 하고, 입력 해시와 근거 참조가 맞아야 한다.

### 800/200 분할 제안

원문/사례/표현 계열 및 근접중복 관계의 전이적 연결 성분을 같은 분할로 묶는다.
정수계획법으로 평가 각50/학습 각200을 동시에 맞추고, 불가능하거나30초 내 풀리지 않으면 실패한다.
수량을 맞추려고 계열을 쪼개지 않는다. seed를 사용하지만 독립 균등 무작위 추출은 아니다.
실행 환경/solver 버전과 최종 분할 지문을 보존해야 한다.

테스트에서는 무의미한 무작위 문자열1,000행·250계열로 정확한800/200 분할을 검증했다.
**이1,000행은 코드 테스트 입력이며 고객사 문서로 저장·채택하지 않았다.**
현재12건에는 등급이 없으므로 실제 고객사 분할은 실행하지 않았다.

### 채점

- 전체 정답 수를 분모로 원시 등급 일치율과 상태ok인 일치율을 별도 보고한다.
- needs_review/error/missing을 분모에서 빼지 않는다. error에 가짜S3 등급을 넣지 않는다.
- 등급별 재현율/정밀도/F1, S1↔S2, S2→S3, TS/S1→S3, S3 과분류, 검토율/고등급 미해결을 분리한다.
- 중복/추가ID·입력/정책 해시 불일치·모델/실행 혼합을 거절한다. 누락·오류 응답은 미완료 실행으로 표시한다.
- 상태ok 비율은 사람 최종확정률이 아니다. 보고서의 모델 해시는 제출값이며 실제 모델 가중치 실행을 증명하지 않는다.

정답과 같은 예측을 넣는200행 시험은 채점 산술 확인이다. 신규 고객사 분류 일치율이나100% 모델 성능을 측정한 것이 아니다.
기존 DB 의존 평가기와 최저등급 오류 치환 경로는 변경하지 않고, 새 오프라인 채점기에서 오류 열을 별도 유지했다.

## 다음 진행에 필요한 결정과 남은 일

**가장 먼저 채점 정책을 선택해야 한다.** 원 가이드 기반 기준안/별도 내부 내용보호 기준/고객 제공 기준 중 어느 것인가?
권고 출발점은 기존 D01/D02 검토안의 원 가이드 기반이다. 숫자 S/V/M을 사용자 필수 입력으로 요구한다는 뜻은 아니다.
필요한 요소와 가상 근거를 명시하고, 운영 기본값 변경 없이 이번 합성 시험의 단일 정책으로 버전 관리한다.

그 다음 순서:

1. 선택한 정책의 충분조건·경계·예외와 필요한 가상 맥락을 문서로 고정한다.
2. 새 원고의 사실/관계/수식을 별도 검산하고 근거 있는 등급 답안을 작성한다.
3. 부족한 업무 상황·문체·판정 경계를 실제로 집필하여1,000건 목표를 채운다. 현재의12건 채택 여부도 검증 후 결정한다.
4. 풀 스캔의 지원 범위 공백, 전체 문체 지름길·근접중복, 모델 입력 적합성을 점검한다.
5. 그룹 단위800/200을 고정하고 정답200을 학습/튜닝에서 격리한다. 고객사 시험 프로토콜 채택과 새 배포 경로를 준비한다.
6. 학습/실제 분류 평가를 실행한 뒤 일치율을 보고한다. 현재는 그 수치를 예측하거나 발표하지 않는다.
