# 합성 문서형 후보 v1.1 — 입력·근거·검증 계약

적용 정책: `content-protection-reference-v1.1-draft`. 미승인 오프라인 계약이다.
기존140건은 보존하고 개발부의 수정 후보40건만 새 ID/본문/맥락/답안으로 연결한다.
새40건은 원본과 본문이 다르므로 **동일 본문 라벨만 바꾸는 A/B 자료가 아니다**.

## 파일과 결합

- `inputs.jsonl`: doc_id, family_id, text, text_sha256, context, context_sha256,
  policy_version, policy_sha256, source. 등급·정답 규칙·만족 플래그 없음.
- `answers.candidate.jsonl`: 입력 레코드/본문/맥락 해시, parent_doc_id/원답 해시,
  두 입력 관점의 후보 답, 규칙·위치·상하위 배제 이유, 검토/권위 상태.
- `lineage.jsonl`: 기존 개발 계열과 새 버전의 연결, 학습 금지, 분할=development_only.
- `impact50.jsonl`: 기존 유지40/검토10의 개정 영향과 필요한 후속 증거. 원래 답안을 덮지 않음.
- `legacy_followup4.jsonl`: 양쪽 원라벨/해시를 유지한 새 제안·필요 증거. 소급 정답 아님.
- `manifest.json`, `validation.json`, `preservation.json`: 버전·지문·구조 검사·원본 보존 결과.

모델에 전달할 텍스트는 `model_input(doc, view)` 함수 한 곳에서 만든다.
본문 관점에는 본문만, 맥락 관점에는 동일 본문과 문서 해시에 결합된 맥락만 제공한다.
계열ID, 부모ID, 기대등급, 규칙, 근거 해설, 생성 유형은 모델 문자열에 넣지 않는다.
두 관점은 서로 다른 입력 해시를 갖고 각각의 답안만 사용할 수 있다.
후속 예측 레코드에는 doc_id, view, input_sha256, policy_version/sha256이 필요하다.
이 계약으로 기존 평가기/API가 자동 호환된다는 뜻이 아니다. 어댑터는 이번 미구현이다.

## 맥락의 출처와 범위

맥락은 `world=fictional_only`, 판본, 기준일, 본문 해시와 `facts`를 가진다.
사실은 `{state, value, origin, source_ref}` 형식이다. 이번 source_ref는
`fictional-author://...`로, 사람 서명/시스템 검증이 아닌 작성자의 명시적 허구 정의다.
`verified_context`는 실제 증거·제공자·유효시간을 확인한 향후 데이터에만 허용한다.

범위 완전성, 배포 상태, 핵심 기능 범위, 개인정보 연결, 통제 권한은 본문과 다른 사실이다.
이 사실을 모델에 숨기고 TS/S1 정답만 요구하지 않는다. 본문 표가 있다는 관찰과
그 표의 식별 가능성/현행성 같은 맥락은 별도 근거로 연결한다.
가상 개인 번호는 현실의 개인정보가 아니고, `DEMO-ONLY` 값은 현실의 비밀값이 아니다.
공통 시험 지시문은 **허구 세계의 보호 필요를 판단한다**는 것이다.
body_only의 보류 정답도 이 시험 질문에 한정되며 공개 예제 자체가 위험하다는 뜻이 아니다.

## 문서형 보완 내용과 한계

- 재현 묶음12: 계열별 단순한 수치 모형의 명세·결정 변수·입출력 시험값을 직접 수록한다.
  허구 세계의 제품 역할만 맥락으로 선언한다. 실제 공장/제품을 재현한다고 주장하지 않는다.
- 대량 원장5: 총6,000개 허구 개인의 실제 행을 생성한다. 계열별1,400/1,060/1,080/1,240/1,220명.
  프로그램이 표를 다시 읽어 행 수와 고유 개인 수·연결 필드를 검증한다. OCR/추출 성능 시험은 아니다.
- 통제 묶음3: 현실에서 작동하지 않는 데모 값과 대상/권한/유효기간을 입력 맥락으로 제공한다.
  검증은 로컬 문자열·메타데이터 검사만 한다. 실제 인증·서명·네트워크 접근 없음.
- S1 20: 개인 소수 행, 제품 시험표/코드 일부, 실제 형태의 협상조건을 수록한다.
  빠진 첨부를 추정하지 않는다. 부분 보고서 자체가 판정 범위라는 허구 조건을 별도로 명시한다.

전체 첨부가 누락된 문서와 완결된 부분 보고서는 다르다. 전자는 범위 미확인 보류,
후자는 그 보고서에 한정해 부분 보호정보를 판단한다.
40건은 폭넓은 문체/장문/실제 업무 위험을 대표하지 않으며 같은 AI 작성자의 교육용 후보다.
템플릿 공유와 명시적 맥락은 학습 지름길이 될 수 있으므로 고객사 정확도로 사용할 수 없다.

## 검증 및 학습 분리

ID/본문/맥락/정책/근거 위치/부모 연결/권위 필드를 검증하고, 중복 인원·999/1000·
필수 맥락 제거·동일 판본 충돌·만료/추가 인증 조건을 단위 시험한다.
수치 모형은 허용된 순수 연산만 검산한다. 문서 안의 코드를 exec/eval 하거나 파일/네트워크 작업을 하지 않는다.
이 검산은 사실 추출 모델도 독립 정답 심사도 아니다.

같은 개발 계열 안에서만 보완한다. 봉인후보는 내용을 읽지 않고 원본 해시만 확인한다.
기존 학습 풀의 본문 중복은 별도 집계하고 계열ID 부재에 따른 의미상 중복 미검증을 표시한다.
대량 표를 기존 분류기 길이에 맞춰 자르면 입력 해시/증거 범위가 바뀌므로 전체 문서 정답을 그대로 쓰지 않는다.
본문+맥락40건의 등급 평가는 TS/S1에만 한정되어 S2/S3·전체4등급 성능을 대표하지 않는다.
승인 전 학습 export, 서명, GOLD 승격은 금지한다. 자동 배포·모델 교체 없음.
