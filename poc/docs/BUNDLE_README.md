# Koipa AI 설치 번들 — 먼저 읽는 한 쪽

이 폴더 하나로 설치가 끝납니다. 인터넷 연결은 필요하지 않습니다.
아래 세 줄을 번들 루트(이 파일이 있는 폴더)에서 순서대로 실행합니다.

## 설치

| 순서 | 명령 | 하는 일 |
|---|---|---|
| 1 | `bash preflight_host.sh` | 서버가 설치 조건을 갖췄는지 점검합니다. 아무것도 바꾸지 않습니다. 차단 항목이 나오면 출력된 조치를 먼저 합니다. |
| 2 | `bash verify.sh` | 반입한 파일이 온전한지 확인합니다. `Checksums OK` 가 나와야 다음으로 넘어갑니다. |
| 3 | `sudo bash setup.sh` | 이미지 적재·설정·DB·기동·검증을 자동으로 진행합니다. 비밀값도 스크립트가 만들므로 `.env` 를 손으로 고치지 않습니다. |

서버 종류는 `setup.sh` 가 스스로 판별합니다. 직접 지정하려면 다음과 같이 씁니다.

```bash
sudo NODE=jjw      bash setup.sh   # 지재원 서버 (전문가 검수 노드)
sudo NODE=customer bash setup.sh   # 고객사 서버 (운영 노드)
```

## 설치가 끝나면

설치 완료 안내에 열 주소와 로그인되는 계정이 출력됩니다. 주소만 열면 자동으로 로그인됩니다.

| 서버 | 열 주소 (`<서버주소>` 는 이 서버의 IP, 포트 8000 은 기본값) | 화면 |
|---|---|---|
| 지재원 | `http://<서버주소>:8000/api/v1/golden/candidates/manage.html` | 전문가 검수 화면 — 검수할 문서 1,711건이 보여야 합니다 |
| 고객사 | `http://<서버주소>:8000/console/admin.html` | 관리 콘솔 |

설치 상태를 다시 확인하려면 `bash verify_install.sh` 를 실행합니다. 서비스 준비 상태와 문서 한 건의 파싱·분류를 확인합니다.

이 주소는 로그인 입력 없이 열리므로, 허용된 사람만 접속할 수 있는 망에서만 여십시오. 외부에서 닿는 서버라면 방화벽이나 VPN 으로 접속을 제한하여 주시기 바랍니다.

## KL 포털 연동에 필요한 값

| 항목 | 내용 |
|---|---|
| 호출 주소 | `http://<서버주소>:8000/api/v1` (포트는 설치할 때 정한 값) |
| 인증 방식 | 요청 헤더 `X-API-Key` 에 API 키를 넣습니다. |
| API 키 위치 | 번들 폴더의 `.env` 파일 안 `API_KEY=` 줄입니다. root 만 읽을 수 있습니다. |
| API 키 확인 | `sudo grep '^API_KEY=' .env` (번들 폴더에서 실행) |

API 키는 설치기가 만듭니다. 손으로 입력하거나 화면에 붙여넣을 곳은 없고, 설치 마지막의 `설치 확인 PASS` 가 키의 적용까지 확인합니다. `setup.sh` 를 다시 실행해도 `.env` 가 있으면 같은 키를 유지합니다.
