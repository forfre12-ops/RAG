`lloydk -> koipa` 리네임(2026-08-12)이 서버 쪽에 세 개의 잔재를 남겼고, 셋 다
**배포를 실제로 실패시켰다.** 223 서버에서도 같은 순서로 터진다.

```

                     "Missing workspace member koipa-ai" 로 죽었다
                     -> 락파일 동기화

2. 외부 볼륨          compose 가 koipa_hf_cache 를 요구하는데 서버엔 lloydk_hf_cache
                     -> koipa_hf_cache 생성 + 2.8GB 모델 캐시 복사(재다운로드 회피)

3. 환경변수 이름       코드가 KOIPA_AUDIT_CHAIN_SECRET 을 읽는데 .env 는 LLOYDK_ 접두
                     -> API 가 startup 에서 죽었다(production 자격증명 누락)
                     -> KOIPA_ 이름을 추가(기존 LLOYDK_ 은 되돌림용으로 보존)

```

```

  poc/uv.lock poc/pyproject.toml poc/docker-compose.yml poc/docker-compose.prod.yml \

# ⚠ 위 §2 의 세 잔재를 **먼저** 확인할 것
grep -c KOIPA_AUDIT_CHAIN_SECRET .env*        # 0 이면 추가해야 한다

                     --build-arg KOIPA_BUILD_AT=$(date -u +%Y-%m-%dT%H:%M:%SZ)
docker compose up -d --no-build
curl -s localhost:8000/api/v1/healthz | python3 -c "import json,sys;print(json.load(sys.stdin)['build'])"
```
