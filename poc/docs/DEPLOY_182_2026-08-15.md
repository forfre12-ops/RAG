### 배포 중 걸린 것 — 프로젝트 이름

`deploy_testserver_dual.sh` 헤더는 `koipa-jjw`/`koipa-cust` 인데 **실제 서버에 도는
스택은 `lloydk-jjw`/`lloydk-cust`** 다(리네임 전 이름 그대로). 내가 헤더대로 새 프로젝트로
올려서 컨테이너·볼륨 세트가 중복 생성됐고, 포트 충돌로 API 만 안 떴다.

```
증상   Bind for 127.0.0.1:8000 failed: port is already allocated
원인   기존 lloydk-jjw-api-1 이 그 포트를 정상 점유 중
```

⚠ 이때 `docker ps | grep koipa` 로 확인해서 **기존 스택이 안 보였고** 서비스가 내려간
   줄 알았다. 실제로는 둘 다 healthy 였다. 필터가 만든 오진이다.

조치: 중복 `koipa-*` 스택을 `down -v` 로 제거(방금 생성된 빈 볼륨이라 데이터 없음),
이미지 6개 태그를 `lloydk-*` 로 찍고 기존 프로젝트에 `up -d --no-build`.

```
⚠ 빌드는 기본 프로젝트명으로 돌아 koipa-poc-{api,worker,beat} 를 만든다.
   배포 전 반드시 lloydk-{jjw,cust}-{api,worker,beat}:latest 로 태그해야 한다 - 6개다.
```

롤백 태그를 새로 남겼다(직전 8/15 1차 빌드).

