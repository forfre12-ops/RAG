# 규칙을 잘못 써서 실패를 세 번 과장했다 — 그리고 무언급 unknown 이 실제로 통했다

작성 2026-08-14. 실데이터 탐침 세 회차의 정정과 결과다.

---

## 1. 내가 잘못 잰 것

실데이터 판정을 **저술 규칙(`grade()`)** 으로 하고 있었다. 그 규칙은 unknown 을 0 으로
계산한다 — **데이터를 만들 때 쓰는 값**이지 서빙에서 사람에게 보이는 등급이 아니다.

서빙 등급은 `serving_grade()` 이고 unknown 을 최악값으로 채운다. 내가 8/14 에 직접
만들어 놓고 판정에는 안 썼다.

```
같은 예측                    grade()   serving_grade()
S=unk  V=lv2 M=lv2             S3          TS
S=lv2  V=unk M=lv2             S3          TS
S=absent V=lv2 M=lv2           S3          S3
```

그래서 unknown 이 늘어도 등급이 안 바뀌는 것처럼 보였고, 세 회차를 "실패" 로 보고했다.

## 2. 정정된 수치 — 경화42 (고등급 26건)

```
모델      등급일치  과소분류  S3추락   변경 내용
v8_bal    0.3333   0.4615     12    7차. 삽입형 도입 전
v8_nf     0.3095   0.6154     12    무요소 문서 -> **악화**
v8_inl    0.3333   0.5000     11    삽입형 + 실질 내용 -> 소폭
v8_nm     0.3333   0.3462      9    무언급 unknown -> **최선**
```

앞서 보고한 "고등급 100% 과소분류" 는 저술 규칙으로 잰 값이다. 서빙 규칙으로는 7차 모델도
이미 46.2% 였다. **"100% -> 34.6%" 가 아니라 "46.2% -> 34.6%"** 다.

---

## 3. 그래도 개선은 실재한다

무언급 unknown 이 과소분류를 46.2% -> 34.6% 로 낮췄다. 요소 예측도 방향이 맞다:

```
경화42 secrecy   absent 13 -> 9   ·  unknown 18 -> 28
       value     absent 14 -> 12  ·  unknown 17 -> 21
```

근거 없이 "부재가 입증됨" 이라 단언하던 것이 줄고 "모른다" 가 늘었다. 그리고 모른다고
답하면 서빙 규칙이 안전측으로 올려 검수로 보낸다.

무요소 문서(v8_nf)가 오히려 악화시킨 것도 확인됐다 — 요소만 빼고 내용을 안 넣어 "빈 문서"
를 만들었고, 빈 문서는 이미 S3 로 배운 상태였다.

---

## 4. 왜 곱셈 규칙에서 absent 와 unknown 의 차이가 등급을 가르는가

```
S  V  M   등급
2  2  2   TS     전부 확정
0  2  2   S3     S 만 0 -> 무너짐
2  0  2   S3     V 만 0 -> 무너짐
2  2  0   S1     M 만 0 -> 견딤
```

S 나 V 가 `absent` 로 떨어지면 M 을 아무리 잘 맞혀도 S3 다. 같은 자리가 `unknown` 이면
보수적 완성에서 2 로 채워져 고등급이 된다. **한 요소의 상태 하나가 등급을 완전히 가른다.**

실제로 경화42 고등급 문서를 보면 두 요소는 맞히고 하나가 무너진다:

```
[S1] M&A 실사        S=absent  V=lv2  M=lv2   S 가 0 이라 곱 0
[S1] 금융 리스크 모델  S=lv2  V=absent  M=lv2   V 가 0 이라 곱 0
[TS] 레이더 알고리즘   S=lv2  V=absent  M=lv1   V 가 0
```

---

## 5. 남은 문제

과소분류 34.6% 는 여전히 높다. 9건이 S3 로 떨어진다. 그리고 서빙 규칙으로 올린 결과
**과분류가 늘어 등급 일치율은 0.3333 에 머문다**(TS 24건 예측 · 정답 TS 12건).

즉 지금 상태는 "모르면 다 TS 로 올린다" 에 가깝다. 안전하지만 검수 부담이 크고 자동확정은
거의 불가능하다. 실측: 경화42 에서 tau 0.99 자동확정 0건.

정직한 도달점은 이렇다:

```
합성 판정면      자동확정 48~76% · 미탐 상한 0.012~0.015
실문서(경화42)   자동확정 0% · 과소분류 34.6% · 등급 일치 33%
```

**합성에서 되는 것이 실문서에서 안 된다는 결론은 그대로다.** 다만 미탐 방향은 개선됐고,
"모르면 안전측" 규칙이 작동한다는 것은 확인됐다.

---

## 6. 교훈

같은 예측이라도 **어느 규칙으로 읽느냐에 따라 등급이 달라진다.** 규칙을 만들어 놓고 판정에
안 쓰면 개선이 안 보이고, 없는 실패를 보고하게 된다. 세 회차를 그렇게 낭비했다.

판정 도구는 만든 즉시 판정 경로에 연결해야 한다.
