# 실문서 S3 후보 채택 기준 — 학습 **전에** 고정한다

작성 2026-08-16, 학습 시작 직후. **결과를 보고 기준을 정하면 그것이 기준 이동이다.**
오늘 릴리스 게이트 판정 단위를 바꾸면서 같은 의심을 받았고, 그때는 두 숫자를 모두 남기는
것으로 답했다. 이번에는 아예 먼저 적는다.

---

## 0. 무엇을 판정하는가

```
후보     실문서 S3 600건(가중치 0.5)을 더해 학습한 모델
기준선   현행 배포본 v-fe4b386b
```

**이 데이터가 고치려는 것은 특이도 한 축뿐이다.** 공개 서식을 영업비밀이라 부르는 헛경보
13.0%. S1 재현율이나 실문서 일반화는 이것으로 안 풀린다 - 빈 양식에 비밀이 없기 때문이다.

---

## 1. 안전 — 하나라도 어기면 탈락

| 축 | 조건 | 근거 |
|---|---|---|
| axis1 hardened42 | `high_risk_to_s3` 증가 **0건** | 고등급이 S3 로 새는 것이 최악 |
| axis1 | `under_graded` 증가 0건 | TS→S1·S1→S2 도 미탐이다 |
| axis1 | `under_graded_severity` 증가 0건 | 낮춘 폭까지 본다 |
| axis3 adversarial | 위 셋 동일 | 적대 셋에서도 무회귀 |
| axis1 | `f1_macro` ≥ 기준선 − 0.02 | 기존 허용치 유지 |

`scripts/gate_p1_candidate.py` 기본값이 이 조건이다(허용치 0). **막힌 뒤에 허용치를
올리면 그것이 기준 이동이므로 하지 않는다.**

⚠ per-class recall 은 판정에 넣지 않는다. axis1 이 n=42 라 문서 1건이 2.4%p 이고
  "1건 차이로 FAIL" 은 잡음을 판정으로 만든다. 리포트에 남겨 사람이 읽는다.

---

## 2. 효과 — 이 중 하나 이상을 만족해야 채택 검토

봉인 서식 400건, 같은 문서로 짝지어 비교(`scripts/eval_sealed_forms_paired.py`).

```
severe(TS/S1) 헛경보   절대 3%p 이상 감소  또는  상대 25% 이상 감소
                       그리고 McNemar p < 0.05
```

**어느 쪽도 만족하지 못하면 채택하지 않는다.** 안전만 지키고 효과가 없으면 바꿀 이유가
없다 - 모델 교체는 그 자체로 위험이다.

---

## 3. 함께 보되 단독으로 탈락시키지 않는 것

```
non_public(TS/S1/S2) 예측 비율     기록. S2 는 취급 등급이라 정답이 불확실하다
needs_review 비율                  기준선 대비 크게 늘면 운영 부담. 사람이 판단
폴더별 헛경보                       한 폴더가 크게 악화하면 합계 개선이어도 재검토
등급 분포                          S3 로 몰아붙인 것이 아닌지 확인
```

⚠ 폴더별은 **합계 개선이 특정 폴더 악화를 숨기지 않게** 하려는 것이다. 자동 탈락 조건으로
  두지 않는 이유는 폴더당 n 이 9~210 으로 편차가 커서 작은 폴더의 1~2건이 큰 비율로
  보이기 때문이다.

---

## 4. 판정 단위

```
판정   서빙 경로 (게이트를 다 지난 출하물)
기록   원시 모델도 함께 남긴다 (회귀 탐지용)
```

오늘 릴리스 게이트에서 정한 것과 같다 - 우리가 파는 것은 원시 모델이 아니다.

⚠ `gate_p1_candidate.py` 는 `predict_direct`(원시)를 쓴다. 그래서 게이트 결과는
  **원시 기준 안전 무회귀**이고, 봉인 서식 평가는 **서빙 경로**다. 둘 다 통과해야 한다.
