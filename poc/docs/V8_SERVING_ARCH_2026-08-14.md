# 자동확정 2.8% -> 91.7% · 무음 미탐 0 — 그러나 판별은 아직 0 이다

작성 2026-08-14. 회차 11~12 와 서빙 게이트 구조 도입의 결과다. 좋은 소식과 나쁜 소식이
둘 다 확정적이라 함께 적는다.

---

## 1. 손실 함수로는 못 고친다 — 학습이 이미 포화한다

r12 는 벌점을 서빙 규칙으로 재도록 고쳤다(`--penalty-rule serving`). unknown 유보에는
벌점이 없고 absent 단언에만 붙는다. 이론은 맞았는데 **효과가 없었다.**

```
business_work n=72        과소분류   등급일치   secrecy absent
  v8_nm   기준             0.4909    0.2639        22
  v8_sec  r11 간접신호      0.4364    0.2222        24
  v8_secp r12 +서빙벌점     0.4727    0.2500        23
```

이유는 학습 로그에 있다. **epoch 3 에 학습 정확도가 1.0 으로 포화한다.** 오차가 0 이면
벌점의 기울기도 0 이다. 손실을 아무리 잘 설계해도 합성 학습셋을 완벽히 맞히는 순간부터는
아무것도 가르치지 못한다. 실문서 동작은 손실이 아니라 표현이 결정한다.

→ **교훈: 학습 정확도가 1.0 이면 손실 설계는 지렛대가 아니다.** 지렛대는 데이터이거나
   추론 시점의 결정 규칙이다.

---

## 2. 지렛대는 추론에 있었다 — absent 단언에만 문턱

서빙 규칙에서 무음 미탐을 만드는 클래스는 `absent` **하나뿐**이다.

```
  정답 lv2 · 예측 unknown  ->  보수적 완성이 2 로 채움  ->  고등급  ->  검수로 감
  정답 lv2 · 예측 absent   ->  곱이 0                ->  S3      ->  무음 통과
```

그런데 argmax 는 네 클래스를 대등하게 본다. p(absent)=0.34 로 1 등이면 absent 를 낸다.
비용이 비대칭인데 결정이 대칭이었다. absent 는 p >= kappa 일 때만 채택하고 미달이면
unknown 으로 내린다.

```
business_work        kappa 0.00   0.90    0.99
  과소분류             0.4364    0.2000  0.0545
  등급일치             0.2222    0.4028  0.4861
```

kappa 는 판정면 곡선을 보고 고르지 않았다. **자동확정 문턱 tau 와 같은 값(0.99)**으로
둔다 — 자동확정도 absent 단언도 "사람 없이 문서를 통과시키는 결정" 이므로 같은 증거
기준을 요구하는 것이 일관된다.

---

## 3. kappa 의 대가는 출처 prior 가 전부 갚는다

kappa 를 올리면 공개문서의 S3 정탐이 떨어진다. 그런데 **공개문서는 본문이 아니라 출처로
S3 인 것이 맞다** — 비공지성은 문서 밖의 사실이고, 공개 여부의 신뢰할 만한 증거는 본문
표현이 아니라 출처다. 본문을 읽어 "공개됐다" 를 알아내려던 시도 자체가 잘못이었다.

```
출처 prior 를 켜면              kappa 0.00 -> 0.99
  court     등급일치 0.9682 -> 0.9682   S3정탐 1.000 -> 1.000   변화 없음
  finance   등급일치 0.7773 -> 0.7773   S3정탐 1.000 -> 1.000   변화 없음
  business  과소분류 0.4364 -> 0.0545   미탐 24건 -> 3건
```

**대가가 0 이다.** kappa 가 무는 비용이 정확히 출처 prior 가 담당하는 문서에만 떨어진다.

---

## 4. 서빙 게이트 3층 구조

```
  1층 출처   공개 출처면 S3 로 확정. 비공지성은 문서 밖의 사실이다
  2층 단언   출처가 공개가 아니면 absent 는 p >= kappa 일 때만. 미달이면 unknown
  3층 확정   서빙 등급이 TS 면 확정(미탐 정의상 불가능) · 아니면 세 요소 확정 + conf >= tau
```

3층에서 TS 에 확신 문턱을 요구하지 않는 근거: **미탐은 낮게 본 오류이고 TS 는 최상단이다.**
TS 로 확정하면 그보다 높은 등급이 없으므로 정의상 미탐이 될 수 없다. 대가는 과분류이고
그것은 위험이 아니라 비용이다.

```
면                   n     자동확정   무음미탐   미탐상한   확정정확   과분류
business_work       72      91.7%       0     0.05500     0.485      34
finance            229     100.0%      51     0.28092     0.777       0
court              409     100.0%      13     0.05362     0.968       0
전체                710      99.2%      64     0.11442     0.861      34
```

finance 51 · court 13 의 "미탐" 은 라벨 오류다 — 전부 공표된 대법원 판례(영업비밀 침해
사건)와 공표된 증권사 리포트다. 본문이 영업비밀을 *다루는* 것이지 문서 자체가 비공지가
아니다. 우리 루브릭으로 판례는 `proven_absent -> S3` 이므로 S1/S2 라벨이 루브릭과
어긋난다. 라벨을 고치지는 않고 어긋남만 기록한다.

---

## 5. 그러나 판별은 아직 0 이다

```
business_work n=72
  정답  TS 33 · S1 22 · S2 17
  예측  TS 66 · S2 3 · S3 3        <- 91.7% 를 TS 라고 한다(정답은 45.8%)
  자동확정 66건 중  정확 32 · 과분류 34 · 미탐 0
```

**전부 TS 라고 답해도 33/72 = 0.458 이다. 모델은 0.444 다.** 자동확정률 91.7% 는
판단을 한 결과가 아니라 판단을 안 한 결과다. 안전은 얻었고 판별은 못 얻었다.

---

## 6. 그리고 판별에는 구조적 상한이 있다

정본 규칙에서 S1 이 나오는 조합을 전수 조사했다.

```
  S1 조합 = [(2, 2, 0)]   <- 단 하나. management 가 **0 으로 확정**될 때만
```

보수적 완성은 unknown 을 2 로 채운다. 그러면 `s=2 v=2 m=unknown -> TS` 다.
**관리성이 확인되지 않으면 S1 은 구조적으로 도달 불가다.**

```
business_work  S1 22건 = 30.6% 는 어떤 모델이어도 TS 로 나온다
               달성 가능한 등급일치 상한 = (33+17)/72 = 0.6944
               현재 0.4861
```

그리고 관리성은 실제로 관찰되지 않는다. 이 문서들은 짧다:

```
등급   n    길이 중앙   관리성 어휘 포함
TS    33     236자      9/33
S1    22     187자      2/22
S2    17     167자      1/17
```

**200자 문서가 자기 접근통제를 진술할 수는 없다.** 관리성은 문서 밖의 사실이고, 그것을
본문에서 읽으려는 시도는 비공지성 때와 같은 오류다.
