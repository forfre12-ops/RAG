# 현재196개 제목 민감도 진단 — 2026-09-15

## 결론

**제목을 바꾸면 일부 예측이 바뀌지만, 제목을 지우는 것만으로 현재 신호가 사라지지는 않았다.**
현재196개·178개 연결 계열을 고정한 문자 n-gram 진단 모델에서 원문 대비 제목 삭제는 5.20%, 공통 제목 대체는 6.12%의 예측을 바꿨다.
조건부 참조와의 전체 일치율은 원문57.55%에서 각각57.45%,57.04%로 거의 유지됐다.

이는 선택한 문자 probe의 입력 조작 민감도다. 고객 모델 정확도·실제 보안등급 정답률·전체 편향의 인과 증명은 아니다.
제목 삭제/대체는 실제 정보를 제거하는 조작이며 의미 동등성이 보장되는 단순 문체 변경으로 해석하지 않는다.

## 통제한 조건

- 기존 누적196개를 사용했다. TS38/S1 56/S2 49/S3 53. 새 원고와 변형 사본을 신규 수량에 넣지 않았다.
- 기존 통합 노출 감사의178그룹을 그대로 사용했다. 선언된 가족/중복 그룹과 추가 의미 링크를 분리하지 않는지 검사했다.
- seed0~4, 각5fold. **25개 진단 probe**를 원문 본문만으로 학습했다.
- 각 학습 fold에서만 TF-IDF 어휘/IDF를 적합했다. 같은 학습 모델로 동일한 held-out 부모의 세 입력을 모두 예측했다.
- 세 입력은 원제목 유지, 첫 줄 제목만 삭제, 첫 줄을 공통 문자열 `문서`로 대체한 것이다.
- 첫 줄의 제목 문자열 외에는 줄바꿈·빈 줄·본문 모든 단락을 바이트 그대로 보존했다.
- 모델에는 맥락·ID·등급·근거·그룹을 입력하지 않았다. 그룹과 정답은 분할/진단 채점에만 사용했다.
- 원고·정답·정책 및 운영 모델·분류 API는 수정하지 않았다. 모델 파일을 저장하거나 배포하지 않았다.

측정기는 `TfidfVectorizer(analyzer="char", ngram_range=(2,5), min_df=1, max_features=30000)`와
`LinearSVC(random_state=seed, max_iter=5000)`이다. numpy2.4.6, scikit-learn1.9.0에서 실행했다.

## 해석의 한계와 다음 사용

1. **본문 단독은 등급 채점 적격 입력이 아니다.** 현재 정책의 S/V/M을 결정하는 관리·가치 가상 맥락은 이번 probe에 입력하지 않았다.
   위 비율은 조건부 참조 라벨과의 진단적 일치이며 고객 문서 정확도가 아니다.
2. 제목 삭제 후에도 전체 일치가 거의 유지되므로 제목 삭제만으로 편향 보완이 완료됐다고 할 수 없다.
   본문 용어·주제·형식·작성 방식 등 남은 신호가 무엇인지 별도 진단해야 한다. 이번 결과로 그 원인을 특정하지 않는다.
3. 공통 `문서` 제목은 학습 시 강제한 표현이 아니다. 삭제와 대체의 차이를 “순수 제목 의미 효과”로 해석하지 않는다.
4. 현196개는 이미 개발에 사용한 자료다. 최종 평가200개로 전용하지 않는다. 새64개와 모집단을 섞은 전후 성능 비교도 하지 않았다.
5. 이 결과를 이유로 원제목/정답을 일괄 수정하지 않는다. 제목과 본문 내용의 정당한 연관도 있을 수 있다.
   다음 집필은 서로 다른 분야·말투·형식과 명시적 사실 근거를 유지하며, 새 자료 결과는 별도로 기록한다.
