
늘리면 그대로 증식한다.

**스키마를 3상태로 바꾼다.** 요소마다:

```
state       proven_absent | present | unknown
level       0 | 1 | 2                      (present 일 때만 의미)
span        근거 문장 원문
direction   존재 | 부재 | 불명
kind        본문 진술 | 문서 메타데이터 | 외부 검증
verified    텍스트상 주장 | 시스템 확인
reason      판단 사유 코드
```

등급은 `state/level` 에서 결정적으로 산출하고 저술자가 직접 적지 않는다. 규약 확정 후

## 2. 8/14 — 사전등록 동결

### 2.1 표본수 역산 → v8 생산량 확정

무미탐 관측의 95% 상한은 표본수로 정해진다.

```
목표 Y      필요 무미탐 자동확정    자동확정률 10% 가정 → 홀드아웃 평가 필요량
0.5%        600건                   6,000건   (형태당 3,000)
1.0%        300건                   3,000건   (형태당 1,500)
2.0%        150건                   1,500건   (형태당   750)   ← 채택
```

**1단계 목표 Y = 2%.** 홀드아웃 형태 2종 각 750건. 0.5% 를 걸면 생성·평가만으로 8/31 을
넘긴다. 실문서 라벨이 쌓이는 3단계에서 조인다.

학습 형태 6종은 경계 표집이 지배하므로 별도 산출(§3.2).

### 2.2 판정 기준

```
1  형태별 최악 성능        홀드아웃 2종 각각에서의 하한. 평균으로 가리지 않는다
2  고등급 과소분류율        TS·S1 → 하위 등급
3  자동확정 커버리지 ≥ X%   와 무음 미탐 ≤ Y% 의 결합 조건
4  두 모델 동시 오답률      등급·형태별
5  같은 과소분류 방향의 동시 오답률
6  형태·등급 통제 후 잔차 오류 상관도
7  각 수치의 bootstrap 또는 이항 95% 상한
```

3번이 핵심이다. **"미탐 0" 단독은 조건이 될 수 없다** — 자동확정 0 에서 정의상 성립하고,
그러면 자동확정을 0 으로 만드는 것이 게이트 통과의 최적해가 된다. 이 함정에 이미 두 번 빠졌다.

### 2.3 ICD 실패 시나리오

### 3.2 축 2 — 경계 counterfactual

27조합을 균등 표집하면 안 된다. 정본 등급식이 결정적 함수라 이렇게 떨어진다(실측):

```
S3 18개 · S2 6개 · TS 2개 · S1 1개
```

균등 표집 = 학습셋 S3 67%. 1차 목표인 고등급 미탐 최소화와 정반대다.

대신 **한 요소를 1단계만 바꿨을 때 등급이 넘어가는 인접 경계 18개**에 예산을 몰아준다(실측):

```
S3 ↔ S2  11개   011-111 · 012-112 · 021-121 · 022-122 · 101-111 · 102-112
                110-111 · 120-121 · 201-211 · 202-212 · 210-211
S2 ↔ TS   4개   121-221 · 122-222 · 211-221 · 212-222
S3 ↔ S1   2개   120-220 · 210-220
S1 ↔ TS   1개   220-221
```

각 경계마다 쌍을 만든다 — **같은 사실 · 같은 형태 · 같은 길이 · 한 요소의 근거만 변경.**
27조합은 "모두 존재"까지만 채우고 나머지 예산은 경계에 쓴다.

### 3.3 S3 는 두 종류로 나눈다 ⚠ 계산 결과가 설계를 바꾼다

S3 자동확정은 "비밀 신호 없음"이 아니라 **부재의 입증**을 요구한다(정본 §3.6,
`rule_engine.py:86`). 판정은 임의 라벨이 아니라 결정 규칙에서 파생시킨다:

```
unknown 을 전부 최악값(2)으로 채운다 → 그래도 S3 면 S3-입증형
                                    → S1/S2/TS 가능성이 남으면 S3-무신호형(검수)
```

이 규칙을 27개 라벨상태에 돌린 결과(실측):

```
보수적 완성 후 S3 = 15개 상태
전부 secrecy 또는 value 가 proven_absent 인가  →  True
management 부재만으로 S3-입증형이 되는 경우    →  0개
반례: s=present, v=present, m=proven_absent   →  S1
```

**규칙이 두 요소로 붕괴한다.** 관리성 부재 입증은 S3 자동확정에 기여가 없다.

데이터 귀결: S3-입증형 문서는 **"공개되었음" 또는 "가치 없음"을 입증하는 문장**을 담아야 한다.
"관리하지 않음" 문장만 있는 문서는 아무리 명확해도 자동확정 후보가 아니다. 지금 S3 문서는
대개 "아무 신호가 없는 문서"이므로, 이대로 만들면 S3 자동확정은 구조적으로 0 이 된다.

ICD 귀결: §1.2 의 5(공개·배포 이벤트) > 6(문서유형 승인) > 7(접근통제) 순서가 여기서 나온다.

### 3.4 축 3 — 근거 언어 최소쌍

evidence 헤드는 근거를 **추출**하지 사실을 **검증**하지 못한다. 문장을 찾아도 그 문장이
현실에서 참인지는 모른다. 모델이 "공개"라는 단어에 반응하는 것을 잡아내려면 최소쌍이 필요하다.

```
시제   게재했다          ↔ 게재할 예정이다        proven_absent 성립 ↔ 불성립
범위   전 직원에게 공유   ↔ 홈페이지에 게재        내부(부재 아님) ↔ 외부(부재)
지시   공개 자료를 참고   ↔ 본 자료를 공개함       부분 ↔ 전체
방향   외부 공개 금지                            역방향 근거
```

증거 강도는 3단계로 분리해 라벨한다.

```
1  시스템 검증   실제 게시 이벤트 · 승인된 공개 저장소 · 문서관리시스템 상태
2  조직 승인     고객사가 승인한 저위험 문서유형 · 템플릿 · 업무 프로세스
3  본문 진술     evidence 헤드가 추출한 명시적 문장  ← 별도 임계 + 표본감사
```

고위험 운영점에서는 1·2 를 강하게 보고 3 은 단독으로 자동확정 근거가 되지 않는다.

독립 판정 축에서 퇴출한다. 시드로는 못 고친다는 것이 실측으로 확인됐다(누산 점수 분산 0 ·
semantic 코사인이 음성 대조군과 겹침 · 임계 탐색이 상수 예측기로 수렴).

```
유지   주민번호 · 계약금액 · 보안표현 등 고정밀 위험 신호
유지   확실한 비공개 근거가 있을 때 자동확정을 막는 veto
유지   운영자에게 판정 근거를 표시하는 보조
폐기   S/V/M 또는 등급을 결정하는 두 번째 투표권
폐기   rule=S3 를 합의 근거로 사용   ← 800건 전부 S3 를 내므로 합의가 무조건 성립한다
```

### 5.2 S3 정책 역전

```
S3 예측은 가장 엄격한 자동확정 대상으로 취급   (현재는 합의 게이트에서 면제 — 논리가 거꾸로다)
§3.3 보수적 완성 판정을 통과해야 자동확정
출처가 불명확한 S3 예측은 무조건 검수
TS/S1 처럼 보수적으로 높은 예측부터 제한적으로 자동화
```

회귀 테스트: **정답 S1/TS + 모델 S3 + 룰 S3 가 반드시 검수로 간다.** 무음 미탐 5건이 전부
이 구조였다.

## 8. 정직한 한계 — 이 계획이 보증하지 않는 것

전부 합성 데이터다. v8 이 성공해도 보증 범위는 **형태 · 길이 · 장르 · 표현 변화에 견딘다**
까지이며 실문서 일반화가 아니다. 자체 실측이 있다 — 교차 silver → gold_real F1 **0.26**
(실데이터 학습본 0.736 대비 붕괴, CAPSTONE 2026-07-01).

```
A+B (v8 · 요소 모델 · 통합 게이트)   합성 홀드아웃 F1 0.26 → 0.74 (v7 실측)
                                     실문서 F1 변화 없음
C   (회원사 실문서 운영학습)          실문서 F1 0.26 → 0.736
```

**A+B 의 값은 품질 향상이 아니라 C 를 받을 그릇을 만드는 것이다.** 형태 결박된 모델에
실문서를 먹이면 회원사 A 의 형태를 외우고 회원사 B 에서 무너진다. 지금 v5 가 경화 42 에서
40.5%, v3 에서 0% 인 것과 같은 실패가 반복된다.

품질 도약은 C 에서만 나오고, C 는 ICD 에 걸려 있다. 그래서 §1.2 가 오늘이다.

또한 지금까지 측정된 조합 중 **자동확정률이 0보다 크면서 무음 미탐이 0 인 설정은 없다**
(요소모델 0.70 → 6.9%/미탐 5건 · 0.80 → 1.9%/1건 · 0.85 → 0%/0건). A+B 를 다 해도
현재 재료로 자동화가 열린다는 보장은 없다.
