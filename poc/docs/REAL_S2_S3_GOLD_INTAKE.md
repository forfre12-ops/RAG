# 실제 S2/S3 골든셋 후보 수집 기준

목적은 고객사 원문 없이도 실운영 문서와 가까운 분포를 S2/S3부터 확보하는 것이다. 이 수집분은 합성 Proxy Gold와 구분하며, 등록만으로 Locked Gold 또는 운영 정확도 근거가 되지 않는다.

## 우선 수집 대상

| 등급 | 문서 예시 | 최소 증적 |
| --- | --- | --- |
| S3 | 공식 공지, 공개 매뉴얼, 공개 교육·안내 자료 | 공개 URL 또는 발행기관·버전 |
| S2 | 조직의 실제 운영 절차, 품질점검·교육 이력, 변경관리, 장애 후속조치 | 소유부서·보관 위치·검수용 사용 승인 |

고객사 문서, 반출 승인 없는 문서, 권한을 설명할 수 없는 파일은 이 경로에 넣지 않는다.

## 등록과 승격의 분리

1. `actual-intake.html`에서 원문, 출처, 사용 근거를 기록한다.
2. 시스템은 원문 SHA-256·추출 품질·등록자를 보관하고 `under_review`로만 저장한다.
3. 관리콘솔에서 잠정 등급을 지정하면 `grade_fixed_unlocked`가 된다.
4. 사람 검수·서명이 완료된 문서만 별도 Locked Gold 승격 게이트를 통과할 수 있다.

따라서 `public_real`과 `organization_real`은 실제 문서임을 나타내는 출처일 뿐, 사람 검수 전에는 실운영 정확도의 평가 정답지가 아니다.
