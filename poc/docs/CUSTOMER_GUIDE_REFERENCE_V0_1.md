# 고객사 합성 시험용 가이드 기반 참조 기준 0.1

2026-09-15. 사용자의 후속 `진행`을 원 가이드 기반 **내부 제작 기준안** 진행으로 기록한다.
이는 고객사 시험 프로토콜 서명, D01~D08 승인, 운영 정책 교체가 아니다. 외부 검수자를 기다리지 않고
우리가 가상 사실과 조건부 정답을 작성·검산한다. 다만 합성 사실을 실제 고객 관측으로 바꾸지 않는다.

정책 ID `customer-guide-synthetic-reference`, 버전 `0.1`. 기계가 읽는 정책은 새 pack의 `policy.json`이다.
이 문서는 이전 `CUSTOMER_BENCHMARK_800_200_V1.md`의 ‘정책 선택 대기’를 이번 내부 제작에 한해 갱신한다.
이전 준비 pack과 그 문서는 당시 상태를 재현하도록 수정하지 않는다.

## 원문 확인과 선택 범위

원본: `doc/[참고] 영업비밀 등급분류 가이드.pdf`, SHA256
`c3a0b9cbc971ced27945c13a3bc1ae8d5f6165fdac128646369c8af62a191fcb`.
16쪽 전체를 이미지로 확인했다. 선택한 근거는 **11쪽 기준표와 12쪽 4단계 산정 예시**다.

- 5쪽: 별도의 다섯 항목 합산 방식. 특급을 기업이 자체 분류하는 표이며 이번 정책에 혼합하지 않는다.
- 11쪽: S/V/M 각 0/1/2의 서술 기준. 주석은 기업 상황에 따른 조정 가능성을 명시한다.
- 12쪽: 2/3/4단계 예시 중 이번에는 4단계만 선택한다. 원문의 숫자 1/2/3/4 등급을 우리 TS/S1/S2/S3와 혼동하지 않는다.
- 6~9쪽: 문서 종류별 예시는 제목만으로 답을 확정하는 규칙으로 쓰지 않는다.
- 10쪽 및 13~14쪽: 관리 수준과 보호 점검을 다루며 산식 결과 자체가 공개 승인이나 법적 성립 판단은 아니다.

| 요소 | 0 | 1 | 2 |
|---|---|---|---|
| S | 해당 정보가 불특정 다수에게 공개됨 | 통상 취득하기 어려움 | 보유자를 통하지 않고는 알 수 없음 |
| V | 경제적 가치 없음 | 취득·개발에 비용 또는 노력 투입 | 상당한 비용 또는 노력 투입 |
| M | 비밀 유지가 불가능하거나 전 직원이 알아야 함 | 업무 필요자에게만 공개 | 승인된 자에게만 공개 |

원문의 S=2는 S=1의 표현에도 걸릴 수 있다. 본 기준에서는 ‘보유자 경유 외 취득 불가’가 확인되면 S=2,
그 외 제한적으로 취득 가능하지만 통상 취득이 어려우면 S=1로 구별한다. 현재 판본 전체의 공개가 입증되면 S=0이다.
M=2의 ‘승인’은 이번 합성 시험에서 **인명별 승인 명단과 실제 접근 제한**으로 좁힌다.
업무 역할만으로 접근하고 별도 인명 승인이 없다면 M=1이다. 이 좁힘도 내부 명세이며 가이드가 IAM 형식을 강제한 것은 아니다.

| S×V×M | 우리 답안 |
|---:|---|
| 0 | S3 |
| 1 또는 2 | S2 |
| 4 | S1 |
| 8 | TS |

27조합을 곱셈표와 별개로 ‘0 존재 여부와 2의 개수’로 검산한다.
운영의 `v22` 보정은 사용하지 않는다. guide/v22 차이가 있는 (1,2,2), (2,1,2), (2,2,0), (2,2,1)을 별도 회귀한다.
예를 들어 (2,2,0)은 이 산식에서는 S3다. 외부 공개 허가로 해석하지 않고 관리 공백을 별도로 드러내야 한다.

## V의 명확한 내부 앵커 — 원문 수치가 아님

가이드는 ‘상당한 비용/노력’의 수치를 제공하지 않는다. 임의 해석을 반복하지 않기 위해 이번 제작안에서만 아래를 사용한다.
**가이드 원문, 고객사 승인 수치, 모든 기업에 맞는 기준이라고 주장하지 않는다.**

| 조건 | V |
|---|---:|
| 경제적 활용이 없다고 가정으로 명시하고 해당 정보 귀속 비용·투입 모두 0 | 0 |
| 경제적 활용 가능, 비용≤100만원 AND 투입≤40인시, 둘 중 하나 이상 양수 | 1 |
| 경제적 활용 가능, 비용≥3,000만원 OR 투입≥480인시 | 2 |
| 위 구간 사이, 근거 누락, 상충 또는 귀속 불명확 | HOLD |

비용/노력은 **해당 문서에 담긴 정보의 취득·개발**에 귀속된 값이다. 계약 금액, 회사 매출, 설비 가격,
프로젝트 전체 비용을 대신 넣지 않는다. 짧은 요약이어도 그 안의 관측값을 취득하는 데 든 비용은 가정으로 구체화할 수 있다.
그 가정은 실제 문서에서 자동 추출된 사실이 아니다. 고등급을 채우려고 본문의 단순 산술 자체를 고비용 연구로 설명하지 않는다.

두 앵커 사이의 문서에는 답을 억지로 부여하지 않는다. 이 보수적인 빈 구간은 ‘누가 봐도 명확한 조건’부터 만들기 위한
내부 제작 범위이며 일반 문서 전수 분류 정책으로 완성됐다는 뜻이 아니다. 앵커를 변경하면 새 정책 버전과 새 답안이 필요하다.

## 근거·맥락·정답 계약

입력은 본문과 가상 맥락이다. 공개 경로, 귀속 비용/인시, 실제 접근 범위를 모델에 제시한다.
S/V/M 숫자, 정답 등급, 적용 규칙, 배제 해설, 문서 계열, 작성자 판단은 입력에서 제외한다.
모든 맥락 항목의 `origin=synthetic_assumption`은 공개적으로 유지한다.

별도 답안에는 다음이 결합된다.

1. 변경되지 않은 본문과 본문 SHA256, 불투명한 새 문서 ID, 맥락을 포함한 입력 해시.
2. 본문 주장 2개씩의 인용·위치·해시. 이는 전체 의미 검증과 동일하지 않다.
3. 가상 맥락 14개 사실의 값·입력 위치·해시 및 사람이 읽을 수 있는 작성 가정 설명.
4. 원문 쪽수와 정책 버전/해시, S/V/M 계산, 곱과 등급, 다른 세 등급 배제 이유.
5. `internally_fixed_conditional`: 이 버전의 가정과 내부 기준 아래 고정한 답. 고객 서명 GOLD나 실제 문서의 진위 보증은 아니다.

필수 근거 12개 중 하나라도 미수신이면 HOLD이며 0으로 바꾸지 않는다. 알려진 0이 있어도 다른 필수 근거 누락을 무시하지 않는다.
공개 여부와 취득 경로가 상충하거나 ‘전 직원 공유’와 ‘개별 승인자만 열람’이 함께 있으면 HOLD다.
`release_authorized`, `other_risk_present`는 별도 공개 검토용이며, 누락이면 추가 검토를 요구한다.
S3여도 공개 미승인인 입고 일정·담당표처럼 **산식 답과 배포 권한을 분리**한다.

현재 20건은 본문만 읽어서는 관리·가치 맥락을 알 수 없다. 같은 본문에서 맥락만 바꾸어 등급이 달라지는 반례 20개를
별도 정책 진단으로 만든다. 이 반례는 새 문서가 아니며 1,000건 수량에 넣지 않는다.
본문만 제공하는 모델의 등급 오답으로 채점하지 않는다. 본문+맥락 시험도 정책 적용/근거 추출 시험 성격을 따로 보고한다.

## 첫 결과의 사용 경계

실제 본문 20개 = 이전 별도 집필 초안 12개 + 신규 8개. 답안도 20개다. 이전 12개를 신규 12개로 중복 집계하지 않는다.
기존 140개, 원장 40개, 짧은 본문 정책 fixture를 학습 자료로 전환하지 않는다.
이 pack은 조건부 참조 후보이므로 기존 `training_allowed/model_evaluation_allowed/gold_eligible`는 false다.
정답 제작은 진행되었지만 **1,000건 학습/평가 배포 동결은 아직 하지 않은 것**이다.

본문 근거 40개 중 산술 검산은 별도 11개 점검만 수행한다. 나머지 문장 전체를 기계가 의미 증명했다고 말하지 않는다.
모델은 호출하지 않는다. 27조합 일치나 산술 검산 통과율은 분류 모델 정확도가 아니다.
원본 PDF, 기존 모델/학습풀/API/운영 산정 방식은 변경하지 않는다.

## 1,000건까지 이어갈 작업

1. 이번 내부 앵커의 적용 결과와 모호 구간을 기록하고, 새 문서는 사실·원고부터 작성한다. 등급은 나중에 계산한다.
2. 현재 TS4/S1 4/S2 6/S3 6에서 각 250건까지 서로 다른 원문·업무·문체를 확보한다. 수량 부족 때문에 가정을 왜곡하지 않는다.
3. 본문+맥락이 실제 시험 모델의 입력에 끝까지 들어가는지 검증한다. 본문 전용 경로에 억지 정답을 붙이지 않는다.
4. 전수 문체/제목/길이/계열 누설, 기존 학습풀 중복, 수치 변형본, 원문-맥락 모순 검사를 한다.
5. 연결된 계열을 나누지 않는 800/200 분할과 입력/정답 동결을 하고 시험용 새 배포 권한을 별도로 만든다.
6. 학습800 안에서만 설정 선택 후 모델을 동결하고 평가200을 한 번 최종 채점한다. 고객 문서 정확도로 확대 해석하지 않는다.

현재 200건 표본의 통계 오차 설명과 고객 수락 기준은 별도 시험 프로토콜 항목이다. 분류 일치율은 실행 전 예측하지 않는다.
