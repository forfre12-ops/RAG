# 주장 가능·불가 수치표 — 납품·시험 대응

작성 2026-08-15. **시험은 성능수치 검증이다.** 무엇을 주장하고 무엇을 주장하지 않을지
먼저 고정해야 한다. 근거 없는 수치를 한 번 내면 그 뒤 전부가 의심받는다.

---

## 0. 전제 — 계약이 요구하는 것

```
RFP 성능요건(PER-002)   속도·자원. **정확도 수치 목표 없음**
명시된 핵심 목표        미탐 최소화
```

따라서 1차 주장은 **"놓치지 않는다"** 이고, 정확도는 부가다. 이 순서를 뒤집으면
증거가 없는 쪽으로 대화가 끌려간다.

---

## 2. ❌ 주장 불가 — 지금은 근거가 없다

| 주장하면 안 되는 것 | 이유 |
|---|---|
| "실문서 정확도 N%" | `locked_gold_eval` 0건. 사람 라벨이 하나도 없다 |
| "TS 판별 정확도" | TS 실문서 서명 0건. 합성만 있다 — 구조적 한계 |
| "판별력 N%" 일반화 | 현재 in-sample. 판정면을 진단에 소비했다 |
| "미탐률 2% 이하" (실문서) | 자동확정 표본 189건 미달 |
| "GA 준비 완료" | readiness `P1 classifier` FAIL |

---

## 3. 표본 수 — 무엇을 말하려면 몇 건이 필요한가

```
20건    등급별 5건. **locked_eval 구조적 게이트만** 해소. GA 아님
120건   검수 파일럿 · 방향성 판단
189건   "무음 미탐 2% 이하" (Wilson 0/189 = 0.0199 <= 0.02)
형태별 189건   형태별 2% 주장
```

⚠ **150건으로는 2% 를 못 말한다** — Wilson 0/150 = 0.02497 로 한계를 넘는다.
   사전등록 표에 150 이라 적혀 있던 것이 산술 오류였고 189 로 고쳤다.

---

## 4. ⚠ 선제 정리 — 시험에서 물어볼 것

### hardened42 F1 0.917 을 대표값으로 쓰지 말 것

```
그 42건의 S3 7건이 2,323~3,023자 · 나머지 151~317자
길이 하나로 100% 분리된다(길이-only F1 0.448 · S3 1.000)
```

"누출 0" 은 **학습셋 중복 기준**일 뿐이다. 이 수치를 대표로 내면 스크루티니에서
바로 무너진다. 쓰려면 그 한계를 함께 적는다.

### 과분류 89% 는 설계 의도다

```
실문서 64건   정답 TS 22 · S1 18 · S2 24   →   예측 TS 57
```

곱셈 규칙 + 보수적 완성 = "모르면 올린다". **veto 시스템의 대가**이고 미탐 0 의
반대급부다. 먼저 설명하지 않으면 결함으로 읽힌다.

### 비공지성·관리성은 본문에서 관측되지 않는다

```
실문서 업무문서 중앙값 167~236자
관리성 어휘 보유   TS 9/33 · S1 2/22 · S2 1/17
```

200자 문서가 자기 접근통제를 진술할 수 없다. **그래서 ICD 메타데이터가 필요하다** —
이것이 요구가 아니라 설계 전제임을 문서에 남긴다.

### S1 은 규칙상 도달 불가였다

```
정본에서 S1 이 나오는 조합은 (2,2,0) 하나뿐
보수적 완성이 미확인 M 을 2 로 채우므로 M 을 못 받으면 S1 이 안 나온다
판정면의 28%(18/64)가 어떤 모델에서도 TS
```

ICD §3.3 `access_scope=all_employees → M=0` 을 구현해 열었다(2026-08-15).
**메타데이터가 오면** 4등급 상한이 0.719 → 1.0 이 된다.

## 5. 메타데이터가 오면 달라지는 것 (실측)

```
커버리지  오류율   4등급     S1재현율   무음미탐   미탐상한
   0%     0%     0.7543    0.5458       0      0.00133
 100%     0%     0.8310    0.8791       0      0.00147
 100%     5%     0.8092    0.8352      33      0.01768   <- 사전등록 한계 이내
 100%    20%     0.7345    0.6923     140      0.06241   <- 붕괴
```

**오류율 5% 가 계약 경계다.** ICD §6 개방항목에 넣어야 한다.

⚠ 이 모사는 이득을 **과소평가**한다 — 합성면은 관리성이 본문에 진술돼 있어 메타데이터
   없이도 S1 재현율 0.5458 이지만 **실문서는 0** 이다.
