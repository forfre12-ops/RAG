# 미배포 형제 v-d2b4d2e1 에 3축을 돌렸다 — FAIL. 배포본 유지가 맞다

작성 2026-08-15. 질문은 "현재 배포본이 최선인가" 였다. **모른다는 상태였고, 그것을
없앴다.**

---

## 1. 왜 물어야 했나

배포본보다 **점수가 높은 형제**가 아티팩트에 있었다.

```
                      배포본 v-fe4b386b   미배포 v-d2b4d2e1
val 정확도(n=256)          0.9531             0.9648
val f1_macro               0.9515             0.9644
val S1 미탐률              0.0217             0.0000
hardened42 f1              0.9166             0.9338
```

전 항목에서 미배포 쪽이 높다. 그런데 배포된 것은 낮은 쪽이다.

`reports/v5_gate/COMPARISON.json` 을 열어 보니 이유가 있었다 — 그 비교는 **axis1 만**
돌린 것이고 파일 자신이 그렇게 적고 있다.

> `auto_verdict_hint 는 (1)(3)만 본 참고치`

**공개문서 오탐률(axis2)을 안 쟀다.** 그래서 배포 자격이 없었다.

## 3. 숫자를 정직하게 읽으면 — **두 모델은 구분되지 않는다**

세 축 모두 차이가 표본 한두 건이다.

```
axis1   n=42    0.9338 vs 0.9166    문서 반 건
axis2   n=400   0.0425 vs 0.0400    400건 중 1건
axis3   n=100   고→S3 1 vs 1        동일
```

⚠ 그러므로 **"배포본이 더 좋다" 는 주장은 성립하지 않는다.** 성립하는 것은 "바꿀 근거가
  없다" 뿐이다. 게이트 규칙이 `과분류율 ≤ 기준선` 으로 엄격한 무회귀라 1건이라도 늘면
  FAIL 이고, 구분이 안 될 때 배포본을 지키는 쪽이 맞다.

⚠ hardened42 는 **랭킹용으로 쓸 수 없다.** 그 셋의 S3 7건은 2,323~3,023자이고 나머지는
  151~317자라 임계 1건으로 100% 갈린다(기록된 실측). n=42 에서 1.7pp 차이로 순위를
  매기는 것은 방어할 수 없다.

## 4. 다만 방향은 일관된다 — 성능 차이가 아니라 **운영점 차이**다

```
escalated_to_high   0.0300 vs 0.0225      후보가 33% 더 많이 고등급으로 올린다
과소분류(axis1)      1 vs 4               후보가 덜 내린다
과소분류(axis3)      35 vs 39             후보가 덜 내린다
```

후보는 **전반적으로 더 공격적**이다. axis1·axis3 에서 이긴 것과 axis2 에서 진 것이 같은
성향의 앞뒷면이다.

그런데 우리 목표는 미탐 최소화이고, **정작 그 축에서는 차이가 0 이다**(고→S3 0 vs 0,
1 vs 1). 바꿔서 얻을 것이 없다.
