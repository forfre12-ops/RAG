
### 원인 — 문서 **종류**가 두 등급에 걸쳐 있다

뒤집힌 문서를 열어 보니 학습에 넣은 서식과 정확히 같은 종류였다.

```
인수 가치평가 메모   <- '인수계약서' 양식
특허 라이선스 협상   <- '라이선스 계약서' 양식
이사회 의사록       <- '이사회 의사록' 양식
```

빈 '이사회 의사록' 양식과 M&A 결정이 적힌 진짜 '이사회 의사록' 은 **제목도 형식도 같다.**
다른 것은 내용에 실제 비밀이 있느냐뿐이다. 한쪽만 가르치면 종류 전체를 S3 로 배운다.

⚠ 내 가설 두 개가 틀렸다. "S3 를 많이 넣어 쏠렸다"(가중치 반으로 줄여도 미탐 그대로),
  "짧아서 그렇다"(뒤집힌 174자 vs 유지된 182자, 거의 같음).

### 근본 제약 — 짝이 없다

```
준 것    빈 양식      -> S3
없는 것   채워진 문서   -> TS      <- 우리가 못 구하는 것
```
