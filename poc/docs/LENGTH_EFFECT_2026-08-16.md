# 모델이 길이에 얼마나 반응하는가 — 120건 전수 실측

작성 2026-08-16. 사용자 질문 "이제 길이만 보고 분류하지 않는가" 에 답하기 위해 쟀다.

---

## 1. 왜 재야 했나

우리 평가셋 여러 개가 길이로 답이 새는 상태였다.

```
경화 홀드아웃 42건   S3 아닌 것 151~317자 · S3 2,323~3,023자   겹치는 구간 0
실문서 gold 777건    TS 중앙값 237자 · S3 중앙값 2,542자        길이만으로 78.5% 적중
봉인 평가셋 800건    길이만으로 96% 적중                         -> 통째로 폐기
```

데이터는 이후 정화했다.

```
학습셋 2,042건     길이만으로 30.0% 적중 (무작위 39.8%)   -> 단서 없음
골든 후보 120건    등급별 중앙값 2,178 / 2,178 / 2,180 / 2,214자
```

**그런데 데이터에 단서가 없다는 것과 모델이 그 습관을 버렸다는 것은 다른 주장이다.**
배포 모델 `v-fe4b386b` 는 7/29 승격이고 골든 후보 정화는 8/9 다 — **모델이 정화보다
먼저 만들어졌다.**

---

## 2. 시험 방법

**같은 본문을 2배·4배로 반복**한다.

```
길이      2배·4배로 늘어난다
내용 밀도  그대로다 (비밀 요소의 비율이 변하지 않는다)
```

등급이 움직이면 그것은 길이 때문이다.

⚠ 첫 시도는 설계가 틀렸다. 중립 사무 문구("구내식당 운영 시간은…")를 붙여 늘렸는데,
  그 문구 자체가 "이 문서는 일상 업무 내용" 이라는 근거라서 등급 하락이 길이 때문인지
  **내용 희석** 때문인지 구분되지 않았다. 실제로 두 방법이 반대 방향으로 나왔다.

```
중립 문구 덧붙이기   S3 방향     (내용 희석 효과)
같은 본문 반복       고등급 방향  (길이 효과)
```

## 3. 결과 — 120건 전수

```
길이 2배
  등급 변화        8/120 = 6.7%      고등급 5 · S3 3
  정답 일치        54.2% -> 51.7%
  비밀/비비밀      75.0% -> 72.5%
  무음 미탐        13건 -> 10건

길이 4배
  등급 변화        8/120 = 6.7%      고등급 6 · S3 2
  정답 일치        54.2% -> 50.0%
  비밀/비비밀      75.0% -> 70.8%
  무음 미탐        13건 -> 9건

등급별 변화(4배)   TS 2/30 · S1 0/30 · S2 3/30 · S3 3/30
```

**93.3% 는 길이를 4배로 늘려도 판정이 그대로다.** 내용을 보고 있다.

**S1 은 30건 전부 불변이다.** 앞서 24건 표본에서 "고등급 방향 4건" 이 나왔던 것은
작은 표본이 과장한 것이었다.

---

## 4. 방향 — 위험한 쪽이 아니다

```
길어지면   더 보수적으로 판정한다 (고등급 6 vs S3 2)
무음 미탐   13건 -> 9건으로 줄어든다
정답 일치   54.2% -> 50.0% 로 떨어진다
```

즉 **안전해지지만 부정확해진다.** 과하게 올려 잡는 쪽으로 기운다. 우리 목표가 미탐
최소화이므로 이 방향은 수용 가능하다.

⚠ 위험한 것은 반대다 — **짧은 문서가 짧다는 이유로 낮게 가는 것**. 실문서 셋에서 TS
  중앙값이 237자로 매우 짧아서 그 위험이 실재한다. 이 시험은 길이를 **늘리는** 방향만
  봤으므로 그쪽은 확인하지 못했다.

---

## 5. 이 숫자를 어디까지 믿을 수 있나

```
⚠ 같은 문장이 네 번 반복되는 문서는 실제로 없다. 6.7% 가 순수한 길이 효과인지,
  이상한 입력에 대한 반응인지 이 시험은 구분하지 못한다. 확정할 수 있는 것은
  **"영향이 0 은 아니다"** 까지다.

⚠ 판정면이 골든 후보 120건이다. 이 셋은 등급별 길이를 맞춰 만든 것이라 길이 신호가
  없는 상태다. 길이 신호가 있는 셋에서는 더 크게 나올 수 있다.

⚠ 원본 상태의 정답 일치가 54.2% 다. 이건 길이와 무관한 별개 사실이고, 이 골든 후보
  셋이 모델에게 어려운 셋이라는 뜻이다. 길이 실험의 기준선이 낮다는 점을 감안해야 한다.
```

산출물: `reports/LENGTH_EFFECT.json` (120건 건별 기록)

## 6. 추가 — 줄이는 방향은 **측정에 실패했다**

§4 에서 "길이를 줄이는 방향은 확인하지 못했다" 고 남겼고, 그것을 재려고
`scripts/measure_length_shrink.py` 를 돌렸다(120건).

조작을 둘로 나눴다.

```
압축      공백·줄바꿈을 접어 길이만 줄인다. 어휘 보존   <- 주 판정
잘라내기   앞에서 60%·30% 만 남긴다. 내용도 줄어듦      <- 참고
```

### 압축은 성립하지 않았다

```
압축으로 줄어든 비율: 0.3%
```

**길이가 거의 안 줄었다.** 골든 후보 문서에 접을 만한 공백·빈 줄이 없다. 조작이
성립하지 않았으므로 등급 변화 2건(1.7%)은 길이 효과라고 말할 수 없다.

### 잘라내기는 방향을 보여주지만 원인을 못 가른다

```
              등급 변화        낮아짐   무음 미탐
전체(100%)      -              -       13건
60% 로 자름   15/120 = 12.5%   10건    13건
30% 로 자름   27/120 = 22.5%   22건    19건
```

**짧아질수록 등급이 내려가고 무음 미탐이 13 -> 19건으로 는다.** 방향은 위험한 쪽이다.

⚠ 그러나 이건 **내용도 함께 줄어든 결과**다. 근거 문장이 사라졌으니 등급이 내려가는 것이
  정당할 수도 있다. 길이 때문인지 내용 때문인지 이 실험은 구분하지 못한다.

### 결론

```
확인된 것     짧아지면 등급이 내려가고 무음 미탐이 는다(13 -> 19건, 30% 절단)
확인 못 한 것  그것이 길이 때문인지 내용 감소 때문인지
```

**길이 단독의 축소 효과는 여전히 미확인이다.** 압축 방식이 이 판정면에 안 맞았다.
다시 재려면 원래 길이가 다양한 판정면이 필요하다 - 골든 후보 120건은 등급별 길이를
맞춰 만든 셋이라(중앙 2,178~2,214자) 압축 여지가 적다.
