# 별칭 삭제 실험뷰 독립 검사 v1

작성일: 2026-09-15. 원문 260개는 정본이며 아래 뷰는 미채택 진단 입력이다. 정답 확정, 학습 허용, 골든셋 승격, 고객 정확도 또는 의미 보존 인증이 아니다.

## 확인 결과와 의미 경계

신규 작성 배치 64개 중 16개 문서의 18개 별칭 구간이 바뀌며 48개는 동일하다. 이전 196개 문서는 그대로다. 신규 벤치마크 문서 수는 0개다.

별도 명사·조사 파서가 원문을 읽어 변경 예상 구간을 계산한다. 작성자의 transform이나 정적 편집 레지스트리를 기대값 계산에 호출하지 않는다. 편집 이외 문자, 숫자열, 제한된 부정·조건 어구, 제목, 가상 맥락, 정책, 원본 조건부 참조답안, 배제 이유, 근거 인용 재결합을 확인한다. 기존 별도 정책 검산기도 원문과 실험뷰 양쪽을 검사한다. 이들은 동일 정책의 구조적 검산이지 외부 정답 권위가 아니다.

변경 16개 본문 전체를 제한적으로 읽었지만 **대상 결합 보존은 인증할 수 없다**. 예를 들어 “이번 결과는 기질 배치 M에 한정”을 “이번 결과는 기질 배치에 한정”으로 바꾸면 한정할 배치 식별값이 사라진다. “분말 R은”, “분할 K는”, “구역 D는” 같은 특정 대상 주어도 일반 명사처럼 읽힐 위험이 있다. 남아 있는 국소 조건·외삽 금지문은 별도 인용으로 기록하되, 빠진 대상 식별값을 복원한다고 보지 않는다.

따라서 모든 변경 문서에 `TARGET_BINDING_NOT_CERTIFIED_HOLD`, `adoption_allowed=false`, `authoritative_parent_replaced=false`를 유지한다. 정적 문자열·정책 필드 검사 통과와 의미 동등성 미확정은 서로 다른 판정이다. 관측 결과를 보고 이번 뷰를 재수정하거나 채택하지 않는다.

배치 64개 **본문**의 알려진 명사+영문자 패턴은 TS의 17회에서 0회로 변한다. 더 넓은 단일 대문자 검출은 TS의 19회에서 1회로 변하며 남은 1회는 `2μL` 단위다. 다른 세 등급은 해당 검출이 없다. 가상 맥락·근거는 그대로이므로 body_context 전체에서 해당 단서가 사라졌다는 뜻이 아니다. 이 수치는 문자열 존재 여부이고, 0회는 품질 합격 기준이 아니다.

## 짝비교 설계

- 원문 260개·기존 236개 그룹·5개 seed·5-fold를 고정한다.
- original/repaired TRAIN × original/repaired TEST 네 셀을 body_only/body_context 각각 비교한다.
- TF-IDF와 진단용 선형 분류기는 해당 fold의 학습 문서만 본다. 실험뷰 학습도 같은 부모의 같은 학습 문서만 교체한다.
- 부모·그룹을 경계로 분할하여 원문과 변형이 학습/검증을 넘어가지 않는다. 모든 셀은 동일 분할과 샘플 수를 사용한다.
- 패널 64×5=320회, 실제 변경 16×5=80회, 불변 패널 48×5=240회, 이전 196×5=980회를 각각 보고한다. 이는 반복 관측이며 독립 문서 수가 아니다.
- 참조 일치율, 예측 변화, 맞음→틀림/틀림→맞음, 등급별 혼동표를 분리한다. body_only도 조건부 답안에 대한 진단적 일치율일 뿐, 본문만으로 등급 정답을 알 수 있다는 주장이 아니다.
- 점수 감소/증가만으로 다른 문체 편향의 원인이나 작성 품질 개선을 확정하지 않는다. 원본 260개는 노출된 개발 자료이며 최종 블라인드 평가에는 계속 사용할 수 없다.
