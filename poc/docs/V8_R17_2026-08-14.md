```

r16  수준을 **종류**로 다시 정의          구체성 맞추고 기술노하우 vs 경영계획
r17  내용 지름길 차단                     value present 문서의 절반은 중립 내용만
```

그리고 판정 규칙 하나:

```
하향 단언 문턱   absent 뿐 아니라 **lv1 단언에도** 문턱을 건다
```

정본이 TS/S1 에 `s==2 and v==2` 를 요구하므로 lv1 단언도 고등급을 깬다
(`s=1 v=2 m=2` -> 곱 4 이지만 S2 가 상한). absent 만 지키면 이 경로가 열린다.

## 2. r16 이 합성 판정면을 무너뜨렸고, 그 이유가 중요하다

```
합성 2차 판정면 F1_macro
  v8_nm  기준        0.9091
  v8_kind r16        0.1271     <- 붕괴
  v8_dc   r17        0.8316     <- 회복
```

원인은 value 였다. r16 은 value 를 3,399/3,680 건에서 `absent` 로 냈다. secrecy 와
management 는 정상이었다.

**내가 지름길을 만들었다.** 학습셋에서 value 가 present 인 문서는 예외 없이 수준 내용을
가졌다. 그러니 모델은 프레임 문장을 읽는 대신 "수준 내용이 있는가" 만 보면 됐고, 수준
내용이 없는 판정면에서는 없다 -> absent 로 답했다.

→ **근거 경로가 둘이면 어느 하나도 단독으로 충분해서는 안 된다.** value present 문서의
   절반은 중립 내용만 쓴다(근거는 프레임 문장뿐). 내용만 있는 문서는 항상 수준 내용을
   쓴다(거기서는 내용이 유일한 근거다).
