# 등급 표식 마스킹 A/B — tell 은 성능을 떠받치고 있지 않았다

작성 2026-08-14. 외부 검토가 지적한 운영 학습셋 tell(46~50%)을 실측하고, 마스킹 전후를
같은 조건으로 학습해 대조한 결과다. **내 예상이 틀렸고 지적의 결론도 성립하지 않는다.**

---

## 1. tell 은 실재한다 — 지적보다 심각하다

`labeled_p1_v5_clean` 2,554건(train 2042 · val 256 · test 256):

```
1급 비밀   380건 -> 100% S1
대외비     382건 ->  99% S2
기밀       432건 ->  82% TS
영업비밀   446건 ->  85% S1
보안등급    25건 ->  56% TS
등급명 노출 283건
하나라도 포함 1,273건 = 49.8%
```

절반의 문서가 등급 표식을 달고 있고, 표식만 보면 등급이 거의 결정된다. 여기까지는 지적이 맞다.

---

## 2. 그런데 모델은 그것을 보고 있지 않았다

표식을 중립 토큰으로 치환하고(치환 4,002회 · 잔여 0건 · 등급토큰 283 -> 0) 같은 코드로
학습해 대조했다.

```
조건                          F1      정확도   고등급 미탐율
clean  학습 -> clean  평가   0.9643  0.9648    0.0521
clean  학습 -> masked 평가   0.9643  0.9648    0.0521    <- 완전히 동일
masked 학습 -> masked 평가   0.9658  0.9648    0.0521
```

가장 결정적인 것은 세 번째 줄이다. **같은 모델 · 같은 문서 · 표식만 지운 조건에서 예측이
한 건도 안 바뀐다** — 예측 분포까지 `TS 45 · S1 48 · S2 54 · S3 109` 로 동일하다.

---

## 3. 왜 내 예상이 틀렸나

`1급 비밀 -> S1` 380건 100% 는 사람 눈에 결정적 단서로 보인다. 그래서 모델이 거기 기댈
것으로 봤다. 아니었다.

512토큰 문서 안에서 그 어절은 한 조각이고, **그 어절이 없어도 문서 전체가 이미 등급을
결정하고 있었다.** 1급 비밀이라 적힌 문서는 내용도 S1 이었다.

tell 과 라벨이 **같은 원인에서 나온 상관**이지, tell 이 라벨을 만든 인과가 아니었다.
"표식이 있으면 라벨이 정해진다" 는 관찰은 맞지만, 거기서 "모델이 표식으로 맞힌다" 는
결론은 나오지 않는다. 그 사이를 실험으로 재야 했고, 재니 갈렸다.

---

## 4. 그래서 무엇이 확인됐나

```
배포본 v5 의 내부 지표는 등급 표식에 기대고 있지 않다
```

외부 검토는 "마스킹 후 F1 0.951 이 얼마나 남는지가 첫 정직한 측정치" 라고 했고 나도
동의했다. 재보니 **거의 다 남는다.** 감리에서 그 수치를 방어할 근거가 하나 늘었다.

---

## 5. 이 결론의 한계 — 넘겨 읽으면 안 된다

```
표본        test 256건. 관측 차이 0.012 는 95% 신뢰구간(±0.025) 안이라 미세 차이는 판정 불가
동일 분포    train/val/test 가 같은 코퍼스다. 이것은 분포 밖 일반화와 별개 문제다
tell 정의    내가 정의한 9개 패턴 기준이다. 다른 형태의 누출은 이 검사가 못 잡는다
학습기       생산 trainer 가 아니라 최소 학습기다(GPU venv 에 sklearn·datasets·pyarrow 가
            없고 오프라인이라 설치 불가). 두 팔이 같은 코드를 쓰므로 대조는 성립하지만
            절대값을 배포본 0.951 과 직접 비교하면 안 된다
```

세 번째가 특히 중요하다. **이 실험이 부정한 것은 "등급 표식 누출" 이지 "누출 일반" 이
아니다.** 길이·장르·형태 누출은 별도로 확인·수정한 것들이고, 아직 안 본 축이 있을 수 있다.

---

## 6. 부수 확인 — 마스킹이 새 신호를 만들지 않았다

표식을 지우지 않고 **중립 토큰으로 치환**했다. 통째로 지우면 문장이 깨지고 길이가 바뀌어
다른 신호가 생긴다.

```
등급토큰 노출   283 -> 0
길이-only 1NN  0.487 -> 0.487
Theil's U      0.080 -> 0.078
tell 문장       0종 -> 0종
```

'보안'·'취급'·'공개' 같은 일반 어휘는 건드리지 않았다. 그것까지 지우면 요소 판단의 근거가
사라져 과제 자체가 달라진다. 지운 것은 등급을 직접 지시하는 표식뿐이다.
