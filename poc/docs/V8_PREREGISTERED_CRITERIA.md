# v8 사전등록 — 결과를 보기 전에 기준을 적는다

작성 2026-08-13. **데이터 생성은 끝났고 학습은 시작하지 않은 시점에 쓴다.**

결과를 본 뒤에 기준을 정하면 통과시키는 쪽으로 정해진다. `V6_PREREGISTERED_PREDICTION.md`
가 같은 이유로 쓰였고, 거기 적어 둔 A/B 가설이 실제로 v6 진단을 갈랐다. 이 문서가 동결된
뒤에는 기준을 바꾸지 않는다. 바꾸려면 바꾼 사실과 이유를 이 문서에 남긴다.

---

## 1. 무엇을 검정하는가

v6 에서 확인된 두 가설을 v8 에서 다시 가른다.

```
(A) 문자열 -> 수준 매핑을 외웠다      다른 형태 · 다른 표현에서 무너진다
(B) 사실 -> 수준 을 일반화했다        다르게 쓰여도 읽는다
```

학습 손실로는 A 와 B 를 구분할 수 없다. **둘 다 손실 0 을 만든다.** 그래서 판정면을
두 축에서 동시에 분리했다.

```
형태 분리   holdout_forms = contract_terms · customer_list   학습에 한 번도 안 나온 형태
표현 분리   문장 풀 뒤 40%                                     학습과 교집합 0종
```

두 축이 동시에 분리됐으므로, 홀드아웃 성적이 유지되면 (B) 이고 무너지면 (A) 다.

---

## 2. 판정 지표 — 이 순서로 본다

게이트 순서는 기존 서빙 설계와 같다. **미탐이 F1 보다 앞선다.**

```
1  고등급 과소분류율        정답 TS/S1 을 더 낮은 등급으로 예측한 비율
2  형태별 최악 성능          홀드아웃 2종 **각각**. 평균으로 가리지 않는다
3  자동확정 커버리지 >= X 에서 무음 미탐 <= Y      (아래 §3)
4  요소별 MAE               secrecy · value · management
5  F1_macro                 마지막에 본다
```

### 부가 관측 (판정 조건은 아니나 반드시 기록)

```
S3-입증형 / S3-무신호형 별 정확도와 자동확정률     두 유형이 갈리는지가 게이트 설계의 전제다
언어 함정 포함 문서에서의 성적                    시제·범위·지시·방향별로 나눠 본다
counterfactual 쌍 정합률                        쌍의 한쪽만 맞히면 경계를 못 배운 것이다
```

세 번째가 중요하다. 쌍은 한 요소의 근거 문장만 다르므로, **쌍 양쪽을 모두 맞혀야** 경계를
배운 것이다. 한쪽만 맞히면 사전분포로 찍은 것과 구분되지 않는다.

---

## 3. 자동확정 조건 — 결합으로만 건다

**"무음 미탐 0" 단독은 조건이 될 수 없다.** 자동확정이 0 이면 정의상 성립하고, 그러면
자동확정을 0 으로 만드는 것이 게이트 통과의 최적해가 된다. 이 함정에 이미 두 번 빠졌다
(v3 에서 "무음 미탐 0" 을 안전의 증거로 읽었다가 자기 계보에서 3.8% 가 나왔다).

무미탐 관측의 95% 상한은 표본수로 정해진다:

```
목표 Y       필요 무미탐 자동확정 건수     자동확정률 10% 가정 -> 필요 평가량
0.5%         600                          6,000  (형태당 3,000)
1.0%         300                          3,000  (형태당 1,500)
2.0%         150                          1,500  (형태당   750)   <- 1단계 채택
```

### 1단계 조건 (동결)

```
자동확정 커버리지  >= 10%
무음 미탐 95% 상한 <= 2.0%    -> 무미탐 자동확정 150건 이상에서 관측해야 성립
고등급 과소분류율   배포본(v5) 대비 무회귀
형태별 최악        두 홀드아웃 형태 각각에서 위 조건 충족
```

**Y 를 정하는 순간 홀드아웃 생산량이 정해진다.** 형태당 750건이 "v8 완성"의 조작적 정의다.
현재 홀드아웃은 384건이므로 **1,500건까지 확대해야 판정이 성립한다.**

0.5% 를 1단계에 걸지 않는 이유는 형태당 3,000건이 필요해 생성·평가만으로 일정을 넘기기
때문이다. 실문서 라벨이 쌓이는 3단계에서 조인다.

## 4. 독립성 조건 — 두 모델의 합의를 믿기 전에

같은 코퍼스 · 같은 생성 규칙으로 학습한 두 모델의 합의는 안전 근거가 아니다. 현재 룰·모델의
"독립성"은 이미 허구다 — 분포 밖에서 룰은 800건 전부에 S3 라는 상수를 낸다.

```
1  서로 다른 백본인가
2  학습 라벨과 생성 과정이 분리됐는가
3  홀드아웃 형태에서 오류가 함께 발생하지 않는가
4  형태·등급을 통제한 잔차 오류 상관도가 상한 이하인가
```

### 상한 (동결)

```
같은 문서에서 두 모델이 동시에 틀릴 확률        <= 두 모델 오류율의 곱 x 2
같은 과소분류 방향으로 동시에 틀릴 확률          <= 전체 동시오류의 50%
형태·등급 통제 후 잔차 오류 상관도               <= 0.30
```

세 지표 모두 bootstrap 95% 상한으로 판정한다. 점추정으로 통과시키지 않는다.

## 5. 예측 — 결과를 보기 전에 적는다

적어 두지 않으면 무슨 결과가 나와도 설명을 붙일 수 있다.

```
홀드아웃 형태 F1_macro
  0.85 이상    (B). 형태·표현 결박이 실제로 풀렸다
  0.60 ~ 0.85  부분 성공. 어느 축이 남았는지 형태별·함정별로 분해해야 한다
  0.60 미만    (A). 문자열을 외웠다. 문장 풀을 더 늘리거나 저술 계보를 나눠야 한다

언어 함정 문서에서의 성적
  비함정 문서와 5pp 이내     근거 문장을 읽고 있다
  10pp 이상 하락            어휘에 반응하고 있다. 축 3 을 늘려야 한다

counterfactual 쌍 정합률
  0.80 이상    경계를 배웠다
  0.50 근처    한쪽만 맞히고 있다 = 사전분포로 찍는 것과 구분되지 않는다

S3-입증형 vs 무신호형
  입증형 정확도가 무신호형보다 높아야 한다. 반대면 부재 입증 문장을 못 읽는 것이고
  S3 자동확정 정책 전체가 성립하지 않는다
```

가장 걱정되는 것은 **counterfactual 쌍 정합률**이다. 쌍은 한 문장만 다르고 나머지가 전부
같으므로, 모델이 그 한 문장을 읽지 못하면 두 문서에 같은 등급을 준다. 그러면 정합률이
0.5 근처에 머문다. 이 지표가 v8 의 성패를 가장 직접적으로 말해 줄 것으로 본다.

## 6. 실패 시 무엇을 하는가 — 미리 정한다

```
(A) 로 판정         문장 풀 확대 + 저술 계보 3종 분리. 게이트는 열지 않는다
쌍 정합률 0.5 근처   요소 헤드가 근거 문장을 못 읽는 것. 청크 창을 먼저 확인한다
                    (v6 에서 value MAE 붕괴의 원인이 입력 창 절단이었다)
함정에서 10pp 하락   축 3 확대. 함정 유형별로 어느 것이 약한지 분해
자동확정 조건 미달   **임계를 낮추지 않는다.** 현행 배포본 유지 + 후보 결과 별도 보고
```

마지막 줄이 이 문서에서 가장 중요하다. 8/28 에 수치가 안 나오면 임계를 낮추고 싶어진다.
그러면 자동화율은 올라가고 미탐이 생긴다. 그 선택은 지금까지의 작업을 전부 무효로 만든다.

## 7. ICD 실패 시나리오

`tb_self_assessments` 와 연동 API 4종이 KL ICD 대기 상태다. 시스템 증거(공개·배포 이벤트 ·
문서유형 승인)를 못 받으면 S3 자동확정의 적극적 증거가 **본문 진술 tier 하나만** 남는다.

```
시스템 증거 확보 시     자동확정 커버리지 목표 10%
본문 진술만 남을 때     자동확정 커버리지 목표  5% + 표본감사 의무화
```

낮춘 목표를 지금 적어 두는 이유는, 12월에 미달로 보고되지 않고 **사전 식별된 외부 의존
리스크의 실현**으로 보고되게 하기 위함이다. 감리에서 방어력이 완전히 다르다.
