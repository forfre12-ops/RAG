## 3. 막고 있던 것은 문장 구문 하나였다

r17 에서 6개 형태 중 5개가 통과하고 `spec_change_log` 만 미탐 2건으로 걸렸다. 그 2건을
열어 보니 **둘 다 value 를 absent 로 확신 있게 오독**했고 문장이 이랬다.

```
  «이 조건 없이는 요구 납기를 맞출 방법이 없다»       이중부정 = 대체 불가
  «이 운전 조건이 연간 전력비의 상당 부분을 정한다»   부정어 없는 절제된 인과 표현
```

학습 lv2 27문장은 「알려지면 즉시 불리해진다 · 재현하려면 처음부터 다시 해야 한다」 처럼
**결과를 과장해** 말한다. 절제된 인과 표현이 없었다.

## 4. 그리고 여기서 두 번째로 같은 실패를 했다

r18 에서 위 두 구문을 **한꺼번에** 넣었다. 결과는 후퇴였다.

```
              F1_macro   tau 0.99 무음미탐
  r17          0.8316          2
  r18          0.7921         27      <- 이중부정 + 절제표현 함께
  r19          0.9188          0      <- 절제표현만
```

원인은 이중부정이다. value 의 absent 27문장은 «없다 · 않는다» 로 가득한데 lv2 에 «없이는
… 없다» 를 넣으면 그 경계가 무너진다. **3차에서 부정어 균형 조정이 실패했던 것과 같은
현상이고, 이번이 두 번째다.**

→ **value 에 부정 어휘를 더하지 않는다.** 두 번 측정했다.

## 5. 온도 보정은 이 지점에서 답이 아니었다

```
온도 적합   secrecy 3.42 · value 2.05 · management 2.93   (ECE 0.12 -> 0.02)

보정 후 게이트   tau 0.90  커버리지 8.78%  미탐 0  <- 미탐은 0 인데 커버리지 미달
                tau 0.99  커버리지 0%
```

온도가 확신을 눌러 tau 0.99 에서 아무것도 안 통과한다. 미탐 0 은 만들지만 커버리지 10%
요건을 못 맞춘다. **보정은 확신을 신뢰 가능하게 만들 뿐 없는 판별력을 만들지 못한다** —
필요한 것은 모델이 그 문장을 읽는 것이었고, 그것은 학습 데이터로 풀렸다.
