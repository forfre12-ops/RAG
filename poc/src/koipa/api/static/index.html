한국어 문서를 받아 4단계 보안등급(특급·1급·2급·3급)을 자동 판정합니다. 시드 v4 404개 키워드 · 부정경쟁방지법 §2조 2호 · KOIPA 가이드 v1 기반으로 분류 근거와 3 평가요소(S·V·M)를 함께 반환합니다.

정직성 표기 규칙

본 데모의 수치는 출처가 다음 3 종으로 명시됩니다.

실측 우리가 직접 측정 / 코드에서 카운트한 사실 · 명세 합격선·목표값·법령 등 명문화된 기준 · 참고 V2 통합본 인용 또는 예시 시나리오(미실측)

BERT 추론 1.18s · LLM 25.8s는 Phase 4/5 자체 GPU(RTX 5070 Ti) 실측. 사고 손해액은 예시 시나리오 기반으로 발주처 실문서 도착 후 실측치로 갱신 예정.

이 라이브 데모의 실시간 판정은 기본적으로 시드 키워드 룰 분류기(rule-fallback-v0)로 동작하며, 학습 KF-DeBERTa(v-dd3abab9)가 로드된 하이브리드 프로파일에서는 룰·모델 이중판정을 함께 노출합니다(실제 로드 상태는 하단 이중판정 패널이 표시). 위 1.18s·25.8s는 별도 GPU 환경 벤치 latency로 이 데모의 실측 응답시간과는 다릅니다.

§2.5운영 현황 · 검수 반영 DB 실측

아래 수치는 모두 DB 실측 카운트(가공 없음)입니다. "실시간 반영 시연"은 등록→분류→검수 교정→재분류를 실제로 호출하며, 교정 결과가 다음 분류에 반영되는 것을 보여줍니다.

버튼을 누르면 실제 문서를 등록·분류하고, 검수자가 등급을 교정한 뒤 같은 문서를 재분류합니다. 각 단계는 서버 실호출이며 위 카운터가 실시간으로 바뀝니다.
