문서 분류 샌드박스

데모 파일이나 비식별 텍스트로 분류 파이프라인과 판단 근거를 확인합니다. 이 화면의 결과는 테스트용이며, 고객 업무의 최종 등급·검수·확정 기록이 아닙니다.

§1테스트 입력 · 분류

파일을 올리거나, 데모 샘플을 선택하거나, 비식별 텍스트를 붙여넣으십시오. 처리 단계와 판단 근거는 결과 영역에 표시됩니다.

지원 형식과 처리 단계HWP · PDF · DOCX · XLSX 등을 받아 추출 → 정규화 → 개인정보 가림 → 분할 → 검수 게이트 → 등급까지 처리합니다. 추출기·품질·글자수·표·개인정보 가림 건수는 결과 안 「파싱 상세」에 있습니다.

분류 결과는 이 브라우저 화면에서만 확인합니다. 파일 업로드 뒤 검수 큐나 RAG 데모 컬렉션에 적재하지 않습니다.

주의: 이 경로는 임시 분석이 아닙니다. 파일 분석 뒤 검수 대상은 POST /documents → /classify로 실제 적재되며, 본문은 RAG demo 컬렉션에 색인됩니다. created_by=demo-console 표식만으로 관리자 콘솔에서 정리할 수 있습니다.

이 화면의 분석은 데이터베이스에 저장하지 않습니다. 올린 문서도 판정 결과도 남지 않습니다 — 문서 크기와 무관합니다 (큰 문서는 비동기로 분류하지만, 저장 경로를 타지 않는 것은 같습니다). 위 「실적재 경로」를 명시적으로 활성화했을 때만 적재됩니다.
자동확정과 검수 라우팅은 현재 서버 설정에 따릅니다. 기준값(확인 중…)에 못 미치거나 추출 품질 게이트가 실패하면 등급을 산출해도 자동확정하지 않습니다. 이 샌드박스 화면의 결과는 안전성·성능·고객 업무 승인에 대한 최신 증빙이 아닙니다.
데모 샘플 — 테스트 전용 예시 6종 (고객 문서·학습 근거·운영 성능 증빙 아님)
데모 샘플
위 5종(TS·S1·S3·S2·S1)은 자동 확정되는 경로입니다(2026-08-24 배포본 실측 · scripts/check_demo_docs.py --set oneclick). 아래 1종은 조용히 오분류하지 않고 검수로 넘기는 안전장치를 보여 줍니다 — 본문이 사실상 없어 추출 게이트가 잡는 경우입니다(확신도 때문이 아닙니다 — 실측 사유 extraction-gate). 이 6종은 본문이 267~448자로 짧습니다 — 확신도는 본문이 길수록 낮아지므로, 실제 업무문서(2,000자 이상)에서는 자동 확정 비율이 이보다 낮습니다.
문서 속성 (ICD) — 출처 · 보안표시 · 접근범위 · 선택. 넣으면 등급 판정에 반영됩니다
보안표시가 있으면 그 등급 아래로는 안 내려갑니다(명시 표기 우선, ICD §4.2). 접근범위는 표시가 없을 때 관리성(M)을 정합니다 — 본문에서 관측되지 않는 축이라 이 값이 유일한 근거입니다. ⚠ 전 직원 열람은 비밀관리성 요건 미충족이라 등급을 내리는 방향입니다 (법리상 영업비밀 아님). 미탐 방향이므로 시스템이 경고를 남기고 사람 검수로 보냅니다.

아래 키워드의 체크를 해제하면 본문에서 해당 단어가 일반어로 치환됩니다. 다시 「분류하기」를 눌러 ① 룰 엔진과 ② 분류기가 어떻게 다르게 반응하는지 보십시오. 「영업팀 주간 업무 공유 초안」 샘플에서 룰 엔진 등급은 S1 → S2 → S3로 내려가지만, 분류기는 단어 사전이 아니라 문서 전체의 문체·구조를 보므로 S2 를 유지하고 최종 등급도 S2 에 머뭅니다. 단어 몇 개를 바꾸는 것으로 등급을 낮출 수 없습니다 — 결합은 항상 더 심각한 쪽을 택합니다(미탐 최소화).

§2결과 — 왜 이 등급인가

등급·자동확정 여부와 그 사유·자연어 판단(양성+음성 근거)·3 평가요소(S·V·M)·근거 키워드. 자동확정 여부는 신뢰도 한 값이 아니라 다단 게이트로 정해지므로, 화면은 수치 대신 결정과 사유를 적습니다(수치는 API 응답·감사기록에 그대로 남습니다). 등급 배지를 클릭하면 §3 법령 카드로 이동합니다. 파일을 올린 경우에는 「파싱 상세」에 추출기·추출 품질·글자수·청크 수·구조화 표·PII 마스킹 건수와 검수 게이트 판정이 함께 표시됩니다.

§2.5개발 전용 · 테스트 데이터 변경 시연

일반적인 임시 분석과 별개인 개발 전용 쓰기 경로입니다. 등록→분류→검수 교정→재분류를 실제 호출하므로, 승인된 테스트 환경과 테스트 데이터에서만 사용하십시오.

버튼을 누르면 테스트 문서를 등록·분류하고, 검수 교정 뒤 같은 문서를 재분류합니다. 이 경로는 데이터 변경을 수반하며, 고객 문서나 운영 판단에 사용하면 안 됩니다.
