로이드케이/문서 파싱·분류 시연
분류 콘솔 거버넌스 콘솔 ↗ Analyze health

문서 업로드 → 파싱 → 검수 → 등급 시연

실제 업무 문서(HWP·PDF·DOCX·XLSX 등)를 올리면 추출 → 정규화·PII마스킹 → 청킹 → 검수 게이트 → 등급 분류까지 전 구간이 어떻게 처리됐는지 단계별로 보여줍니다. 실제 서빙 파이프라인(POST /documents/analyze)을 그대로 호출합니다.

연결
폐쇄망 데모는 API Base를 /api/v1(같은 호스트) 그대로 두면 됩니다. 헬스 배지를 눌러 연결을 확인하세요.

시연 문서 원클릭
위 4종(TS·S1·S2·S3)은 깨끗한 문서가 자동 확정되는 경로. 아래 2종은 파싱 이상(PDF 표 불완전·얇은 본문)을 조용히 오분류하지 않고 검수로 라우팅하는 안전장치 시연. 직접 업무 문서를 끌어다 놓아도 됩니다.
실적재를 켜면 분석과 별개로 문서를 실제 적재(POST /documents → /classify)합니다 — needs_review 건은 거버넌스 콘솔의 DB 검수 큐에 나타나고, 본문은 RAG demo 컬렉션에 색인됩니다. 적재 문서는 created_by=demo-console 로만 태깅되어 admin의 「데모 데이터 초기화」로 한 번에 지웁니다.
