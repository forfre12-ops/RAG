Lloydk·문서 파싱·분류 시연
분류 콘솔 거버넌스 콘솔 ↗ Analyze health

문서 업로드 → 파싱 → 검수 → 등급 시연

실제 업무 문서(HWP·PDF·DOCX·XLSX 등)를 올리면 추출 → 정규화·PII마스킹 → 청킹 → 검수 게이트 → 등급 분류까지 전 구간이 어떻게 처리됐는지 단계별로 보여줍니다. 실제 서빙 파이프라인(POST /documents/analyze)을 그대로 호출합니다.

연결
폐쇄망 데모는 API Base를 /api/v1(같은 호스트) 그대로 두면 됩니다. 헬스 배지를 눌러 연결을 확인하세요.
