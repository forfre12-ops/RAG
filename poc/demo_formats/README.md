파일명은 실제 문서 제목을 씁니다(등급은 파일명에 노출하지 않음 — 시연에서 시스템이 등급을 판정하는 것이 자연스럽기 때문). 각 제목당 `.docx/.pdf/.xlsx/.hwpx` 4개 포맷.

## HWP(바이너리 .hwp)에 대한 정직한 안내

- **`.hwpx`(현행 한/글 포맷)** 는 생성했습니다. 실 KOIPA hwpx를 구조 템플릿으로 재활용해 본문 문단을 새로 구성한 것으로, 파서(rhwp) 추출·분류 정상(품질 0.95, 잔여 원문 없음).
  - 단, 실제 한/글에서 열어 최종 확인을 권장합니다(파서 검증은 통과).
- **레거시 바이너리 `.hwp`** 는 이 PC에 **한컴오피스가 설치돼 있지 않고** 파이썬용 `.hwp` 라이터도 없어 **직접 생성 불가**합니다.
  - docx를 `.hwp`로 이름만 바꾸면 파서가 실패하므로(거짓 파일) 하지 않았습니다.
  - 바이너리 `.hwp`가 꼭 필요하면: ① `.hwpx`를 한/글에서 열어 "다른 이름으로 저장 → `.hwp`", 또는 ② 이미 보유한 실 KOIPA `.hwp`(공고문) 사용.

## 참고: 실 KOIPA 공개문서의 과분류

실제 KOIPA 공고문(.hwp)·제안요청서(.hwpx)는 진짜 바이너리라 파싱은 되지만 **공개문서인데도 과분류(TS/S1)** 됩니다.
이는 "미탐 최소화(안전우선)" 설계의 정직한 한계로, 검수 큐가 이를 걸러내는 구조입니다. 깨끗한 등급별 시연에는 위 합성 세트를 권장합니다.
