## 1. 법적 근거 (공개 출처)

### 1.1 부정경쟁방지 및 영업비밀보호에 관한 법률 (§2조 2호)

> "영업비밀"이란 공공연히 알려져 있지 아니하고 독립된 경제적 가치를 가지는 것으로서, **비밀로 관리된 생산방법·판매방법, 그 밖에 영업활동에 유용한 기술상 또는 경영상의 정보**를 말한다.

**3대 요건** — 모든 등급(TS·S1·S2)에 공통 적용:

1. **비공지성** (Non-publicity): 공공연히 알려져 있지 아니할 것
2. **경제적 유용성** (Economic Value): 독립된 경제적 가치
3. **비밀관리성** (Management Level): 비밀로 관리되고 있을 것

### 1.2 산업기술의 유출방지 및 보호에 관한 법률

- **§9 (산업기술 지정)**: 국가핵심기술 → 본 시스템 TS 등급 자동 매핑
- **§14 (유출 금지)**: 산업기술 보유 기관의 임직원·전직자 의무
- **§22 (수출 승인)**: 국가핵심기술의 외국 매각·이전 시 산업통상자원부 승인 필요

### 1.3 영업비밀보호법 시행령

- **§3 (관리 수준 판단 기준)**: 비밀 표시·접근 통제·보관·전달 절차의 4축
- 본 시스템은 시행령 §3을 4 평가요소(LEAK_IMPACT·ECONOMIC_VALUE·MANAGEMENT_LEVEL·NON_PUBLICITY)로 변환

## 2. 4 평가요소 정의 (시드 v3 정합)

| 코드 | 명칭 | 가중치 | 정의 | 시드 키워드 수 (v3) |
|---|---|---|---|---:|
| **LEAK_IMPACT** | 유출 시 영향도 | 0.30 | 유출 시 회사·산업·국가에 미치는 손해 규모 | 33 |
| **ECONOMIC_VALUE** | 경제적 가치 | 0.30 | 독립된 시장 가치, 대체 비용, 경쟁우위 기여도 | 126 |
| **NON_PUBLICITY** | 비공지성 | 0.25 | 공개 정보망(법령·공시·논문)에서 미공개 정도 | 115 |
| **MANAGEMENT_LEVEL** | 관리 수준 | 0.15 | 접근 통제·암호화·NDA·물리 보호 등 관리 강도 | 39 |
| **합계** | — | 1.00 | — | **313** |

각 요소는 **0~5점**으로 평가되며 최종 점수 = Σ(score × weight). 등급 임계값:

| 최종 점수 | 등급 |
|---|---|
| ≥ 4.0 | TS |
| 3.0 ≤ x < 4.0 | S1 |
| 2.0 ≤ x < 3.0 | S2 |
| < 2.0 | S3 |

> ⚠ **(v1.1) 가중합보다 §4.0 비공지성 게이트가 우선한다.** 위 가중합은 4요소를 더하므로 경제가치·관리수준 점수가 높으면 **이미 공개된 문서**도 TS/S1로 산출될 수 있다(실측: 진짜 공개판례의 85%가 비밀로 과분류 — [doc/32 §1](32_평가체계_실데이터_전환_권장안.md)). 법리상 비공지성은 가중 요소가 아니라 **필요조건**이다(부정경쟁방지법 §2.2). 따라서 §4.0 게이트가 가중합 결과를 **덮어쓴다**.

## 4. 등급 경계 판단 가이드 (M3 룰 라벨러용)

### 4.0 비공지성 게이트 — 출처 우선 규칙 (v1.1, 최우선 적용)

**원칙:** 영업비밀의 3대 요건(§1.1) 중 **비공지성은 가중 요소가 아니라 필요조건(gate)** 이다. 부정경쟁방지법 §2.2는 "**공공연히 알려져 있지 아니하고**"를 전제로 한다 — 이미 공개된 정보는 경제적 가치·관리 수준이 아무리 높아도 영업비밀이 **성립하지 않는다**. 따라서 등급 산정은 다음 2단계로 한다:

```
1단계 (Gate 1 · 출처): 이 문서가 이미 공개되었는가?
    YES → 무조건 S3.  내용 점수(§2 가중합)·등급 키워드 전부 무시.
    NO  → 2단계로.
2단계 (Gate 2 · 내용): §2 가중합 + §3 기준으로 TS/S1/S2/S3 산정.
```

**공개 출처(= 비공지성 미충족 → S3 강제) 판단 기준** — 다음 중 하나라도 해당하면 공개:

| 신호 | 예시 |
|---|---|
| **공개 경로 메타데이터** | source = 판례·공시·보도자료·공개특허·공공입찰·공개논문·정부공개(FOIA) |
| **공표 채널 명시** | DART/EDGAR 공시, 관보, 법원 공개 판결문, 학회/프리프린트, 공식 SNS·블로그 |
| **본문 공개 신호** | "공개", "공시 대상", "보도자료", "이미 공개", 오픈소스 라이선스 명시 |

**핵심 사례 — 공개 법원 판결문:**
공개된 판결문은 *영업비밀 침해를 다룬 사건이라도* 그 **판결문 자체는 공개 문서(S3)** 이다. 판결문이 묘사하는 비밀 내용에 이끌려 TS/S1로 올리지 않는다. (그 비밀 내용을 학습 데이터로 쓰려면 [doc/32 §3 재구성 규칙](32_평가체계_실데이터_전환_권장안.md) 준수 — 판결문 본문 verbatim 사용 금지.)

**"모호하면 상향(FNR 회피)" 원칙과의 관계 ([LABELING_GUIDE](../poc/datasets/gold_real/LABELING_GUIDE.md)):**
상향 원칙은 **2단계(내용 축)에만** 적용한다 — 진짜 비밀을 과소평가하지 않기 위함. **1단계에서 공개로 판정된 문서는 절대 상향하지 않는다** (공개 = 비공지성 미충족 = 영업비밀 불성립). 이 구분을 놓쳐 공개문서까지 상향한 것이 과분류의 직접 원인이다.

**구현:** 런타임은 `m5_inference/pipeline.py`의 `source_prior` 게이트(`settings.source_prior_enabled`, `source_prior_cap_grade`)로 1단계를 적용한다. 학습 데이터 역시 공개 출처 문서를 S3로 재라벨해야 출처 불명(메타데이터 없는) 입력에서도 모델이 같은 규칙을 학습한다 ([doc/32 §3](32_평가체계_실데이터_전환_권장안.md)).

### 4.1 등급 상승 트리거 (S2 → S1)

- "내부" + 핵심기술 키워드 (예: "내부 공정 노하우" → S1)
- "내부" + 보안 키워드 (예: "내부 API 키" → S1)
- 명시 표기 우선 — "1급 비밀"이 본문에 있으면 다른 키워드 무관 S1

### 4.2 등급 상승 트리거 (S1 → TS)

- "핵심 원천기술" + 도메인 키워드 (예: "핵심 원천기술 + EUV 공정" → TS)
- "M&A" + "비공개" 동시 출현 → TS
- 마스터 키·루트 CA 등 시스템 전체를 위협하는 보안 자산

### 4.3 등급 하강 트리거 (S1·S2 → S3)

- "공개" + "보도자료" 동시 출현 → S3
- "공시" + 재무 키워드 → S3 (이미 DART 공개)
- "오픈소스" + 라이선스 명시 → S3

### 4.4 모호 사례 (수동 검수 권장)

| 본문 | 후보 등급 | 검수 포인트 |
|---|---|---|
| "M&A 검토 자료 — 내부 회람" | TS or S1 | "검토"는 미확정. 진행 단계에 따라 결정 |
| "고객 데이터베이스 통계 — 익명 처리" | S1 or S2 | 익명화 수준 검증 필요 |
| "특허 출원 검토" | S1 or S2 | 출원 전(S1) vs 출원 후(S3) 구분 |
| "내부 교육 자료" | S2 or S3 | 일반 교육(S3) vs 노하우 교육(S2) |
