시연 콘솔 소개

2026-06-29 운영 전제 업데이트: 실데이터 0 · 빌드 검수 0 · 반출 0 제약에서는 배포 전 정확도 검증을 주장하지 않는다. 합성/LLM 라벨은 학습 시드·상대비교·회귀 테스트용이며, locked_gold_eval은 사람 서명 전용이다. 현재 목표는 "검증된 분류기 배포"가 아니라 룰 우선 안전 부트스트랩 + 보수적 검수 라우팅 + 운영 관리자 확정에서 배우는 루프다. 이 문서의 기존 F1/FNR/PASS 수치는 합성·OOD·프록시 또는 메커니즘 검증으로만 해석한다.

시스템에는 두 개의 웹 콘솔이 있습니다 — 실시간 분류 데모(등급 판정을 눈으로)와 거버넌스 운영 흐름(검수·교정) 콘솔(검수·교정·메트릭을 한 화면에서). 본 문서는 화면 흐름과 접속법을 설명합니다. 실제 동작은 서버 가동 시이며, 정적 문서로는 버튼이 동작하지 않습니다.
※ 환류=재학습은 미확정(A 무반출 기본 / B 온사이트 / C 반출). 기본 A안은 집계 진단지표만 환류하며, 고객사는 추론·확정 포착·exact-match 선례 우선이다.

01실시간 분류 데모

① 실시간 분류 데모

한국어 문서를 넣으면 4단계 보안등급(특급·1급·2급·3급)을 자동 판정하는 라이브 콘솔. 등급·신뢰도·평가요소(S·V·M)·근거 키워드를 함께 보여줍니다.

기능설명
샘플 분류샘플 문서 선택 또는 직접 입력 → 등급 판정 (SSE 단계 점등)
키워드 토글키워드를 끄면 등급이 어떻게 바뀌는지 즉시 확인 (S/V/M 민감도)
BERT vs LLM 경쟁동일 문서를 두 방식으로 처리해 속도 비교 (실측)
법령·사고 시뮬등급별 법령 근거 + 미탐(FNR) 사고 시나리오 시각화
02거버넌스 콘솔

② 거버넌스 폐곡선 콘솔

운영 거버넌스 흐름(분류 → 검수 → 재학습 → 모델 핫리로드 → 메트릭)을 한 화면에서 시연하는 E2E 검증 콘솔. 기존 /api/v1 엔드포인트를 그대로 호출합니다. (재학습 환류 = 고객사 CPU 야간 증분재학습, 무반출·활성화는 사람 사인오프)

1 분류→ 2 검수→ 3 재학습→ 4 모델 리로드→ 5 메트릭
1
분류 실행
골든셋 샘플(등급별 2건) 또는 직접 입력 → POST /classify. 등급·신뢰도·S/V/M·근거 표시. "골든셋 8건 일괄 분류"로 검수 큐에 한 번에 적재.
2
검수 큐 — 확정/재라벨
자동확정·검수 라우팅은 신뢰도 임계(기본 0.7) 단독이 아니라 다단 게이트로 결정합니다. 신뢰도 게이트에 더해 희소근거 게이트(룰-폴백 경로 기본 ON, 단일 약한 키워드 자동확정 차단)와 합의 게이트(base 기본 OFF·운영 프로파일 별도, 예측이 공개등급이거나 룰등급==모델등급일 때만 자동확정)를 적용합니다. 통과하지 못한 건은 자동 플래그 → 사람 검수로 보냅니다. → POST /confirm(확정)·/relabel(등급 교정). 재학습 큐·임계 표시.
3
재학습 트리거
POST /train + 작업 목록 폴링. 누적 corrections가 임계 도달 시 재학습. 단발 트리거(드리프트/이벤트)이며 상시 재학습 아님; 재학습 주체=지재원 합성 + 고객사 CPU 야간 증분.
4
모델 핫리로드
POST /admin/model/reload — 활성 모델을 프로세스 재기동 없이 서빙 반영.
5
메트릭 · FNR 게이트
GET /metrics/* — 정확도·등급별 FNR·이력·등급체계 조회.
왜 다단 게이트인가 — 신뢰도 단독이 아닌 이유

신뢰도(confidence)는 분류기가 학습한 정답확률이 아니라 softmax 파생값(logits→온도→softmax→청크집계→정규화)이라, OOD(골든/실데이터)에서 과신하며 정답/오답 판별력이 낮습니다(골든500 AUROC 0.58, ECE 0.18). temperature 보정도 val 분포 내 과신만 완화할 뿐 OOD로는 전이되지 않습니다. 그래서 자동확정은 신뢰도 단독이 아니라 게이트로 판단합니다(희소근거 룰-폴백 기본 ON, 합의 base 기본 OFF):

  • 희소근거 게이트(rule_fallback_min_evidence) — 단일 약한 키워드만으로 conf=1.0이 되는 룰-폴백 자동확정을 차단(golden100 무성 TS 미탐 5→0).
  • 합의 게이트(agreement_gate_enabled) — 자동확정은 예측이 공개등급(S3)이거나 룰등급==모델등급일 때만 허용하고, 그 외 불일치는 사람 검수로 보냅니다(자동확정 정밀도 63→81%, 고등급 TS/S1 미탐 46→8). TS/S1 자동확정분은 표본감사합니다.

합의 게이트 재생성 기준 — golden100: 자동확정 35 / 검수 65(미탐 0), golden500: 자동확정 189 / 검수 311(TS·S1 미탐 8). 모든 수치는 합성 골든셋(OOD) 기준이며 운영 human_review/locked 확정 전에는 운영 FNR/정확도 수치가 아닙니다.

왜 중요한가 (KL 관점)

이 콘솔은 KL이 전달하는 메타데이터(출처·보안표시·접근범위)가 분류 결과에 어떻게 반영되는지를 눈으로 확인하는 자리이기도 합니다. KL 연동(ICD) 합의 후, KL이 채운 메타데이터로 분류·검수가 도는 것을 1단계 분류에서 검증할 수 있습니다.

03시연 안내

미팅 시연 방법

  • 라이브 시연 — 미팅 시 로이드케이가 서버를 띄워 위 5단계를 직접 시연합니다(룰엔진 안전 veto가 대표 경로이며, KF-DeBERTa 분류기가 CPU 추론으로 병행 판정 — 등급 핫패스는 LLM-free·무GPU).
  • 정적 문서 — 본 소개 문서로 화면 흐름·기능을 사전 파악할 수 있습니다(버튼 동작은 라이브에서만).
  • 한국어 입력 — 한국어 본문도 정상 처리됩니다.
참고 — 데이터 표기

시연에 쓰는 샘플은 운영 골든셋(합성 텍스트)이며, 발주처 실문서 도착 전 기준입니다. 실데이터 입수 후 실측치로 갱신됩니다.
