의사결정 대장

2026-06-29 운영 전제 업데이트: 실데이터 0 · 빌드 검수 0 · 반출 0 제약에서는 배포 전 정확도 검증을 주장하지 않는다. 합성/LLM 라벨은 학습 시드·상대비교·회귀 테스트용이며, locked_gold_eval은 사람 서명 전용이다. 현재 목표는 "검증된 분류기 배포"가 아니라 룰 우선 안전 부트스트랩 + 보수적 검수 라우팅 + 운영 관리자 확정에서 배우는 루프다. 이 문서의 기존 F1/FNR/PASS 수치는 합성·OOD·프록시 또는 메커니즘 검증으로만 해석한다.

이 문서 하나로 KOIPA 영업비밀관리시스템의 전체 의사결정 이슈를 파악·추적한다. 미팅 진행 흐름 + 발주처/KL 합의 + DB 거버넌스 + 본개발 + 사업 판단을 모았고, 각 항목에 배경 · 선택지 · 추천 · 주체 · 상태를 담았다. 상세 근거는 발주처 안건서·ICD·적용서 링크 참조.

03DB · 인프라 거버넌스

항목배경 · 선택지추천(우리 입장)상태

벡터·검색 백엔드 — ES → Postgres 단일화 신규Elasticsearch(nori+BM25) 제거·PG 단일화 검토. dense는 pgvector 채택 방향. 변수는 한국어 lexical 채점기 — 실측(_bench_pg_lexical_revalidation, 합성·발췌쿼리라 낙관치): PG 코어 ts_rank는 IDF 부재로 R@5 80~85%(vs nori 94%), raw pg_bigm/pg_trgm 유사도는 62~71%로 붕괴. nori 동급(92~94%)은 BM25 확장(ParadeDB·pg_search/VectorChord-bm25) 또는 앱사이드 채점 필요(폐쇄망 부품·라이선스 재검토 수반). NL(비발췌 190건) 재검증 추가(--tag nl): bigram(pg_bigm) 토큰의 ts_rank=87%≈nori-BM25 89%로 morph와 동급 유지(="토큰화는 위험 아님"이 패러프레이즈 쿼리서도 성립, 적대검증 "발췌 편향" 반증 기각) — 단 어절(plain tsvector 'simple')은 NL서 47%로 붕괴 → 어휘채널은 bigram 토큰 필수. [실 PG 풀스택 측정 2026-06-24 — 최종] Docker→pgvector 이미지→마이그레이션→실 연산자(NL 190). 구현 함정: ts_rank_cd(cover-density)는 OR-매칭 흩어진 bigram에 근접도≈0이라 36%로 붕괴 → ts_rank(plain, norm=1)로 교정 시 어휘 단독 87%(프록시 적중). 결정타: 실 하이브리드(dense+ts_rank) R@5=85% > dense-only 76%(+9pp), R@10 91% vs 80%(실 85%≈프록시 86%). 이긴 경로는 pgvector dense + bigram-tsvector ts_rank뿐 — raw pg_bigm 26%라 미사용ⓑ 확정: pgvector dense + bigram-tsvector ts_rank(plain,norm1) 하이브리드 + RRF (실 PG R@5 85% > dense 76%). pg_bigm 확장 불요(하이브리드 미사용; bigram tsvector + GIN로 충분) → 스톡 pgvector/pgvector:pg16로 ES 제거 가능. 어휘 랭킹은 반드시 ts_rank(plain,norm1), ts_rank_cd 금지. 한계: NL=합성·LLM쿼리라 실 운영쿼리로 모니터결정(실측)
