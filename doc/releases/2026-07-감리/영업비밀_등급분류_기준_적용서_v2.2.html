03 시스템 적용 결정

본 시스템 적용 결정

3.1 산정 요소: 정본 3요건 채택

영업비밀의 법적 정의(부정경쟁방지법 §2.2)는 비공지성·경제적 유용성·비밀관리성 3요건이고, 정본 가이드 B안이 이를 그대로 S/V/M으로 쓴다.

코드명칭정본 대응비고
SECRECY비공지성 (S)가이드 비공지성 0/1/2곱셈 게이트 — 0이면 전체 0
VALUE경제적 유용성 (V)가이드 경제적 유용성 0/1/2
MANAGEMENT비밀관리성 (M)가이드 비밀관리성 0/1/2

v1.1의 4번째 요소 DAMAGE/LEAK_IMPACT(유출영향도)는 삭제한다. 정본 3요건에 없고, '외부 유출 위험'은 A안(보조)에만 존재한다. 유출영향도 의미는 등급 서열 + tb_classification_levels.loss_weight(고등급 오분류 가중)로 보존한다.

3.2 점수 스케일 변경: 0~5 → 0~2, 합산 → 곱셈

  • 각 요소 점수 도메인을 0/1/2로 변경(현 0.0~5.0 CHECK → 0~2)
  • 최종 등급 = grade_from(S × V × M) (가이드 4단계 매핑). 기존 가중합·임계값(4.0/3.0/2.0) 폐기

3.3 왜 B안(곱셈)인가 — 채택 근거

  1. 4등급 1:1 매핑 — 8/4/1·2/0 → 특급/1급/2급/3급으로 깔끔히 대응
  2. 과분류 근본 차단 — 곱셈은 한 요소라도 0이면 0(공개). v1.1이 게이트(§4.0)로 따로 막던 "공개문서 과분류"(실측: 공개판례 85% 과분류)를 산정식 자체가 내포
  3. 라벨링·골든셋 단순화 — 입력이 0/1/2 3단계뿐이라 사람 검수·합성 라벨·일치도 측정이 단순하고 재현성이 높다
  4. 정본 예시와 직접 대조 가능 — 가이드 12p 워크드 예시를 회귀 테스트 정답으로 그대로 사용
  5. AI 운영 가능성 (결정적 근거) — A안 5요소 중 '정보 창출·유지 비용', '내부 활용 효과', '외부 유출 위험'은 문서 본문에 거의 없는 외부 경영·재무 정보라 텍스트 분류 AI로 산출 불가. 반면 B안 3요건은 텍스트·메타데이터로 근사 가능. A안=사람 수기 정량평가용, B안=AI 자동분류용.
설계 결정 (수행사 전문가 판단)

AI 자동분류 정본 산정법 = B안(S×V×M). A안은 회원사 수기 자가진단 보조(§6)로 보존. 이는 위 5개 기술·법리 근거에 따른 수행사 설계 결정이며, 발주처에는 근거와 함께 통보한다. 트레이드오프: B안은 0/1/2 3단계라 A안의 100점 그라데이션보다 세밀도가 낮다 — 단 R1·R2로 보완되며 AI 운영가능성·법리정합 이득이 세밀도 손실을 압도한다.

3.4 특급기밀(TS) 처리 — 자동분류 + 수동지정 병행

정본은 특급을 자체분류(A안) 또는 극비 S=V=M=2(B안)로 본다. 본 시스템은 다음 OR 조건으로 TS를 부여한다:

  1. S×V×M = 8 (S=V=M=2), 또는
  2. 명시 표기 본문/메타에 "특급기밀·극비·Top Secret·1급 보안·Eyes-Only" 등, 또는
  3. 관리자 자체분류(수동 오버라이드) — 점수와 무관하게 기업/담당자가 특급 지정

AI는 특급을 제안하되 특급은 본질적으로 판단·자체분류 영역이므로 항상 사람 확정을 거친다(FUN-005 임시저장→확정과 정합). 평가 시 특급의 미탐율(FNR)을 보안상 최우선 지표로 관리한다. AI 특급-FNR 평가 대상은 "텍스트로 산출 가능한 특급(S=V=M=2 신호 보유)"에 한정하고, 텍스트 신호가 없는 순수 자체분류 특급은 AI 책임 범위 밖으로 둔다.

3.5 설계 정합성 점검 — 적용 정밀화 (R1~R6)

"B안이 AI 시스템에 최선인가"를 과분류↔과소분류(미탐) 트레이드오프 관점에서 재점검한 결과 도출한 6개 정밀화다.

항목내용상태
R1 룰↔모델 분리BERT 분류기는 텍스트→등급을 직접 학습·추론한다. S×V×M은 학습 라벨·룰 후보·근거(evidence) 산정 계층이지 모델의 추론식이 아님 → 곱셈의 "급변(cliff)"이 모델 추론에 직접 전가되지 않는다.기설계 내포
R2 추론단 미탐 안전장치출처(비공지성) 게이트는 과분류 93%→0%. 곱셈 게이트는 출처/비공지성(S) 축에만 하드 적용, 내용(V·M) 축은 콘텐츠 미탐 가드 + 상향충돌 시 검수 라우팅 유지(silent 하향 금지).기설계 내포
R3 등급체계·매핑 설정화등급 개수와 S×V×M→등급 매핑(8/4/1·2/0)을 하드코딩하지 않고 DB·설정 주도로 둔다(FUN-005 관리자 등급체계 변경 요구사항).신규 반영
R4 유출영향도 처리정본 3요건에 없음. 등급 서열 + loss_weight(고등급 오분류 가중) + 등급별 FNR로 보존(별도 입력 요소 아님).신규 반영
R5 특급 표본·기대치특급은 희소. 골든셋 특급은 합성·수동 시드로 별도 확보, 내용만으로 특급을 못 만들어도 미탐으로 과벌하지 않는다.신규 반영
R6 S·M은 메타데이터 의존비밀관리성(M)과 사실적 비공지성(S)은 본문 텍스트만으로 판정 곤란. KL 웹계층의 출처·보안표시·접근범위 메타데이터를 S/M 산정 입력으로 받는다.신규 반영

3.6 가이드 내부 변이 — 설계 판정 + 근거

가이드 예시표(p6~9)와 산정법(p11~12)이 일부 불일치. B안 채택의 귀결로 등급은 S×V×M 계산이 정본이고 예시표는 전형값 예시로 본다.

정본 가이드 PDF는 텍스트 레이어가 없는 스캔 이미지본(16p)이라 전 페이지를 직접 판독했다. 확인 결과 가이드는 두 산정법을 모두 제시한다 — A안(Σ 5요소 100점)은 p4 절차도·p5 산정식, B안(S×V×M 곱셈)은 p11 배점·p12 방법. p12는 곱셈값 4단계 매핑(0→공개 / 1·2→대외비 / 4→비밀 / 8→극비)과 워크드 예시(조직도 1·1·1=1=대외비, 인사평가보고서 1·2·2=4=비밀, 중장기경영계획 2·2·2=8=극비)를 제시한다. 가이드는 또한 "기업 여건에 따라 2~4단계 중 선택"(p12)과 "S 또는 V 단독값만으로 분류 가능"(p11)을 명문화해, 산정법·단계 선택을 기업 재량으로 둔다 — 본 시스템의 B안·4단계 채택은 가이드 위배가 아니다.

본 시스템 v2.2의 grade_from_svm은 가이드 B안(p12) 곱셈 매핑을 기반으로 하되, 골든셋 100건 실증에 따라 두 곳을 운영 보정했다. 가이드 원본 매핑과의 정확한 차이는 다음과 같다.

A안 = 사람 수기 (역할 분담 확정)

A안 5요소 중 65점(내부 활용효과 35 + 외부 유출위험 30)은 문서 텍스트에 없는 경영·재무 판단값이라 텍스트 분류 AI로 산출 불가. 가이드도 A안 특급을 "기업 자체분류"로 두어 사람 판단을 전제한다. ∴ AI = B안 곱셈으로 1차 자동분류 / 사람 = A안으로 가치 정밀평가(회원사 수기 자가진단 보조, §6). 경쟁이 아니라 용도가 다른 보완 관계 — A안의 AI 구현은 시도하지 않는다.

06 A안 보조 보존

A안(5요소 100점) 보존 — 보조 옵션 + 충돌 해소 정책

A안(§1.1)은 회원사 자가진단/정량 산정 보조 모드로 보존한다. AI 자동분류 정본 룰은 B안이며, A안은 기업이 수동으로 자료 가치를 정량 평가할 때 별도 산식으로 제공한다(선택).

6.1 A안과 B안은 합산하지 않는다 — 다른 척도

두 안은 척도가 달라 점수를 직접 더하거나 평균낼 수 없다. 각자 4등급으로 환산한 뒤 등급 코드 수준에서만 비교한다. A안과 B안을 가중합하는 제3의 공식은 두지 않는다.

등급 임계특급=자체분류 / ≥75 1급 / ≥50 2급 / <50 3급8 특급 / 4 1급 / 1·2 2급 / 0 3급
특급 산출점수로 안 나옴 — 자체분류(사람 별도 지정). 100점 만점도 자동은 1급까지곱=8이면 특급 산출 (단 확정은 항상 사람)
입력 정보매출 기여도·유출 손실 등 경영·재무 판단 포함문서 텍스트·메타데이터 근사

6.2 A안으로 매기면 그게 절대기준 — 사람 우선

사람이 A안 100점으로 정량 평가하면, A안 자체의 임계(특급=자체분류 / ≥75 / ≥50 / <50)로 확정된 등급이 그 문서의 절대기준이 된다. 이는 시스템의 기존 원칙 "사람이 확정한 라벨이 있으면 AI 추론을 건너뛴다"(verified_label 우선, classify_service)와 동일하다. 사람 판단 > 기계 추론.

A안(사람 확정) 있음   → A안이 절대기준. AI(B안) 추론 스킵
A안 없음             → B안(AI)이 1차 자동분류
둘 다 있고 불일치     → 사람(A안) 우선
                       단 AI가 더 높은 등급이면(미탐 위험) 검수 라우팅
                       AI가 더 낮으면 무시(사람 우선)
충돌 해소 = 산술 합산이 아니라 우선순위 + 보안 게이트

핵심은 "사람 우선 + 보안상 AI가 더 높으면 재확인"이다. AI(B안)가 사람(A안)보다 낮게 보면 사람 판단을 따르고, 높게 보면 흘려보내지 않고 검수로 띄운다(미탐 방지). 두 등급을 평균·가중합하는 일은 없다.

특급은 A안에서 점수로 안 나온다

A안은 특급기밀 = "기업 자체분류"라 100점 만점을 받아도 자동으로는 1급까지만 산출된다. 특급은 사람이 별도 명시 지정해야 한다(§3.4 — AI는 제안만, 특급 확정은 항상 사람). 운영 화면에서 A안 75점↑ 문서는 "1급(특급 후보)"로 표시하고 특급 승격은 별도 결재로 둘 것.
