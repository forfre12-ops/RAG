안녕하십니까, 로이드케이입니다.

저희 담당 파트는 **"문서를 넣으면 등급이 나오는 AI 엔진"** 입니다.  
특급기밀부터 3급 공개까지 4단계로 자동 분류하고, 분류 근거도 함께 제공합니다.

오늘은 PoC 5종의 실측 결과와 다음 단계 계획을 보고드립니다.

## 슬라이드 2: PoC 5종 실측 결과 (1분 30초)

**총 5가지 검증 항목을 완료했고, 핵심 4종은 합격선을 통과했습니다.**

첫째, **분류 정확도(P1)**: F1-macro 1.0, 특급→하위 미탐율 0%. 합격선 F1 0.75 대비 큰 여유입니다.

둘째, **문서 추출(P4)**: HWP·DOCX·PDF 모두 누락률 0%, 품질 0.986. 합격선 누락 5% 이내를 충족합니다.

셋째, **합성 데이터(P3)**: Qwen3-14B로 생성한 문서의 라벨 일치도 100%. 외부 API 없이 온프레미스 GPU로 달성했습니다.

넷째, **E2E 응답 시간(P5)**: RAG 없이 380ms, RAG 포함 9.2초. 합격선 각 10초·30초 대비 26배·3.3배 여유입니다.

**한 가지 재측정이 필요한 항목**이 있습니다. RAG 검색 정확도(P2)는 현재 0.70으로, 합격선 0.80 미달입니다. 원인은 합성 문서의 boilerplate 한계로 확인됐으며, **발주처의 가이드 문서 v2 제공 시 즉시 재측정**하겠습니다.

---

## 슬라이드 3: 차별화 포인트 3가지 (1분 30초)

**첫 번째, 외부 API 없이 완전 동작합니다.**  
Qwen3-14B를 자체 GPU에서 구동해 분류·합성·RAG 답변을 생성합니다. 폐쇄망 환경에서도 인터넷 없이 운영 가능하며, 납품 패키지 크기는 22.8GB입니다.

**두 번째, 미탐 방어를 3단계로 설계했습니다.**  
① 비대칭 손실 함수로 특급기밀 미탐을 최소화하고, ② 신뢰도 임계값 미달 시 관리자 확인 큐로 자동 전송하며, ③ 15분마다 드리프트를 자동 감시합니다.

**세 번째, 감사 추적이 변조 불가능합니다.**  
모든 분류 결과에 SHA-256 해시 체인을 적용해 사후 수정이 불가능하며, 완전한 감사 로그를 제공합니다.

---

## 슬라이드 4: 다음 단계 및 요청 사항 (1분 30초)

**지금 즉시 가능한 것**: 데모 콘솔에서 실시간 분류·RAG 답변·근거 인용을 시연할 수 있습니다.

**발주처 협조가 필요한 두 가지**:

첫째, **등급분류 가이드 문서 v2** 제공 부탁드립니다. RAG 검색 정확도 0.80 달성에 직접 영향을 미칩니다. 공개 법령 기반 임시 가이드로 현재 운영 중이나, 정본으로 교체가 필요합니다.

둘째, **실문서 샘플**(비밀해제 또는 가명처리 문서 50~100건)이 제공되면 분류 정확도 실문서 기준 재측정과 최종 F1·FNR 확인이 가능합니다.

저희는 GPU 0, API 비용 0, 완전 오픈소스 스택으로 납품 준비가 완료된 상태입니다.  
**두 가지 자원만 제공해 주시면 최종 검증을 마무리할 수 있습니다.**

감사합니다.
