## 1. 부팅 명령 (lite-noapi — 외부 의존 0)

PowerShell 기준:

```powershell
$env:PYTHONIOENCODING="utf-8"
$env:DEPLOY_PROFILE="lite-noapi"
$env:VECTOR_BACKEND="inmemory"
$env:POC_MODE="dryrun"
$env:SLOWAPI_SKIP_DOTENV="1"
$env:RATE_LIMIT_DISABLED="1"
$env:AUDIT_DISABLED="1"
$env:API_KEY="devkey"
$env:LLOYDK_API_KEY="devkey"
$env:PYTHONPATH="poc/src"
python -m uvicorn lloydk.api.app:app --host 127.0.0.1 --port 18022
```

브라우저 진입: `http://127.0.0.1:18022/demo/`

- nav 상단 우측에 `lite-noapi · LLM noop · emb hash` 배지가 녹색으로 표시되면 부팅 완료
- 부팅 시 `_warmup_models` 가 hash embedder 워밍업 1회 호출 (lite-noapi 는 즉시 반환)

다른 프로파일 전환:

| 프로파일 | 변경 env | 비고 |
|---|---|---|
| lite-cloud | `DEPLOY_PROFILE=lite-cloud` + `LLM_PROVIDER=anthropic` + `ANTHROPIC_API_KEY=...` | RAG 답안 합성 실호출 |
| onprem-local | `DEPLOY_PROFILE=onprem-local` + vLLM 기동 + `LLM_PROVIDER=vllm` | 폐쇄망 표준 |
| full-train | `DEPLOY_PROFILE=full-train` + GPU + `ENABLE_TRAINING=1` | `/train` 라우터 활성 |

## 6. 분담 명확화

이 콘솔은 **KL 화면 침범 아님**. KL 이 만들 발주처 운영 화면(FUN-001·002·006~021)과 별개:

| 사용자 | 이 콘솔 | KL 운영 화면 |
|---|---|---|
| KOIPA 임직원 (실무자) | 안 봄 | 본 화면 |
| KOIPA 사업 담당 (검수) | 시연용으로 봄 | 검수 대시보드 |
| KL 개발자 | 통합 인터페이스 확인용 | 본인이 개발 |
| 로이드케이 내부 | 라이브 회귀·QA | 인터페이스 합의용 |

## 7. 알려진 제약

- lite-noapi 에서는 LLM=noop, vector=inmemory 이므로:
  - `/answer` 응답은 `deterministic_fallback=true`
  - `/metrics/latest` 는 404 (no active model)
  - `/train` 라우터 미등록 (full-train 에서만 활성)
- 첫 분류는 모델 워밍업으로 콜드스타트가 발생할 수 있음 (5070 Ti 기준 ~32s) — 페이지가 `/healthz` 의 `warmup_done` 을 폴링해 자동 활성화
- Geist 폰트는 폐쇄망에서 다운 불가 — `Pretendard · Apple SD Gothic Neo · Noto Sans KR` fallback 으로 동일 톤 유지
