7. 용어 사전

본 문서에 사용된 약어·기술 용어 1줄 설명.

기능 ID

FUN-003
문서 분류 — 입력 문서를 4등급(특급기밀·1급비밀·2급대외비·3급공개) 중 하나로 자동 분류
FUN-004
관리자 확정·재라벨 — AI 분류 결과를 관리자가 검토·확정·정정
FUN-005
등급체계 변경 — 등급 정의 변경 시 재학습 트리거
FUN-022
가이드 문서 RAG — 등급분류 가이드 문서를 검색엔진에 인덱싱하여 분류 시 참조
FUN-023
합성 데이터 생성 — LLM 기반 학습용 합성 영업비밀 문서 생성
FUN-024
평가·능동학습 — 등급별 미탐률·혼동행렬 산출, 정정 누적 → 재학습 큐

기술 용어

RAG
Retrieval-Augmented Generation — 검색 결과를 컨텍스트로 활용하는 AI 기법
OpenAPI
API 명세 표준 (Swagger). KL ↔ Lloydk 인터페이스 정의에 사용
Repository (DB)
데이터 접근 계층 — DB 테이블별 CRUD 로직을 캡슐화
Job 큐
학습·합성 등 장기 작업의 비동기 큐. 진행률·결과를 폴링으로 조회
감사로그 미들웨어
모든 API 요청을 자동 기록하는 컴포넌트 — 누가·언제·무엇을·결과를
FNR (False Negative Rate)
등급별 미탐률 — "고등급을 저등급으로 분류"한 비율 (가장 위험한 오류)
Confusion Matrix
실제 등급 × 예측 등급의 교차표. 어느 등급 간 혼동이 잦은지 시각화
Nori
Elasticsearch의 한국어 형태소 분석기. 도메인 용어를 사용자 사전으로 보강
분류모델
KF-DeBERTa 등 한국어 사전학습 인코더 기반 등급 분류 모델
임베딩 모델
문장→벡터 변환 모델 (KURE-v1 등). RAG 검색에 사용
합성 LLM
합성 문서 생성용 대규모 언어모델. 외부 API 또는 자체호스팅 옵션
SBOM
Software Bill of Materials — 사용 오픈소스 목록·라이선스 명세 (CycloneDX 표준)
RTO
Recovery Time Objective — 장애 발생 시 복구 목표 시간 (본 사업 4시간)
DR 리허설
Disaster Recovery — 장애 복구 시나리오 모의 훈련
폐쇄망 번들
인터넷 차단 환경에 반입할 의존성·모델·이미지 일괄 패키지
