06정리 후보

실행에 안 쓰이면서 용량을 차지하는 것

지우자는 제안이 아니라, 물었을 때 답이 있어야 할 항목이다. 이번 측정에서 삭제한 것은 없다.

항목내용회수 가능
도커 이미지 rollback 태그이미지 29개 중 실제로 쓰이는 것은 8개. koipa-jjw-{api,worker,beat} 의 rollback-* 태그가 3세대씩 남아 있다(각 3.53 GB). 빌드 캐시는 별도로 6.70 GB11.1 GB
artifacts_out/…/checkpoint-*학습 체크포인트 2개. 옵티마이저 상태까지 들어 있어 배포 모델(713 MB)보다 크다. 재개할 학습이 없으면 남길 이유가 없다4.2 GB
~/poc/poc배포 래퍼가 만든 한 겹 안쪽 중복 트리. datasets·src·tests·scripts 를 통째로 다시 갖고 있고, 컨테이너는 이 경로를 마운트하지 않는다416 MB
~/poc/doc/releases감리 릴리스본 691개. 실행에 안 쓰인다. 다만 지운 적이 있는데 배포 래퍼의 git checkout -- . 이 되살렸다 — 지우려면 래퍼 쪽을 함께 손봐야 한다191 MB

주의 — 배포 버전을 git 으로 판단하면 안 된다

~/poc 의 git HEAD 는 1eda3d5(8/17)인데, src/koipa/config.py 의 수정 시각은 8/24 23:12 이다. 재배포가 git 을 거치지 않고 소스 tar 를 직접 풀어 덮어쓰기 때문이다. 서버에서 git log 로 배포 버전을 읽으면 7일 전 상태를 보게 된다.
