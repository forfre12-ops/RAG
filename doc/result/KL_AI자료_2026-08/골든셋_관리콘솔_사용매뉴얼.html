골든셋 관리 콘솔 사용 매뉴얼

SPECLEDGER GOLDSET OPS · /api/v1/golden/candidates/manage.html · 2026-08-09
한눈에 보기 — 이 콘솔이 하는 일
  • 검수 대상 문서(합성 후보 + 업로드 실문서)를 한 목록에서 봅니다.
  • 문서를 열어 전문을 읽고 등급을 확정하거나 보류·폐기합니다.
  • 모든 결정은 사유·검수자·시각과 함께 지워지지 않는 이력으로 남습니다.
  • 품질 지표로 이 골든셋이 믿을 만한지 스스로 점검합니다.
먼저 알아둘 것 — 여기서 확정한 등급은 Proxy Gold 입니다.
이 콘솔의 승인·확정은 Locked Gold(잠금 평가셋) 승격이 아닙니다. 실운영 정확도의 근거로 쓸 수 없으며, 잠금 평가셋 편입은 사람 서명 절차를 별도로 거칩니다. 화면 곳곳에 같은 문구가 표시됩니다.

1. 접속

콘솔은 포털 접속 토큰으로만 열립니다. 공유 API 키로는 열 수 없습니다 — 누가 등급을 정했는지 이력에 남겨야 하기 때문입니다.

1
/api/v1/golden/candidates/login.html 을 엽니다.
2
발급받은 토큰을 붙여넣고 로그인을 누릅니다. 토큰은 이 브라우저 쿠키에만 저장되고 주소창에 남지 않습니다.
3
자동으로 manage.html 로 이동합니다. 토큰의 계정 이름이 그대로 검수 이력에 기록됩니다.
토큰 없이 manage.html 을 직접 열면 화면 대신 401 한 줄만 보입니다. 화면이 안 뜨면 먼저 로그인 페이지를 거쳤는지 확인하십시오.

2. 화면 구성

왼쪽 사이드바에 5개 구역이 있고, 본문이 위에서 아래로 같은 순서로 이어집니다.

구역하는 일
01 개요전체 진행률(확정/전체)과 문서 업로드·새로고침 버튼
02 골든셋 후보검수 대상 목록. 상태·등급·출처로 거르고 문서를 선택
03 등급 확정선택한 문서의 전문과 결정 패널
04 보류·폐기 이력문서를 열지 않고 전체 결정 기록을 최신순으로 확인
05 품질 지표이 골든셋 자체가 건강한지 점검

5. 보류 · 폐기 이력

문서를 하나씩 열지 않고 전체 결정 기록을 최신순으로 봅니다. 이 기록은 덧붙이기만 하며 지워지지 않습니다(append-only).

열의미

GRADE제안 → 확정. 확정하지 않은 결정은 오른쪽이 –

상단 드롭다운으로 보류만, 폐기만 골라 볼 수 있습니다. 폐기 사유를 모아 보면 후보 생성 단계에서 무엇이 반복해서 잘못되는지 드러납니다.

6. 품질 지표 — 이 골든셋을 믿어도 되는가

등급을 맞히는 데 본문 말고 다른 단서가 섞였는지 봅니다. 여기가 나쁘면 이 골든셋으로 잰 정확도는 부풀려집니다.

지표뜻판정
길이만으로 등급 맞히기
length_only_1nn		 문서 길이만 보고 등급을 맞히는 비율. 높으면 길이가 정답을 흘리고 있다는 뜻입니다 — 모델이 내용 대신 길이를 외웁니다. 무작위 = 0.25
0.40 초과 시 경고
본문에 등급 노출
grade_token_exposed		 본문에 자기 등급 문구(“1급 비밀”·“대외비” 등)가 그대로 남아 있는 건수. 문서에 답이 적혀 있으면 검수가 검증이 아니라 확인 절차가 됩니다. 0건이어야 합니다
1건이라도 있으면 경고
실문서 비율
real_ratio		 합성이 아닌 실제 문서의 비율. 잠금 평가셋 자격이 있는 문서가 얼마나 되는지입니다. 높을수록 좋음
등급 균형
grade_balance_ratio		 최다 등급 ÷ 최소 등급. 한 등급만 많으면 그 등급만 맞혀도 점수가 높게 나옵니다. 1에 가까울수록 균형
본문 길이
length p50		 중앙값과 최소~최대 범위. 아래 등급별 표에서 등급마다 길이 분포가 겹칠수록 좋습니다. 특정 등급만 길거나
짧으면 위험
등급별 길이 표를 읽는 법. TS·S1·S2·S3 의 MIN ~ P50 ~ MAX 구간이 서로 겹치면 건강합니다. 특정 등급만 유독 짧거나 길면 모델이 내용 대신 길이를 학습하게 되고, 그 골든셋으로 잰 정확도는 실제 운영에서 재현되지 않습니다.

7. 문서 업로드

업로드한 문서는 검토 대기 상태로만 저장됩니다. 자동으로 골든셋에 올라가지 않고, 외부 LLM 으로 전송하지도 않습니다.

입력설명
원문 파일TXT · PDF · Word · HWP/HWPX · Excel · PPTX · 이미지(OCR)
문서 출처조직 보유 실문서(S2/S3) 또는 공개 실문서(S3 우선)
원천 위치예: 품질관리/운영절차/2026 또는 공개기관 URL
사용 권한예: 소유부서 검수용 사용 승인 / 공개 라이선스
출처와 권한을 남기지 않으면 나중에 평가셋으로 쓸 수 없습니다. 고객사 원문이나 반출 승인이 없는 문서는 등록하지 마십시오. 등록 자체가 반출에 해당할 수 있습니다.

8. 자주 막히는 곳

증상원인과 조치
화면이 안 뜨고 401 만 보임토큰 없이 직접 열었습니다. login.html 에서 토큰을 넣고 들어오십시오.
“등급 지정·보류·폐기에는 사유가 필요합니다”사유 칸이 비었습니다. 한 문장이라도 적어야 저장됩니다.
결정 저장이 403토큰 권한이 부족합니다. 관리자 권한 토큰을 재발급받으십시오.
“지표를 낼 수 없습니다”등급이 붙은 문서가 아직 없습니다. 후보를 먼저 확정하십시오.
목록에 문서가 없음필터가 걸려 있습니다. 상태·등급·출처를 전체 로 되돌리고 필터 를 다시 누르십시오.
