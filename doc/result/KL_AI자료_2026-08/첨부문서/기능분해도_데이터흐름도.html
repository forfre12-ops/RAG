2026-08-03 개정 — 본문 최초 작성 2026-07-17. 2026-08-03 개정 내용: ① DFD Level 1에 모델 구축 경로(P8~P11)를 신설해 담당 6요건 전체를 도식화(종전 Level 1은 FUN-003·023 미표현) ② 회원사·KL 포털로 돌아가는 반환 흐름(F17~F19)을 추가해 Level 0↔1 균형 성립 ③ metadata_floor_enabled 상태 서술을 실배포 프로파일 기준으로 정정 ④ P6 흐름 연결·흐름ID 레벨 간 주석·소스 규모 재실측. 기준 데이터: 배포본 v5_clean(v-fe4b386b) · 골든 정본 gold_real 777건.

담당 6개 기능요건(FUN-003·004·005·022·023·024)을 기능계층으로 분해(FBD)하고, 시스템 경계의 데이터 흐름을 컨텍스트 다이어그램(DFD Level 0)과 주요 처리 흐름(DFD Level 1)으로 도식화한다. Level 1은 운영 처리 경로(P1~P7)와 모델 구축 경로(P8~P11) 두 갈래로 나누어 표기한다. 소스 182파일 / 39,191줄(poc/src/**/*.py 물리 줄 수 · 2026-08-03 실측), 6-모듈 파이프라인(M1~M6) 기준.

범위 · 기준

담당 6요건 범위이며, KL 담당 16요건은 도식 경계 밖이다. RAG 질의응답(/answer)은 요건 외 부가 기능이라 도식에서 제외하되, 인덱싱·검색(P6)은 분류 근거를 보강하는 경로로 실제 배선돼 있어 OPT 표기로 포함한다.

※ 소스 규모는 물리 줄 수 기준이다(빈 줄 제외 33,904 · 빈 줄+주석 제외 30,882). 파일 규모를 보이는 것이 목적이라 물리 줄 수를 쓴다.

03데이터흐름도 Level 1

P0를 11개 하위 프로세스(P1~P11)로 분해하고, 성격이 다른 두 갈래로 나누어 도식화한다 — (A) 운영 처리 경로(P1~P7 · 회원사 문서가 들어와 등급이 나가는 런타임)와 (B) 모델 구축 경로(P8~P11 · 지재원에서 합성·라벨링·골든셋·학습·승격으로 모델을 만드는 오프라인). 담당 6요건은 두 경로에 나뉘어 대응한다 — A에 FUN-022·FUN-005·FUN-024, B에 FUN-003·FUN-023, FUN-004(학습·승격)는 양쪽에 걸친다. 감리 관점 주 처리 경로는 F1→P1→F3→P2→F5→P3→F17(문서업로드 → M2추출 → M5분류 → 검수 라우팅 → 회원사 반환)이고, 검수 대상은 F6→F7→P4→F18, 교정은 F10→F12→P5로 환류한다. 각 단계마다 안전장치가 배치된다.

※ 흐름 ID도 저장소 ID와 마찬가지로 레벨 간 동일 번호가 다른 대상을 가리킨다 — 예를 들어 Level 0 F2(등급·근거 → 회원사)는 Level 1에서 F17·F18로, Level 0 F3(ICD 메타)는 Level 1 F4로 대응된다. 레벨 간 대응은 아래 레벨 균형(balancing) 대조표에 Level 0 흐름 6종 전량을 명시한다.

Level 1 데이터 저장소

※ Level 1 저장소 ID는 Level 0을 세분한 것으로 레벨 간 동일 번호가 다른 대상을 가리킨다 — Level 0 DS1(PostgreSQL)이 Level 1 DS1~DS6(문서·분류·교정·감사·합성문서·가이드 PG 테이블)로 분해되고, Level 0 DS2(벡터)·DS3(로컬FS)는 DS-VEC·DS-FS로 표기된다. DS-GOLD(골든셋 파일)·DS-OBX(아웃박스)는 Level 1에서 새로 드러나는 저장소다.

검수 두 루프 구분

골든 검수(P10)와 운영 검수(P3·P4)는 다른 루프다. P10은 학습·평가의 정답을 만드는 지재원 내부 루프로 산출물이 서명된 골든셋(DS-GOLD 3분할)이고, P3·P4는 회원사 업로드 문서의 등급을 확정하는 운영 루프로 산출물이 확정 등급(DS2)과 교정(DS3)이다. 저장소·서명 주체·환류 경로가 모두 분리되어 있으며, 운영 교정이 골든셋 정본을 직접 바꾸지 않는다 — 재학습(P5) 입력으로만 합류한다(F12·F26).

주 경로 안전장치

① P3에서 저신뢰·희소근거·cap-conflict·access-conflict 신호는 신뢰도와 무관하게 needs_review로 격리(자동확정 차단). ② P1 저품질·OCR 추출 문서는 processing_status로 격리되어 자동분류 우회 불가. ③ P5 재학습은 admission 게이트(검수+확정) 통과 교정만 반영하며, 자동 활성은 잠금(retrain_auto_activate=False — 후보 등록까지만). ④ P2·P3·P4·P5 전 상태전이는 F11로 감사 hash체인에 기록. ⑤ P11 승격 판정은 자동 게이트로 한다 — evaluate_deploy_gate 지표 기준 미달이면 활성 차단이고, 자동 활성 경로는 추가로 locked_gold_eval readiness(등급별 min_locked_per_grade) 충족을 요구한다. 활성 후 지표 이상은 F29로 자동 롤백한다. kill-gate는 품질붕괴 신호(TS/S1 미탐·검수 과부하·overturn율)를 경보하는 비파괴 관제 지표로 승격을 차단하지 않는다. ⑥ F18 콜백은 아웃박스 경유 재시도·DLQ로 전달을 보장하며, 대상 URL은 SSRF 가드를 통과한 것만 큐잉된다.
