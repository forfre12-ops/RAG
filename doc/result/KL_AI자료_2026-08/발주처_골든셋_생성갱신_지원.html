발주처가 운영 단계에서 자체 생성·갱신 가능한지에 대한 설계상 답변 · 2026-07-29
지원됩니다. ① 생성 = 합성 골든 빌더로 모의문서·골든셋을 만들고 검수해 등급을 확정. ② 갱신 = 운영 중 검수 교정이 현장 CPU 야간 증분재학습으로 반영. ③ 모든 모델 활성화는 사람 사인오프이며 문서는 망 밖으로 나가지 않습니다(무반출).

1. 생성 — 모의문서·골든셋

통합 골든 빌더(/golden/build)가 모의문서와 골든셋(정답지)을 생성합니다. 교차 합성 + 합의 게이트 + 외부 앵커 방식으로 초안을 만들고, 관리자가 검수해 등급을 확정합니다. 등급 계층은 silver_train(학습) · gold_candidate(후보) · locked_gold_eval(사람서명 평가)로 분리됩니다.

2. 갱신 — 운영 학습 루프

  1. 운영 중 관리자가 분류 결과를 검수·교정(tb_corrections 기록)
  2. 교정이 고객사 망 내 CPU 야간 증분재학습(02:00, enable_incremental_retrain)으로 기존 학습셋과 혼합 반영 — GPU 불필요, 무반출
  3. 재학습 결과는 후보로만 등록(자동 활성화 아님, auto_activate=False)
  4. shadow 검증 후 사람 사인오프 시에만 활성화

3. 주체 · 책임 경계

주체역할
발주처 / 고객사 관리자모의문서·골든셋 검수, 등급 확정, 운영 교정, 활성화 승인(사인오프)
지재원(로이드케이)초기 합성 공장(학습셋·골든·인덱싱), 빌더·모델 재번들 제공, 증분재학습 파이프라인 배선
정확도와의 연결. 합성 부트스트랩의 구조적 천장(요청 3)을 넘는 유일한 실개선 경로가 이 운영 학습 루프입니다. 발주처가 실문서를 검수·확정할수록 분류기가 현장 분포에 맞춰 개선되며, 안전장치(활성화 사인오프·무반출·후보등록)는 그대로 유지됩니다.
