결론 — 다중배포 라이선스 리스크 없음. 배포 스택은 permissive 중심(PostgreSQL/BSD/MIT/Apache)이며, DB 드라이버(psycopg) 1건만 LGPL-3.0(약한 copyleft)이나 파이썬 동적 링크라 재배포는 자유·라이선스 고지만 하면 됩니다. 강한 copyleft(AGPL·GPL·SSPL) 구성요소는 배포 이미지에 설치되지 않습니다(§2).

2. 배포 범위 고정 — 카피레프트 반출 경로 없음

배포 이미지가 설치하는 extras는 [psh, otel, jwt, hwp, hwp-tables, xls]로 고정돼 있습니다(Dockerfile.api.prod). 이 범위 밖의 선택 구성 — PyMuPDF(AGPL-3.0) · MinIO 서버(AGPL-3.0) · poppler-utils(GPL-2/3, OCR용) — 과 레거시 Elasticsearch(SSPL) 어댑터는 소스에 옵션으로만 존재하고 배포본에 설치되지 않아 AGPL·GPL·SSPL 반출 경로가 없습니다. 배포되는 유일한 copyleft는 psycopg(LGPL-3.0)이며 동적 링크·고지로 다중배포에 지장 없습니다. 권위 목록은 SBOM(CycloneDX)으로 최종 확정합니다.

3. 상용 LLM · 외부 API

  • 등급 결정 핫패스는 LLM-free — 분류기 + 룰 엔진만 사용하므로 운영 서버에 LLM이 없어도 등급 분류가 동작한다.
  • 로컬 LLM(Qwen3-14B, Apache-2.0)은 합성문서 생성·서술형 질의응답 등 부가 기능 전용이며 본 번들에 가중치를 동봉하지 않는다. GPU 보유 고객사가 vLLM/Ollama로 기동한 망 내 엔드포인트를 설정으로 연결하는 방식이라 외부 전송이 없다.
  • 원격 상용 API(anthropic·openai)는 클라우드 티어 옵션이며 폐쇄망 기본 구성에 미포함. 상용 LLM 활용은 공개출처 문서에 한정.

4. 산출물 · 실측 검증

  • 의존성 라이선스 표: scripts/dump_licenses.py (pip-licenses)
  • SBOM(CycloneDX): cyclonedx-bom — 권위 확정본은 배포 이미지(Dockerfile.api.prod) 내에서 생성·첨부(운영 전환 시)
  • 실측 스팟체크(2026-08, Trove classifier 기준): psycopg=LGPL-3.0 · torch=BSD-3 · transformers/mlflow(지재원 학습서버 전용·고객사 미포함)/bcrypt=Apache-2.0 · SQLAlchemy/openpyxl/python-docx/python-pptx/redis=MIT · xlrd=BSD · PyMuPDF(AGPL)은 배포 미포함 확인. 그 외 MPL-2.0 소수(certifi·tqdm·pathspec 등)는 파일단위 약카피레프트·미수정 사용이라 재배포 자유(배포 포함 무방).
