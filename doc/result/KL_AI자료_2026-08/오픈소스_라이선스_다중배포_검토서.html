결론 — 다중배포 라이선스 리스크 없음(기본 구성). 폐쇄망 기본 스택은 permissive 중심(PostgreSQL/BSD/MIT/Apache)이며, DB 드라이버(psycopg) 1건만 LGPL-3.0(약한 copyleft)이나 파이썬 동적 링크라 재배포는 자유·라이선스 고지만 하면 됩니다. 강한 copyleft(AGPL·GPL) 구성요소는 배포본에서 전부 제외이며, 필요한 경우에만 옵트인 + 프로세스 격리로 경계를 국한합니다.

2. 강한 카피레프트(AGPL·GPL) 처리 — 배포본 제외·격리

구성요소라이선스처리 방식
PyMuPDF (PDF)AGPL-3.0기본 제외. 옵션 [pdf-agpl]로만 옵트인. 기본 PDF 추출은 pdfminer.six(BSD-3)
pyhwp (HWP 표 셀) — 제거됨AGPLv3+의존성 자체를 삭제(2026-08-01). HWP 표 셀 회수를 AGPL 없이 얻기 위해 대체 후보를 실측 비교한 결과 unhwp(MIT)로 교체했고, 소스·uv.lock 양쪽에서 pyhwp가 0건임을 확인했다. 이로써 [hwp-tables]는 AGPL 옵트인이 아니라 기본 배포에 포함되는 MIT 구성요소가 되었다. 검증: unhwp 네이티브(Rust)에 카피레프트 문자열 0건, 동봉 크레이트 29종 전수가 MIT/Apache-2.0/Unlicense/Zlib, 기존 AGPL 구현(pyhwp·hwp.js·hwplib) 파생 흔적 0건
MinIO (객체 스토리지)AGPL-3.0폐쇄망 미사용(로컬 파일시스템). 옵션 [minio]는 클라우드(CSAP) 티어 전용 → AGPL 이슈 해소. (파이썬 클라이언트는 Apache-2.0, AGPL은 서버 바이너리)
poppler-utils (OCR용 PDF→이미지)GPL-2/3배포 이미지에서 제외(2026-08). OCR은 요건 외(FUN-022=전자문서 텍스트추출뿐)라 배포본에 [ocr]·poppler-utils 미포함 → GPL 반출 소거. OCR 코드·옵션은 리포에 존치(옵트인). 참고: Tesseract는 Apache-2.0
다중배포 시 유의점. 강한 copyleft(AGPL 3종 pdf-agpl·hwp-tables·minio + GPL [ocr]/poppler)은 폐쇄망 배포 프로파일에 포함하지 않습니다. HWP 표 셀 정밀 추출이 필요한 고객사에 한해 [hwp-tables]를 프로세스 격리로 옵트인하되, 해당 환경의 AGPL 수용 여부를 배포 전 확인합니다. psycopg(LGPL)는 배포 대상이나 동적 링크·라이선스 고지로 다중배포에 지장 없습니다. 권위 목록은 SBOM(CycloneDX)로 최종 확정합니다.

3. 상용 LLM · 외부 API

  • 폐쇄망 운영은 로컬 LLM(Qwen3-14B, Apache-2.0) 오프라인 동봉 — 외부 전송 없음. 등급 결정 핫패스는 LLM-free.
  • 원격 상용 API(anthropic·openai)는 클라우드 티어 옵션이며 폐쇄망 기본 구성에 미포함. 상용 LLM 활용은 공개출처 문서에 한정.

  • 의존성 라이선스 표: scripts/dump_licenses.py (pip-licenses)

  • 실측 스팟체크(2026-08, Trove classifier 기준): psycopg=LGPL-3.0 · torch=BSD-3 · transformers/mlflow/bcrypt=Apache-2.0 · SQLAlchemy/openpyxl/python-docx/python-pptx/redis=MIT · xlrd=BSD · PyMuPDF(AGPL)은 배포 미포함 확인. 그 외 MPL-2.0 소수(certifi·tqdm·pathspec 등)는 파일단위 약카피레프트·미수정 사용이라 재배포 자유(배포 포함 무방).
