## 왜 뺐나

8/5 납기 요청은 AI 자료 **6건**이다. 첨부문서/ 에는 그 6건에 해당하는 문서 외에,
본문이 인용한다는 이유로 딸려 들어온 참조 문서 16종이 함께 있었다. 참조 문서는
발주처가 **검토를 요청한 적이 없는** 자료이고, 제출하는 순간 감리 대상 표면이 그만큼
넓어진다. 그래서 요청 6건에 해당하는 문서만 남겼다.

- **남긴 것 11종** — 요청 1 설계 산출물 7종 · 요청 3 골든셋 2종 + 등급분류 기준 적용서 v2.2 · 요청 4 RTM
  - 등급분류 기준 v2.2 는 요청 3 이 명시한 "등급 판정근거"의 **기준 원문**이라 남겼다.
    판정근거 카드 777건만 주고 판정 규칙을 빼면 근거가 반쪽이 된다.
- **뺀 것 15종** — 이 폴더

이 문서들은 폐기가 아니다. 정본은 `doc/result/감리정본/` 에 그대로 있고, 8/31 설계감리 ·
11/23 종료감리의 산출물 트랙에서 정식 제출된다. 여기 사본은 **되돌리기 편의용**이다.

## 되돌리는 법 (나중에 필요할 때)

1. 파일을 `../KL_AI자료_2026-08/첨부문서/` 로 옮긴다.
2. 아래 표대로 **해제해 둔 링크를 되살린다.** 파일만 옮기면 본문은 여전히
   "본 묶음 미포함"이라고 말한다 — 검증기는 이 불일치를 못 잡는다(링크가 없으니
   깨진 링크도 없다). 대신 `고아(정리 후보)` 로 보고되므로 그 신호를 단서로 쓴다.
3. `python scripts/sync_kl_bundle.py` 로 누락·깨진 링크·범위 이탈 0 을 확인한다.
4. `index.html` 의 첨부 종수·용량·설명을 함께 고친다.
