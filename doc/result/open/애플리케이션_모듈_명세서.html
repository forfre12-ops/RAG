애플리케이션 모듈 명세서

개발된 소스코드를 계층·패키지·모듈 단위로 정의한 프로그램 목록 산출물. 각 모듈의 식별자·책임(역할)·주요 파일·연관 요건ID를 표로 정리한다. 상세 요건↔구현 추적은 요구사항_추적표_RTM, 인터페이스 계약은 기술구현_백서_부록B_API명세, 데이터 구조는 기술구현_백서_부록A_DB스키마를 참조한다.

범위 · 기준

대상: poc/src/lloydk 애플리케이션 소스(182 파일 · 38,699 LOC, 테스트·벤더 제외). 담당 범위는 로이드케이 소유 6개 기능요건(FUN-003·004·005·022·023·024)이며, KL(원청) 소유 포털·연동은 범위 외. 표기: 코어 요건 직접 구현 · 지원 공통·운영 인프라 · 부가 요건 외 옵션.

01아키텍처 계층

계층 구조 개요

계층형(layered) 구조. 외부 요청은 인터페이스(api) → 업무로직(services) → 데이터접근(repositories) → DB 순으로 흐르고, 등급분류 도메인 처리는 M1–M6 파이프라인이 담당한다. 외부 의존(임베딩·LLM·저장소·벡터스토어)은 어댑터(adapters)가 Protocol로 추상화해 교체 가능하다.

계층 / 패키지책임구분
apiHTTP 인터페이스(FastAPI 라우터)·인증(RBAC)·미들웨어·관측성 노출인터페이스
services업무 로직(분류 서빙·검수·골든빌드·감사·재학습·웹훅 등) 오케스트레이션업무로직
