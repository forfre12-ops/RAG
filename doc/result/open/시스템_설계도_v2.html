2026-06-29 운영 전제 업데이트: 실데이터 0 · 빌드 검수 0 · 반출 0 제약에서는 배포 전 정확도 검증을 주장하지 않는다. 합성/LLM 라벨은 학습 시드·상대비교·회귀 테스트용이며, locked_gold_eval은 사람 서명 전용이다. 현재 목표는 "검증된 분류기 배포"가 아니라 룰 우선 안전 부트스트랩 + 보수적 검수 라우팅 + 운영 관리자 확정에서 배우는 루프다. 이 문서의 기존 F1/FNR/PASS 수치는 합성·OOD·프록시 또는 메커니즘 검증으로만 해석한다.

⚠ 비밀 경계 — 절대 규칙

실 비밀 본문은 지재원·고객사 안에서만 처리한다. 상용 LLM·외부 GPU·클라우드로 비밀이 나가는 경로는 없다. 밖으로 나가는 건 공개 데이터와, (환류 시) 문서식별 불가한 집계 진단지표뿐.

왜 무GPU로도 되나

분류기의 GPU 수요는 전부 공개데이터·지재원 밖에서 끝난다(또는 CPU). 지재원·고객사 안에서는 가중치를 CPU로 추론만 한다. 막히는 건 "실 비밀로 GPU 재학습"뿐이고, 그건 지재원 안 CPU 학습으로 대체하거나(허용 시) 보류한다. ⇒ GPU 0과 분류기 사용은 양립한다.

한계 — 정직 고지

실 비밀로 즉시 재학습을 못 하므로 raw 모델 자체의 S1 실력은 약하다(raw S1 recall ≈ 0.42 측정). 단 서빙 안전장치(룰·FNR-safe override·escalation)가 이를 상당부분 회복(서빙 S1 recall 0.92, escalation 시 고등급 미탐 0 — ★실측 베이스라인 참조). 그래도 잔여분·OOD 위험이 있어 고등급은 사람검수 필수가 불가피한 트레이드오프다.

성능 지표 (FUN-024) — 후보 6개

분류 AI가 측정·표출해야 할 핵심 지표. 골든셋(§05 eval)을 정답지로 산출한다. 정확히 어느 6개로 확정할지는 미결정(§08).
#지표의미 · 쓰임
1F1_macro분류 정확도 종합(4등급 평균). 단순 정답률 대신 사용
2방향성 미탐률(FNR)비밀을 더 낮은 등급으로 흘린 비율 — 최우선 관리
3fnr_high고등급(TS·S1) 평균 미탐 — 배포 게이트·롤백 기준값
4등급별 Precision/Recall과분류·미탐을 등급별로 분해
5Recall@5 / MRR검색(RAG) 품질 — 근거 선례가 상위에 오는지
6추출 품질 · 라벨 일치도문서 추출 누락률·정확도 + 학습데이터 라벨 품질
참고 — 측정 영역

백서 부록C 기준 측정 영역은 P1 분류 · P2 검색 · P3 합성LLM · P4 추출 · P5 E2E(5영역). 위 6개는 이 영역들의 핵심 수치를 추린 것. "6개"가 담당 기능 6개(FUN-003·004·005·022·023·024)를 가리킨 것일 수도 있어 §08에서 확정한다.

08

남은 의사결정 사항

설계를 확정·진행하기 전에 발주처·KL과 합의가 필요한 항목.
#결정 사항내용 · 영향
D1"지표 6개"가 무엇인지(A) 담당 기능 6개(FUN-003·004·005·022·023·024)인가, (B) 평가 지표 6개(§07)인가. 둘 다 가능 — 의도 확정 필요
D2골든셋 1,000건 실데이터 출처·고등급 비중지재원 제공 실데이터 — TS/S1 실건수가 평가 신뢰도와 S1 약점 해소 가능성을 좌우
D3검토자 자격사람검수 주체(지재원 관리자 RBAC). 신뢰도 임계·2인검토 정족수 — 발주처 협의
D4지재원 CPU 재학습 허용 여부지재원 안에서 CPU 배치 학습을 돌릴 수 있나. 불가면 모델은 공개학습본 고정, 실데이터는 게이트·검수로만
D5상용 LLM "공개 데이터" 정의 범위(가) 공개·개발용으로 확정됨. 어디까지 "공개"인지(판례·공보·합성) 경계 명문화 — fail-closed로 코드 강제
D6운영 환류 방식무반출(기본)·온사이트·반출 3안. 기본=집계 진단지표만 반출(문서 미반출)
진행 1순위 (무GPU·CPU로 당장 가능)

① 1,000건 사람서명 locked 평가셋 구축 → ② 기존 분류기를 그 골든으로 확정 실측 → ③ Optuna로 게이트·온도 튜닝(고등급 FNR=0 제약 하 자동확정율 최대). 셋 다 GPU·재학습 없이 진행된다. ※ ②는 누출제거 holdout(77건)으로 잠정 실측 완료(★ 실측 베이스라인) — Optuna 정밀 튜닝은 N이 충분한 1,000 골든서 수행(작은 N 튜닝은 과적합).
