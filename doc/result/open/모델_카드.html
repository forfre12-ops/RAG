모델 카드 (Model Card)

2026-06-29 운영 전제 업데이트: 실데이터 0 · 빌드 검수 0 · 반출 0 제약에서는 배포 전 정확도 검증을 주장하지 않는다. 합성/LLM 라벨은 학습 시드·상대비교·회귀 테스트용이며, locked_gold_eval은 사람 서명 전용이다. 현재 목표는 "검증된 분류기 배포"가 아니라 룰 우선 안전 부트스트랩 + 보수적 검수 라우팅 + 운영 관리자 확정에서 배우는 루프다. 이 문서의 기존 F1/FNR/PASS 수치는 합성·OOD·프록시 또는 메커니즘 검증으로만 해석한다.

KOIPA 영업비밀 등급 분류 모델의 명세를 한 장으로 모았다 — 모델·학습 데이터·프록시 평가 결과·입출력·세이프티·한계. 이 카드는 모델을 "검증된 분류기"로 주장하지 않고, 관리자 확정을 보조하는 안전 부트스트랩으로 위치시킨다. 고객사는 기본적으로 추론 전용이며, 운영 개선은 exact-match 선례·상향 라우팅·검수 루프부터 시작한다.

한눈 요약

KF-DeBERTa 기반 한국어 영업비밀 4등급(TS·S1·S2·S3) 분류기. 현재 수치는 합성·공개·프록시 holdout에서의 메커니즘/상대비교 결과이며 운영 정확도 보증이 아니다. 서빙 경로는 캘리브레이션, FNR-safe 오버라이드, 최고위험 청크 집계를 적용해 미탐을 보수적으로 줄이는 방향으로 동작한다.

02의도된 용도 · 금지 용도

의도된 용도

  • 한국어 영업비밀 문서의 1차 자동 등급 분류(B안) — 사람 검수 전 후보 등급·근거 제시.
  • 검수자 UI에 "왜 이 등급?"(S/V/M·근거 키워드) 시각화 입력 제공.

금지 · 비의도 용도

  • 사람 검수 없는 최종 등급 자동 확정 — 등급의 최종 결정권자는 항상 사람.
  • A안(5요소 100점, 경영·재무 판단) 대체 불가 — 매출 기여·유출 손실 등은 사람 수기.
  • 한국어·영업비밀 외 도메인 일반 문서 분류.

평가-서빙 갭 (정직 공시)

원시 argmax로 측정하면 미탐을 9배 과소평가(원시 FNR 0.167)한다. 본 수치는 실배포 경로(캘리브레이션 + FNR-safe 오버라이드 + 최고위험 청크 집계)를 통과해 측정한 서빙 기준이다(직전 배포본 v4 기준 메커니즘 예시 FNR 0.167→0.018; v5는 hardened 42셋 고위험 위험미탐 0). 단, temperature 보정은 val 분포 내 과신만 완화하며 OOD(골든/실데이터)로는 전이되지 않는다(골든 ECE 0.18, 정답/오답 AUROC 0.58) — 보정만으로 confidence가 자동확정의 신뢰 근거가 되지는 않는다. 따라서 평가 경로를 배포 경로에 맞췄을 뿐, 평가가 배포 동작과 완전히 일치함을 보장하지는 못한다.

게이트 적용 시 잔존 미탐 개선

위 서빙 수치는 FNR-safe 오버라이드까지의 기본 경로 기준이다. 현재 소스 기준 희소근거 게이트(rule_fallback_min_evidence=0.9)는 룰-폴백 경로 기본 ON으로 단일 약한 키워드 자동확정을 차단한다. 합의 게이트(agreement_gate_enabled)는 base 기본 OFF이나 운영 프로파일에서 켤 수 있으며, 적용 시 룰/모델 불일치 미탐을 줄인다 — golden100 무성 TS 미탐 5→0건, 고등급(TS/S1) 미탐 46→8건. golden500 기준 자동확정 189 / 검수 311(TS·S1 미탐 8)이 된다.

05입력 · 출력
내용
입력문서 텍스트(512 토큰 청킹) + 메타데이터(출처·보안표시·접근범위 — KL 제공)
출력등급(TS/S1/S2/S3) + confidence + 근거(S/V/M 분해·키워드·위치) + RAG 유사 기준문서
상태staging(자동확정 후보) / needs_review(검수 필요) — confidence 임계(기본 0.7)·출처충돌 단독이 아니라 다단 게이트로 결정: 희소근거 게이트(rule_fallback_min_evidence=0.9, 룰-폴백 기본 ON) + 합의 게이트(agreement_gate_enabled, base 기본 OFF·운영 프로파일 별도). 자동확정은 예측이 공개등급(S3)이거나 룰등급==모델등급일 때만 허용. §06 참조.
06세이프티 메커니즘
  • FNR-safe override — 룰이 모델보다 높은 등급을 가리키면 상향(미탐 방지).
  • 출처 cap — 공개 출처(공개특허 등)는 S3로 하향 가드.
  • 검수 게이트 — 신뢰도 < 0.7 또는 출처-내용 충돌(cap-conflict) 시 needs_review. 단, confidence는 분류기가 학습한 신뢰도가 아니라 softmax 파생값이라 OOD에서 과신하며 정답/오답 판별력이 낮다(골든500 AUROC 0.58). 그래서 자동확정·검수 라우팅은 confidence 임계(기본 0.7) 단독이 아니라 아래 다단 게이트로 결정한다(합의 게이트는 기본 OFF·희소근거 게이트는 기본 ON).
  • 희소근거 게이트 (rule_fallback_min_evidence=0.9, 룰-폴백 기본 ON) — 단일 약한 키워드만으로 conf=1.0이 되는 룰-폴백 자동확정을 차단(golden100 무성 TS 미탐 5→0).
  • 합의 게이트 (agreement_gate_enabled, opt-in·기본 OFF) — 자동확정은 예측이 공개등급(S3)이거나 룰등급==모델등급일 때만 허용하고 그 외 불일치는 사람 검수로 보낸다(자동확정 정밀도 63→81%, 고등급 TS/S1 미탐 46→8). TS/S1 자동확정분은 표본감사한다.
  • fail-secure — 본문 없음/조회 불가 시 최고등급(TS) + 검수로 격리(절대 공개/S3로 기본값 안 함).
  • 사람 확정 라벨 우선 — A안 자가진단·검수 확정이 있으면 모델 추론을 건너뛰고 그 등급 사용.
