발주처 의사결정 안건서

2026-06-29 운영 전제 업데이트: 실데이터 0 · 빌드 검수 0 · 반출 0 제약에서는 배포 전 정확도 검증을 주장하지 않는다. 합성/LLM 라벨은 학습 시드·상대비교·회귀 테스트용이며, locked_gold_eval은 사람 서명 전용이다. 현재 목표는 "검증된 분류기 배포"가 아니라 룰 우선 안전 부트스트랩 + 보수적 검수 라우팅 + 운영 관리자 확정에서 배우는 루프다. 이 문서의 기존 F1/FNR/PASS 수치는 합성·OOD·프록시 또는 메커니즘 검증으로만 해석한다.

화요일 설계 미팅에서 지식재산보호원(지재원)이 확인·승인·합의해야 할 항목을 한 장으로 정리한 결정 요청서. 각 안건은 배경 → 수행사 권고 → 근거 → 결정란 순으로 구성된다. 수행사 설계 확정 사항(통보)은 §A·근거로만 적고, 발주처 판단이 필요한 것만 안건으로 올린다.

읽는 법 — 안건 유형 4가지

확인 발주처 자체 가이드를 정정하는 판정 · 승인 수행사 보정의 활성화 가부 · 합의 측정·표기 기준 값 · 협조 자료·자원 제공

01확인 안건

확인이 필요한 안건

A1공개·등록 특허·실용신안 = 3급 공개(S3)확인

배경

발주처 정본 가이드 직무별 예시표(p6~9)는 특허·실용신안을 2급 대외비로 표기한다. 그러나 등록·공개된 특허는 특허청이 공표한 정보다.

근거

등록·공개 특허는 비공지성=0 → S×V×M=0 → 공개. 부정경쟁방지법 §2.2("공공연히 알려져 있지 아니하고")상 공개특허는 영업비밀 불성립. (단 출원 전·미공개 IP 전략은 내용에 따라 S1/S2.)

수행사 권고: 등록·공개분에 한해 S3(3급 공개)로 분류. 이는 발주처 자체 가이드 예시를 정정하는 것이므로 발주처 확인을 요청한다.
