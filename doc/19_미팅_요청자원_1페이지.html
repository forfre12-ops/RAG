1. 의사결정 요청 자원 (우선순위 순)

REQUEST #1 · 최우선

LLM API 키 또는 비용 승인

차단 P2 합격선 결정타

차단 중인 작업: P3 합성 풀 모드(800·5,000건 노출 시), RAG 답안 합성 LLM 실호출, KF-DeBERTa 학습 보조 라벨링. 현재 noop provider로 동작 — 라벨 일치 100%이지만 LLM 의미해석 미반영.

P2 검색 품질 합격선 도달의 결정적 차단 — 본 미팅 직전 정량 입증. 의도형 쿼리 추가 측정 결과 시드 대비 -0.067~-0.133 하락으로 천장 원인이 알고리즘이 아닌 합성 코퍼스 boilerplate임이 확정. LLM API 키 도착 → P3 풀 합성 → 본문 다양화가 합격선 0.80 도달의 결정 경로.

받으면 즉시 가능: .env에 키 채우고 make poc-all 또는 --provider anthropic 재실행 → P3 풀 합성 → P2 재측정 → doc/02 §부록 A 갱신 (당일~3일).

예상 비용: P3 풀 합성 약 $50~100, 전체 PoC 약 $200 추산. 운영 단계는 발주처 부담(원 합의).

REQUEST #2

GPU 환경 또는 클라우드 GPU 예산

차단

차단 중인 작업: W6 KF-DeBERTa 풀 학습(--mode full --epochs 5), 폐쇄망 번들 25~30GB 실빌드, 운영 환경 추론 성능 측정. ML 측 회귀는 RTX 5070 Ti 로컬에서 단위 검증만 가능 — 풀 학습 미진행.

받으면 즉시 가능: 풀 학습 1회 약 6~10시간, 평가셋 분리·confusion matrix·미탐율 산출까지 24시간 내 결과.

대안: 클라우드 옵션(AWS g5/Azure NC-series)으로 시간당 약 $3~5, 풀 학습 1회 $30~50.

REQUEST #3

비밀해제 실문서 샘플 (50~100건)

차단

차단 중인 작업: FUN-022 실파일 누락률·품질 측정, P4 HWP/DOCX/PDF 실파일 검증, 합성 코퍼스 → 실문서 분포 검증. 현재 30 파일 dryrun PASS(누락 0%, 품질 0.986)이지만 실 문서 형태와 차이 노출 불가.

받으면 즉시 가능: 등급별 균등 50~100건이면 P4 정량 갱신 + FUN-022 명세 정합 검증.

대안: "미제공" 자체결정으로 잠겨 있음. 도착 시 잠금 해제 + W6 평가셋 50% 실문서 비중 적용.

REQUEST #4

등급분류 가이드 v2 (KOIPA 공식)

위험·우회중

차단 중인 작업: 시드 키워드·Nori 사전·라벨링 규칙 v4 정밀화. (P2 합격선은 #1로 결정 — 본 자원은 시드 갱신 효율 증가) 1차 실측 결과 시드 쿼리 0.700, 의도형 0.567~0.667 — 시드든 의도형이든 합성 본문 boilerplate가 천장 결정 요인.

받으면 즉시 가능: v2 키워드로 시드 v4·Nori 사전·라벨링 YAML 패치. P3 풀 합성과 결합 시 합격선 도달 가속.

현재 우회: 공개 법령 기반 자체 v1 (시드 v3 313 키워드, 18 도메인) — 가이드 v2 도착 시 diff만 패치.
