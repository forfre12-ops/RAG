## B. 검토 후 보류 (의도적 미수정)

- **B3 (청크 노이즈 가드)** — *철회*. 짧은 노이즈 청크 스파이크 과분류를 막으려 severe-max에
  최소길이 필터를 시도했으나, 짧은 *비밀* 청크("마스터 키: …")도 배제돼 **미탐(FNR) 유발**
  (test_audit_w2_a가 적발). 영업비밀 시스템은 **과분류가 안전 방향**이므로 전체 청크 severe-max
  유지가 옳음. → 미적용 확정.

## A2. 능동학습 배포 폐곡선 — 이번 세션 후속 구현 (A2-①②·C-ver) ✅

자체감사 후 코드 정밀대조에서 **A2의 현 동작이 백로그 기술보다 더 깨져 있었음**을 확인:
`TrainReport`에 `run_id`가 없어([trainer.py](../poc/src/lloydk/modules/m4_training/trainer.py))
`train_classifier_task`가 **랜덤 UUID**로 소비를 시도 → 그 UUID가 `training_runs`에 없어
`consumed_in_run` FK가 깨짐 → 교정이 소비도 안 되고(무한누적) 학습 반영도 안 됨
(`spec_kwargs=None`). 보안 직결(미탐 누적 교정이 영원히 미반영)이라 #1 우선 처리.

| ID | 조치 | 구현 | 검증 |
|---|---|---|---|
| **A2-①** 교정유실 차단 | unconsumed corrections를 `{text,label}`로 재빌드(본문=Chunk→preview, 정답=최신 교정등급) → **train만** 병합(홀드아웃 불변) → **실제 반영된 correction_id만** 실 `TrainingRun` id로 소비. 본문 없으면 제외+미소비(라벨 날조·무손실) | [corrections_rebuild.py](../poc/src/lloydk/modules/m6_evaluation/corrections_rebuild.py) + [tasks.py train_classifier_task](../poc/src/lloydk/workers/tasks.py) 재배선 | test_corrections_rebuild(5), test_wiring_4_closures(반영분만 소비·무반영시 무소비) |

데이터로 확정한 뒤 켠다. (동시성 락·수동/자동 롤백·서빙 전환·핫리로드는 아래 A4에서 완료 —
소형 GPU E2E 7/7 PASS, 대규모 full-train만 잔여.)

## A4. 3차 — 폐곡선 끝까지 배선 (정직 감사 후) ✅

"만들었으나 끝맺지 않은" 미배선 4건을 마감 — 폐곡선이 DB 장부가 아니라 **실제 작동**.

| 항목 | 마감 | 기본값(동작 보존) |
|---|---|---|
| **자동 롤백 스케줄** | `auto_rollback_tick`을 celery beat 매 60분 등록(라이브 fnr_high 회귀 시 직전 활성 복귀) | `auto_rollback_enabled=False`(판정·로깅만) |
| **검수자 신뢰도 게이트 배선** | `compute_reviewer_reliability(db=)` 세션주입으로 2인검토 정족수에 반영(저신뢰 동의 제외) | `high_grade_review_min_reliability=0.0` |
| **서빙↔활성 ModelVersion** (핵심) | `ClassifyService`가 활성 ModelVersion.model_uri 우선 로드(env 폴백) → activate/rollback이 **실제 서빙 모델 전환** | `serving_prefer_active_model=True`(활성 없으면 env=동작보존) |
| **모델 핫리로드** | `POST /admin/model/reload`(admin) — activate/rollback 후 **재기동 없이** 서빙 적용 | — |

검증: test_auto_rollback(8)·test_reviewer_trust(2)·test_serving_model_resolve(11, fullstack API 포함). 회귀 0.

남은 본질 레버(데이터·정책): **B1/C-esc 운영점 확정**(doc/37에서 109건 실측, 골든셋 500건 확정만 잔여),
**C-cons 정식 검수정책**(검토자 자격·사인오프 범위, 발주처), **실데이터 확보**(합성→실 격차), **대규모 GPU full-train E2E**(소형 7/7 완료).

## 본개발 우선순위(갱신)
1. ✅ **A2-①②·C-ver + 잔여(락·롤백)** — 이번 세션 완료
2. ✅ **C-esc·C-eval·B1·C-cons 메커니즘 배선** — 이번 세션 완료
3. ✅ **C-esc/C-eval 운영점 실측** — 실 모델+실 홀드아웃 109건 측정([doc/37](37_운영점_실측_B1_Cesc_Ceval.md)).
   **발견: 서빙경로 FNR(0.018)이 원시 argmax 평가(0.167)보다 9배 낮다**(룰 override 효과) →
   원시 스윕 추천 τ=0.10은 배포엔 과분류 유발. **운영점 확정: 기본 argmax(FNR_TS=0)·고등급
   미탐0 강제 시 τ=0.35**. **B1 배수도 서빙스윕 완료 → 1.0 유지 확정**(낮추면 FNR↑·F1↓ 순손해,
   범용약어는 S1 recall에 load-bearing).
4. **실데이터 확보** + **실 GPU 재학습 E2E** + **C-cons 정식정책**(발주처)
