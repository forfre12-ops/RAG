## 1. 정본 가이드가 제시하는 2가지 산정법 (PDF 원문)

발주처 정본 가이드는 **같은 4등급에 이르는 두 경로**를 제시한다. 가이드 12페이지 상단에 *"기업 현황·여건에 따라 2~4단계 중 적용 가능한 단계를 선택"* 으로 **택일·선택 적용**을 명시한다.

### 1.1 A안 — 5요소 100점 가산식 (가이드 5p, "영업비밀 등급산정식")

| 평가항목 | 배점 | 평가점수 |
|---|---:|---|
| 정보 창출 및 유지비용 | 10 | 상10·중6·하1 (A) |
| 산출 정보 수준 | 15 | 상15·중9·하3 (B) |
| 정보 활용도(공유 정도) | 10 | 상10·중6·하1 (C) |
| 정보 활용 파급효과 — 내부 활용 효과 | 35 | 상35·중21·하7 (D) |
| 정보 활용 파급효과 — 외부 유출 위험 | 30 | 상30·중18·하6 (E) |
| **총점** | **100** | **A+B+C+D+E** |

**등급 기준**: 특급기밀 = *별도 산정 없이 기업 자체분류* / 1등급 비밀 = **≥75점** / 2등급 대외비 = **≥50점** / 3급 공개 = **<50점**

### 1.2 B안 — 3요소 곱셈식 S×V×M (가이드 11~12p, "등급분류 기준 / 방법") ← **본 시스템 채택**

각 요소를 0/1/2점으로 평가한 뒤 **세 점수를 곱한다.**

| 점수 | 비공지성(S) | 경제적 유용성(V) | 비밀관리성(M) |
|---:|---|---|---|
| 0 | 불특정 다수에게 공개된 정보 | 경제적 가치 없는 정보 | 비밀로 관리 불가 / 임직원 외 모두 알아야 |
| 1 | 통상적 방법으론 입수 곤란 | 취득·개발에 비용·노력 투입 | 임직원 일부만 자체 공개 |
| 2 | 보유자를 통하지 않곤 알 수 없음 | 상당한 비용·노력 투입 | 승인된 자에 한해 공개 |

**S×V×M → 등급 (4단계):**

| S×V×M | 등급(시스템 코드) | 가이드 표기 |
|---:|---|---|
| **8** | 특급기밀 (TS) | 극비 (등급 1) |
| **4** | 1등급 비밀 (S1) | 비밀 (등급 2) |
| **1 또는 2** | 2등급 대외비 (S2) | 대외비 (등급 3) |
| **0** | 3급 공개 (S3) | 일반공개정보 (등급 4) |

**가이드 12p 워크드 예시 (검증용 시드):**

| 문서 | S | V | M | S×V×M | 등급 |
|---|:-:|:-:|:-:|:-:|---|
| 조직도 | 1 | 1 | 1 | 1 | 2급 대외비 |
| 내선번호 | 0 | 0 | 0 | 0 | 3급 공개 |
| 인사평가보고서 | 1 | 2 | 2 | 4 | 1급 비밀 ※가이드 원본. v2.2는 S2로 보정 — §3.7 |
| 중장기 경영계획 | 2 | 2 | 2 | 8 | 특급기밀 |
| 사무실 배치도 | 1 | 1 | 0 | 0 | 3급 공개 |

## 2. 4등급 체계 (정본 가이드 정합)

| 코드 | 정본 등급명 | 영문(가이드) | 정의(가이드 10p 관리등급) | S×V×M |
|---|---|---|---|:-:|
| **TS** | 특급기밀 | Confidential | 기업의 생존과 직결 — 관련 임원 등 한정 인원만 접근 | 8 / 자체분류 |
| **S1** | 1등급 비밀 | Restricted | 내부 직원 중 관련 직원 일부에게만 접근 제한 | 4 |
| **S2** | 2등급 대외비 | Internal Use | 내부 직원에게만 접근 제한 | 1·2 |
| **S3** | 3급 공개 | Public | 기업 내·외부에 공개된 정보 | 0 |

> **표기 정합 주의**: v1.1은 영문을 TS=Top Secret, S1=Restricted, **S2=Confidential** 로 표기해 정본(특급=Confidential)과 **충돌**했다. v2는 정본 영문(특급=Confidential, 1등급=Restricted, 2등급=Internal Use, 3급=Public)을 **정본 표기**로 채택한다. 내부 식별 코드(TS/S1/S2/S3)는 안정적 식별자로 유지하되, UI·감리문서 **표시명**은 정본 한국어("특급기밀/1등급 비밀/2등급 대외비/3급 공개")를 사용한다.

## 3. 본 시스템 적용 결정 (PDF에 없는 우리 결정 — 화요일 협의 확정 대상)

### 3.1 산정 요소: 정본 3요건 채택

영업비밀의 법적 정의(부정경쟁방지법 §2.2)는 **비공지성·경제적 유용성·비밀관리성** 3요건이고, 정본 가이드 B안이 이를 그대로 S/V/M으로 쓴다. 따라서 시스템 `evaluation_factors`를 **3요소로 정정**한다.

| 코드 | 명칭 | 정본 대응 | 비고 |
|---|---|---|---|
| `SECRECY` | 비공지성 (S) | 가이드 비공지성 0/1/2 | **곱셈 게이트** — 0이면 전체 0 |
| `VALUE` | 경제적 유용성 (V) | 가이드 경제적 유용성 0/1/2 | |
| `MANAGEMENT` | 비밀관리성 (M) | 가이드 비밀관리성 0/1/2 | |

> v1.1의 4번째 요소 **`DAMAGE`/`LEAK_IMPACT`(유출영향도)는 삭제**한다. 정본 3요건에 없고, '외부 유출 위험'은 A안(보조)에만 존재한다. (DB 행 삭제 + 가중 재배분 — DDL 변경 아님, §5 참조.)

### 3.2 점수 스케일 변경: 0~5 → **0~2**, 합산 → **곱셈**

- 각 요소 점수 도메인을 **0/1/2** 로 변경(현 0.0~5.0 CHECK → 0~2).
- 최종 등급 = `grade_from(S × V × M)` (가이드 4단계 매핑). 기존 가중합·임계값(4.0/3.0/2.0) 폐기.

### 3.3 왜 B안(곱셈)인가 — 채택 근거

1. **4등급 1:1 매핑** — 8/4/1·2/0 → 특급/1급/2급/3급으로 깔끔히 대응.
2. **과분류 근본 차단** — 곱셈은 *한 요소라도 0이면 0(공개)*. v1.1이 게이트(§4.0)로 따로 막던 "공개문서 과분류"(실측: 공개판례 85% 과분류)를 **산정식 자체가 내포**한다. 즉 비공지성=0이면 경제가치·관리성이 아무리 높아도 자동 S3 → 부정경쟁방지법 §2.2(비공지성=필요조건)와 정합.
3. **라벨링·골든셋 단순화** — 입력이 0/1/2 3단계뿐이라 사람 검수·합성 라벨·일치도 측정이 단순하고 재현성이 높다.
4. **정본 예시와 직접 대조 가능** — 가이드 12p 워크드 예시(조직도=1, 중장기경영계획=8 등)를 회귀 테스트 정답으로 그대로 사용.
5. **AI 운영 가능성 (결정적 근거)** — A안 5요소 중 '정보 창출·유지 비용', '내부 활용 효과', '외부 유출 위험'은 **문서 본문에 거의 없는 외부 경영·재무 정보**라 텍스트 분류 AI로 산출 불가. 반면 B안 3요건(비공지성·경제유용성·비밀관리성)은 텍스트·메타데이터로 근사 가능. **즉 A안=사람 수기 정량평가용, B안=AI 자동분류용으로 용도가 다르다.** 게다가 A안은 특급=자체분류(비산출)라 AI에게 사실상 3등급 문제로 축소된다.

> **설계 결정 (수행사 전문가 판단)**: AI 자동분류 정본 산정법 = **B안(S×V×M)**. A안은 회원사 **수기 자가진단 보조**(§6)로 보존. 이는 발주처 *승인 대기 사항이 아니라* 위 5개 기술·법리 근거에 따른 **수행사 설계 결정**이며, 발주처에는 **근거와 함께 통보**한다. 가이드가 두 방식을 모두 제시하고 "기업 여건에 맞게 선택"을 명시(p12)하므로 가이드 위배 아님. *트레이드오프 정직 표기*: B안은 0/1/2 3단계라 A안의 100점 그라데이션보다 세밀도가 낮다 — 단 R1(룰↔모델 분리)·R2(콘텐츠 가드)로 보완되며, AI 운영가능성·법리정합 이득이 세밀도 손실을 압도한다.

### 3.4 특급기밀(TS) 처리 — **자동분류 + 수동지정 병행**

정본은 특급을 *자체분류*(A안) 또는 *극비 S=V=M=2*(B안)로 본다. 본 시스템은 다음 **OR** 조건으로 TS를 부여한다:

1. **S×V×M = 8** (S=V=M=2), 또는
2. **명시 표기** 본문/메타에 "특급기밀·극비·Top Secret·1급 보안·Eyes-Only" 등, 또는
3. **관리자 자체분류(수동 오버라이드)** — 점수와 무관하게 기업/담당자가 특급 지정.

> 운영 의미: AI는 특급을 *제안*하되 특급은 본질적으로 판단·자체분류 영역이므로 **항상 사람 확정**을 거친다(FUN-005 임시저장→확정과 정합). 평가 시 **특급의 미탐율(FNR)** 을 보안상 최우선 지표로 관리한다. (단, 공개·합성 데이터에 특급 표본이 희소하므로 골든셋의 특급은 합성·수동 시드로 별도 확보 — [doc/05](05_PoC_데이터셋_구축계획.md) 연계.)
>
> **설계 결정 + 평가 범위 (수행사 판단)**: 위 병행안은 가이드의 **A안(자체분류)·B안(S=V=M=2)을 모두 만족**하므로 충돌 없음 → 발주처 통보 사항. 단 **AI 특급-FNR 평가 대상은 "텍스트로 산출 가능한 특급(S=V=M=2 신호 보유)"에 한정**하고, 텍스트 신호가 없는 순수 자체분류 특급(예: 경영진만 아는 M&A 결정)은 AI 책임 범위 밖(수동 지정)으로 둔다 — 신호 없는 문서의 미탐으로 모델을 과벌하지 않기 위함(공정한 평가 기준).

### 3.5 설계 정합성 점검 — 적용 정밀화 (R1~R6, 2026-06-18 설계 재검토 반영)

> "B안이 AI 시스템에 최선인가"를 과분류↔과소분류(미탐) 트레이드오프 관점에서 재점검한 결과 도출한 6개 정밀화다. 대부분은 기존 설계가 이미 내포한다.

- **R1 (룰↔모델 분리)** — BERT 분류기는 텍스트→등급을 **직접** 학습·추론한다([doc/04 §5 말미](04_AI코어_모듈_상세설계.md)). S×V×M은 *학습 라벨·룰 후보·근거(evidence)* 산정 계층이지 모델의 추론식이 아니다. → 곱셈의 "급변(cliff)"이 모델 추론에 직접 전가되지 않는다.
- **R2 (추론단 미탐 안전장치 유지)** — [doc/32](32_평가체계_실데이터_전환_권장안.md) 실측: **출처(비공지성) 게이트는 과분류 93%→0%(트레이드오프 0)**, 그러나 *콘텐츠 축 과격 재라벨은 과소분류(미탐↑)로 역전*. ∴ 곱셈 게이트는 **출처/비공지성(S) 축**(신뢰 프로비넌스)에만 하드 적용, 내용(V·M) 축은 콘텐츠 미탐 가드 + 상향충돌 시 검수 라우팅 유지(silent 하향 금지).
- **R3 (등급체계·매핑 설정화)** — FUN-005는 관리자의 등급체계 추가/변경/삭제를 요구하고, 가이드도 2·3·4단계 선택을 허용한다. ∴ 등급 개수와 `S×V×M→등급` 매핑(8/4/1·2/0)을 **하드코딩하지 않고 DB·설정 주도**로 둔다.
- **R4 (유출영향도 처리)** — 정본 3요건에 '유출영향도'는 없다. 대신 **등급 서열 + `classification_levels.loss_weight`(고등급 오분류 가중) + 등급별 FNR**로 보존(별도 입력 요소 아님). loss_weight 컬럼 유지.
- **R5 (특급 표본·기대치)** — 특급은 S=V=M=2 또는 자체분류라 표본이 희소. 골든셋의 특급은 합성·수동 시드로 별도 확보, 모델이 내용만으로 특급을 못 만들어도 미탐으로 과벌하지 않는다(자체분류 영역).
- **R6 (S·M은 메타데이터 의존)** — **비밀관리성(M)** 과 사실적 **비공지성(S)** 은 본문 텍스트만으로 판정 곤란(표시·접근권한·출처는 문서 외부 정보). ∴ KL 웹계층의 **출처·보안표시·접근범위 메타데이터**를 S/M 산정 입력으로 받는다(S는 기존 `source_prior`가 일부 담당, M 신호 수신 신설).

> **결론**: B안(곱셈 S×V×M)은 정본 정합·법리 정합·과분류 해소 면에서 **정본 산정식 채택이 최선**이다. 단 R1~R6 전제(R1·R2는 기설계 내포, R3·R6은 신규 반영). 미탐(FNR)은 출처 게이트(과분류↓) + 콘텐츠 가드(과소분류↓)의 **2축 균형**으로 관리한다.

### 3.6 가이드 내부 변이 — 설계 판정 + 근거

가이드 예시표(p6~9)와 산정법(p11~12)이 일부 불일치. **B안 채택의 귀결로 등급은 S×V×M 계산이 정본**이고 예시표는 *전형값 예시*로 본다.

| 변이 | 예시표 | 본 시스템 판정 | 근거 / 결정 주체 |
|---|---|---|---|
| 중장기 경영계획 | 1급(S1) | **S×V×M 계산 결과**(문서별 S/V/M에 따라 1급~특급) | 예시표 단일 등급은 전형 케이스 약식. 실제 등급은 그 문서의 비공지성·가치·관리수준으로 산정 — **B안 채택의 귀결. 수행사 결정** |
| 공개·등록 특허·실용신안 | 2급 대외비 | **3급 공개(S3)** *(등록·공개분 한정. 출원 전·미공개 IP 전략은 내용 따라 S1/S2)* | 등록·공개 특허는 특허청 공표 → 비공지성=0 → 곱=0 → 공개. 부정경쟁방지법 §2.2("공공연히 알려져 있지 아니하고")상 **공개특허는 영업비밀 불성립.** ⚠ 단 이 판정은 **발주처 자체 가이드 예시표(2급)를 정정**하는 것 → 근거 제시 후 **발주처 확인 필요**(§7.2) |

### 3.7 가이드 원본 곱셈 매핑 vs v2.2 운영 보정 — PDF 직접 대조 (2026-06-20 추가)

> **PDF 직접 확인 — 정본 가이드 16p 스캔 이미지본 전수 판독**
> 정본 가이드 PDF는 텍스트 레이어가 없는 **스캔 이미지본(16p)**이라 전 페이지를 직접 판독했다. 가이드는 **두 산정법을 모두 제시**한다 — **A안(Σ 5요소 100점) = p4 절차도·p5 산정식**, **B안(S×V×M 곱셈) = p11 배점·p12 방법**. p12는 곱셈값 4단계 매핑(`0→공개 / 1·2→대외비 / 4→비밀 / 8→극비`)과 워크드 예시(조직도 1·1·1=1=대외비, 인사평가보고서 1·2·2=4=비밀, 중장기경영계획 2·2·2=8=극비)를 제시하고, **"기업 여건에 따라 2~4단계 중 선택"**(p12)·**"S 또는 V 단독값만으로 분류 가능"**(p11)을 명문화한다 — 본 시스템의 B안·4단계 채택은 가이드 위배가 아니다.

본 시스템 v2.2의 `grade_from_svm`은 가이드 B안(p12) 곱셈 매핑을 기반으로 하되, 골든셋 100건 실증에 따라 **두 곳을 운영 보정**했다.

| 케이스 S·V·M | 가이드 원본(p12) | v2.2 운영 보정 | 방향 | 근거 |
|---|---|---|---|---|
| `2·2·0` (곱=0) | 3급 공개(S3) | **1급 비밀(S1)** | 더 보수적(미탐↓) | 관리 미공식화 고가치 영업비밀 — 곱=0이어도 s=2·v=2면 비밀 성립(§4.5). 부정경쟁방지법 §2.2 정합 |
| `1·2·2` (곱=4) | 1급 비밀(S1) *(가이드 12p 인사평가보고서 예시)* | **2급 대외비(S2)** | 덜 보수적(과분류↓) | s<2(공개 가능성 존재) 시 1급 상향 보류 — §3.3 #2 과분류 차단 |

> **설계 결정 (수행사 판단) — 보정을 "설정값"으로 분리**: 위 두 보정은 골든셋 실증 근거가 있으나 **엄밀히는 발주처 가이드의 예시값을 정정**하는 것이다. 따라서 **가이드 순수 곱셈 매핑(0 / 1·2 / 4 / 8)을 기본값(default)으로, v2.2 보정 규칙(2·2·0→S1, 곱4 강등)을 운영 토글**로 분리한다(R3 등급체계 설정화와 동일 — 하드코딩 금지·DB/설정 주도). 발주처가 "가이드 그대로"면 보정 off, "FNR 최우선"이면 on(§7.2 승인 항목).

> **A안 = 사람 수기 (역할 분담 확정)**: A안 5요소 중 **65점(내부 활용효과 35 + 외부 유출위험 30)**은 문서 텍스트에 없는 경영·재무 판단값이라 텍스트 분류 AI로 산출 불가. 가이드도 A안 특급을 "기업 자체분류"로 두어 사람 판단을 전제한다. ∴ **AI = B안 곱셈으로 1차 자동분류 / 사람 = A안으로 가치 정밀평가**(§6). A안의 AI 구현은 시도하지 않는다.

- **모호 사례 검수 라우팅**: "M&A 검토(미확정)", "특허 출원 전/후", "익명화 고객DB" 등은 사람 검수.

### 4.5 S1 운영 판단 기준 — 골든셋 100건 실증 보강 (v2.2 신설)

> **배경**: 골든셋 100건 평가에서 S1 FNR 76%(룰), 48%(LLM). 주원인: `s=2, v=2, m=0` 조합을 시스템이 S1으로 올바르게 분류하지 못하는 사례. 본 절은 그 판단 기준을 명문화한다.

**S1 확정 조건** (아래 3가지 모두 충족):

| 요소 | 기준값 | 판단 근거 |
|------|--------|-----------|
| 비공지성 S | = 2 | 보유자 없이 알 수 없는 정보 (경쟁사가 독자 취득 불가) |
| 경제적 유용성 V | = 2 | 직접 경쟁 우위 또는 매출에 기여 (복제 시 즉각 피해) |
| 비밀관리성 M | = **0** | 공식 문서 등급·물리적 통제 미존재. 비공식 열람 제한만 있어도 해당 |

> ✅ `S×V×M = 0` 이지만 `s==2 AND v==2` 조건에 의해 곱셈식이 S1을 반환한다. 이는 "관리 체계가 미흡해도 비공개 고가치 정보는 영업비밀로 성립"하는 법리(부정경쟁방지법 §2.2)를 반영한 의도적 설계다.

**S1 전형 문서 유형** (골든셋 확인 사례 기반):

| 유형 | 예시 | S/V/M |
|------|------|-------|
| 알고리즘·모델 운영 파라미터 | 가격 최적화 알고리즘 임계값, 사기 탐지 드롭률 테이블, AVM 보정 계수 | 2/2/0 |
| 장기 축적 노하우 | 금형 공차 설계 집성 문서, 발효 배합비·공정 명세 | 2/2/0 |
| 비공식 열람 제한 영업 전략 | 수익 배분 기준서, 공급망 헤징 전략 및 대체 공급사 목록 | 2/2/0 |
| NDA만 있고 내부 등급 미부여 | M&A 자문 쇼트리스트, 임원 보상·스톡옵션 풀 설계 | 2/2/0 |
| 승인 전 단계 임상·검증 데이터 | IRB 승인 전 예후 예측 모델 검증 보고서 | 2/2/0 |

**S1 vs TS 분기 핵심**:
- `m = 0` → **S1** (관리 공식화 없음)
- `m ≥ 1` → **TS 후보** (비밀관리성 존재, 아래 §4.6 분기표 확인)

### 4.6 등급 결정 분기표 (TS · S1 · S2 · S3) — v2.2 신설

```
s == 2 AND v == 2?
├── YES
│   ├── m == 0  → S1 (관리 미공식화 고가치 영업비밀)
│   ├── m == 1  → TS (S×V×M=4, 비밀관리 존재)
│   └── m == 2  → TS (S×V×M=8, 엄격 통제)
└── NO  (s < 2 OR v < 2)
    ├── s == 0  → S3 (Gate-1 비공지성 게이트 강제)
    ├── S×V×M ≥ 1  → S2
    └── S×V×M == 0 (but not s=2,v=2)  → S3
```

**경계 케이스 판단 보조표**:

| S | V | M | S×V×M | 등급 | 대표 케이스 |
|:-:|:-:|:-:|------:|------|-------------|
| 2 | 2 | 2 | 8 | **TS** | 반도체 공정 레시피, 군사 AI 아키텍처 |
| 2 | 2 | 1 | 4 | **TS** | 임상 1상 중간 데이터, 양자컴퓨팅 실험셋 |
| 2 | 2 | 0 | 0* | **S1** | 알고리즘 운영 파라미터, 임원 보상 체계 |
| 2 | 1 | 2 | 4 | **S2** | 내부 기술 검토안 (가치 간접적) |
| 2 | 1 | 1 | 2 | **S2** | 사업 계획 초안, 협상 조건 |
| 1 | 2 | 1 | 2 | **S2** | 경영 전략 보고서 |
| 1 | 1 | 1 | 1 | **S2** | 조직도, 교육 교안 |
| 1 | 1 | 0 | 0 | **S3** | 사무실 배치도 (가이드 예시) |
| 0 | * | * | 0 | **S3** | 공시·보도자료·공개특허·학술논문 |

> *`s=2, v=2, m=0` → 곱=0이나 `s==2 AND v==2` 분기에 의해 S1 반환. 이 케이스에 한해 곱=0이 S3가 아닌 S1을 의미한다.

## 6. A안(5요소 100점) 보존 — 보조 옵션 + 충돌 해소 정책

A안(§1.1)은 **회원사 자가진단/정량 산정** 보조 모드로 보존한다. AI 자동분류 정본 룰은 B안이며, A안은 기업이 수동으로 자료 가치를 정량 평가할 때 별도 산식으로 제공한다(선택).

### 6.1 A안과 B안은 합산하지 않는다 — 다른 척도

두 안은 **척도가 달라 점수를 직접 더하거나 평균낼 수 없다.** 각자 4등급으로 환산한 뒤 **등급 코드 수준에서만** 비교한다. A안과 B안을 가중합하는 **제3의 공식은 두지 않는다.**

| 구분 | A안 (사람 수기) | B안 (AI 자동) |
|---|---|---|
| 척도 | 0~**100점 가산** (Σ 5요소) | 0~**8 곱셈** (S×V×M) |
| 등급 임계 | 특급=자체분류 / ≥75 1급 / ≥50 2급 / <50 3급 | 8 특급 / 4 1급 / 1·2 2급 / 0 3급 |
| 특급 산출 | **점수로 안 나옴** — 자체분류(사람 별도 지정). 100점 만점도 자동은 1급까지 | 곱=8이면 특급 산출 (단 확정은 항상 사람) |
| 입력 정보 | 매출 기여도·유출 손실 등 **경영·재무 판단** 포함 | 문서 **텍스트·메타데이터** 근사 |

### 6.2 A안으로 매기면 그게 절대기준 — 사람 우선

사람이 A안 100점으로 정량 평가하면, **A안 자체의 임계(특급=자체분류 / ≥75 / ≥50 / <50)로 확정된 등급이 그 문서의 절대기준**이 된다. 이는 시스템의 기존 원칙 *"사람이 확정한 라벨이 있으면 AI 추론을 건너뛴다"*(verified_label 우선, `classify_service`)와 동일하다. 사람 판단 > 기계 추론.

```
A안(사람 확정) 있음   → A안이 절대기준. AI(B안) 추론 스킵
A안 없음             → B안(AI)이 1차 자동분류
둘 다 있고 불일치     → 사람(A안) 우선
                       단 AI가 더 높은 등급이면(미탐 위험) 검수 라우팅
                       AI가 더 낮으면 무시(사람 우선)
```

> **충돌 해소 = 산술 합산이 아니라 우선순위 + 보안 게이트**: 핵심은 **"사람 우선 + 보안상 AI가 더 높으면 재확인"**이다. AI(B안)가 사람(A안)보다 **낮게** 보면 사람 판단을 따르고, **높게** 보면 흘려보내지 않고 검수로 띄운다(미탐 방지). 두 등급을 평균·가중합하는 일은 없다.

> **특급은 A안에서 점수로 안 나온다**: A안은 **특급기밀 = "기업 자체분류"**라 100점 만점을 받아도 자동으로는 **1급까지만** 산출된다. 특급은 사람이 **별도 명시 지정**해야 한다(§3.4 — AI는 제안만, 특급 확정은 항상 사람). 운영 화면에서 A안 75점↑ 문서는 "1급(특급 후보)"로 표시하고 특급 승격은 별도 결재로 둘 것.

## 7. 결정 상태 — 수행사 확정 / 발주처 확인 / 협조

### 7.1 수행사 설계 확정 — 근거 통보(승인 대기 아님)
- **산정법 = B안(S×V×M)** — §3.3 근거 5종(특히 **AI 운영가능성**: A안 요소는 문서 텍스트로 산출 불가). A안은 수기 보조(§6).
- **특급 = 자동(S=V=M=2)+명시표기+수동 병행, 항상 사람 확정** — §3.4. 가이드 A·B 모두 만족.
- **변이①(중장기 경영계획 등) = S×V×M 계산 정본**, 예시표는 전형값 참고 — §3.6.

### 7.2 발주처 확인 필요 — 발주처 자체 가이드를 정정하는 판정
- **변이②: 공개·등록 특허·실용신안 = 3급 공개(S3)** — 예시표는 2급이나 비공지성 법리상 공개 IP는 영업비밀 불성립(§3.6). 근거 제시 후 확인. (출원 전·미공개 IP 전략은 별도)
- **v2.2 곱셈 보정 2건(`2·2·0→S1`, `1·2·2 등 곱4 강등→S2`) = 가이드 p12 곱셈 매핑 정정**(§3.7) — 골든셋 실증 근거가 있으나 가이드 원본과 다르므로, **기본값(가이드 순수 곱셈) + 보정 토글** 구조로 두고 발주처 승인 후 보정 활성화 권고.

### 7.3 발주처 협조·값 합의 필요
- 모델 운영 임계값(confidence·검수 라우팅) + **90% 측정 기준**(전체 vs 등급별) + 실데이터 제공 여부 — PMR-002.
- 등급 한국어/영문 표시명 최종 확정(§2).
- (KL) R6 S/V/M 메타데이터 인터페이스.
- GPU·서버 사양(PER-002).
