> **요약**: 정본 가이드를 코드·문서·DB·골든셋 시드까지 반영 완료(B안 S×V×M, 테스트 통과). 다만 가이드가 **2가지 산정법**을 제시하고 **내부 변이**가 있어, 아래를 발주처가 확정해야 모델을 최종 고정하고 1,000건 골든셋·90% 검증에 착수할 수 있음.

## 안건 1. 등급 산정법 채택 — A안(가산) vs **B안(곱셈)** ★핵심

| | A안 (가이드 5p) | **B안 (가이드 11~12p) — 권장** |
|---|---|---|
| 방식 | 5요소 100점 **가산** | 3요건 **곱셈** 등급=S×V×M |
| 임계 | 1급≥75·2급≥50·3급<50, 특급=자체분류 | 8→특급·4→1급·1·2→2급·0→3급 |
| 장점 | 정량 자가진단 적합 | **4등급 1:1 매핑 · 법적 3요건 정합 · "한 요소라도 0이면 공개"로 과분류 차단** |

- **우리 권장: B안 채택.** 근거 — 영업비밀 법적 3요건과 정합, 과분류 문제 근본 해결(doc/32 실측: 출처 게이트로 과분류 93%→0%, 트레이드오프 0).
- **발주처 확정 필요**: ① B안을 정본 산정법으로 승인? ② A안(100점)은 회원사 자가진단 보조로 병행할지?

## 안건 2. 특급기밀(TS) 처리 방식

- 가이드상 특급 = *자체분류*(A안) 또는 *S=V=M=2 극비*(B안). 본질적으로 판단·자체분류 영역.
- **우리 권장**: 자동분류(S×V×M=8) + 명시표기 + **관리자 수동지정 병행**, 특급은 **항상 사람 확정**. 특급 **미탐율(FNR)** 을 보안상 최우선 지표로 관리.
- **발주처 확정 필요**: 특급을 AI 자동분류 대상에 포함할지 vs 수동지정 전용으로 둘지. (모델 평가 기대치·골든셋 특급 표본 확보 방식이 달라짐)

## 안건 3. 목표 정확도 90% 와 QA 버퍼 (PMR-002)

- RFP: **1,000건 이상 블라인드 골든셋 + 목표 정확도 90% + 미달 시 보완·재학습 QA버퍼 최소 2주**.
- **현실성 의견**: 4등급 영업비밀 분류에서 90%는 도전적. **보안축(고등급 FNR≈0)** 과 **정확도축**을 분리 평가하고, QA버퍼 2주를 WBS에 명시(RFP 요건) 권장.
- **발주처 확정 필요**: ① 90% 측정 기준(전체 정확도 vs 등급별)? ② 측정용 **실데이터 제공 여부**(미제공 시 합성·공개 데이터로 검증).

## 안건 4. 골든셋 1,000건 구성 방안 (PMR-002 / 8월 일정)

- **현황(완료)**: 가이드 예시표 기반 **골든셋 시드 v2** 구축 — S/V/M 앵커(p12) + 요건별 레벨 예시(p11) + 직무별 등급 예시(p6~9).
- **방안**: 가이드 예시표 + LLM 합성 + **사람 검수** → 1,000건, train과 **완전 격리(블라인드)**. 발주처 비밀 실데이터 없이도 구성 가능 → **개인정보·제3자 저작권 사전검토(PMR-001) 리스크 회피**.
- **발주처 확정 필요**: ① 검수에 발주처 검수자 참여 가능 여부? ② 희소한 **특급 표본** 확보 방법(합성/수동 시드).

## 안건 5. 가이드 내부 변이 — 정본 판정 ★주의

가이드의 **예시표(p6~9)** 와 **S×V×M 워크드 예시(p12)** 가 일부 불일치(가이드 p2: "각 기업 현실에 맞게 수정 활용" 특성).

| 문서 | 예시표(p6~9) | S×V×M(p12) |
|---|---|---|
| 중장기 경영계획 | 1급(S1) | S=V=M=2 → **특급(TS)** |

- **우리 권장**: **S×V×M(p11·p12)을 정본**으로 → `svm_anchor` 권위, 예시표는 검수 대상.
- **발주처 확정 필요**: 변이 항목에 대해 어느 산정을 정본으로 볼지 확인(추가 변이는 골든셋 검수 시 도출·정리).

## 안건 6. S/V/M 산정에 필요한 메타데이터 — KL 인터페이스 (R6)

- **비밀관리성(M)** 과 사실적 **비공지성(S)** 은 *문서 본문만으로 판정 곤란* — 보안표시·접근권한·출처는 문서 외부 정보.
- **우리 권장**: KL 웹계층이 **출처·보안표시·접근범위 메타데이터**를 분류 API로 함께 전달(비공지성 게이트는 기 구현된 `source_prior`가 일부 담당).
- **확정 필요(KL)**: 분류 요청 시 전달할 메타 필드 합의.

## 안건 7. 성능·측정 환경 (PER-002 / ECR-001)

- RFP: 등록 **3초** · 문서 등록/분류 **30초** · 메모리 **90% 미만** · CPU **70% 이하**.
- **확정 필요(발주처)**: 학습·추론 **GPU/서버 사양**, 부하 측정 환경(현재 부하시험 미실시).
